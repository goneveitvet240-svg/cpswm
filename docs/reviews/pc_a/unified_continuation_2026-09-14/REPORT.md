## 恢复与使用边界

生产部署必须在启动时计算并固定源码和依赖身份，将同一 `ContinuousStateStore` 交给连续入口。首次初始化会保存一次完整状态；已存在状态必须用 `ContinuousEvidenceInput.resume`。上下文构造器应由相同配置确定，恢复待完成 P5 步骤时原输入、cutoff 和上下文绑定必须一致。不能更换状态源后继续旧会话。

本地检查点用于崩溃恢复，不是抵抗能修改本地数据库并重算摘要的攻击者的独立保管证明；所有外部成功/失败语义仍依赖所配置的执行器与校准生产者。SQLite/对象图当前为小预算开发实现，不能承诺无限历史或任意物理故障下 exactly-once。

固定开发扫描入口：`tools/run_continuous_unity_camera.py`，使用既有 Python 3.11 AI2-THOR SDK 进程和 Python 3.13 感知/核心进程。只有 SDK 进程拥有相机控制器；只有连续入口拥有 CPSWM 记忆。
