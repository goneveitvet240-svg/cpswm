# VISOR 图像特征对照：部分图像依赖，但接触收益尚未成立

本轮完成同预算图像/偏置对照与全61帧分离视频开发诊断。图像读出优于同SGD步数偏置读出；但两个预算均未超过按训练标签求得的最优常数参照，且无接触类比同预算偏置更差。因此现有结果不足以将读出接入可信接触或部署前端，不能用平均损失下降宣布结构二视觉能力闭合。

训练频率参照是同一逐帧可用轴BCE目标下的解析最优常数：每轴对有监督训练帧的正像素比例取平均，不池化像素，不看新视频标签。运行时无接触先验、正式架构/阈值/论文指标均未改。

## 真实结果

下表为所有帧各可用轴平均二元交叉熵之和，再按帧平均，越低越好；不是准确率。

|读出|拟合8帧|P01_03完整61帧|
|---|---:|---:|
|仅偏置16步|1.173382|1.160622|
|图像特征16步|1.078964|1.088961|
|仅偏置128步|0.961949|0.991537|
|图像特征128步|0.673207|0.789911|
|训练频率解析常数|**0.520727**|**0.725423**|

图像臂相对同预算偏置臂的目标较低，但两预算都没有超过常数参照；偏置SGD仍未达到其解析最优，不能仅凭击败未收敛偏置宣称视觉收益。

128步新视频接触正类BCE：图像0.301522、偏置0.519074；无接触类：图像**1.343687**、偏置**0.904045**。多数接触类改善伴随无接触恶化。解析常数在无接触类更差（3.003937），进一步表明总目标被多数类影响，不能当成完整接触辨别能力。

把完整视频每帧标签配给下一帧RGB（最后配第一帧、不删帧、不自配）后，图像16步目标1.092378、128步0.809516，相对正确配对高0.003418/0.019606。这提供有限的输入对应依赖迹象；相邻帧相关、只有一个开发视频和2帧接触负类，不能推成稳健泛化或候选召回提升。未按结果调参或发布新模型。
