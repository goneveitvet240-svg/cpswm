# 项目结构一：长期家庭观察与持续个性化习惯世界模型

英文工作名：**Long-term Household Observation and Continual Personalized Habit World Model**  
版本：`v0.2`  
日期：2026-08-13  
上位文件：`项目总纲_持续个性化语义世界模型_v1.0.md`

## 0. 方向声明与范围边界

本结构是 CPSWM 的一条**核心研究主线**，不是被缩减后的验证代价子项目。

它研究的是：

> 家庭机器人如何通过跨天、跨周和跨月的持续观察，逐渐理解当前家庭中的人物、物体、场景、活动和生活安排；学习不同人物对具体物体的使用、携带、摆放、归还和整理习惯；结合物体属性与常识形成个性化家庭模型；在遮挡、漏观测、多人干扰和习惯变化下维护可追溯的概率记忆；预测物体未来位置和家庭行为，并把这些长期知识用于语言理解、主动协助、搜索、导航、操作和日常共处。

本结构明确包含但不限于：

- 长期、非任务限定的家庭观察；
- household scene arrangement（家庭场景与常景安排）学习；
- 具体物体实例、属性、功能和空间关系；
- 通用常识与当前家庭个性化规律的结合；
- 稳定物体、常回原位物体、多常用位置物体和持续迁移物体；
- 人物—物体—时间—活动—地点条件化习惯；
- 多人物、访客、物体交接和人物归因不确定性；
- 情景记忆、隐藏事件和未观测状态转移；
- 习惯形成、巩固、渐变、突变、回归和遗忘；
- 下一位置、下一使用者、下一活动相关位置预测；
- observed habit（观察到的习惯）、stated preference（明确偏好）和 normative placement（规范位置）的区分；
- 个性化查询、解释、协助、搜索、导航、递送、整理和放回。

以下内容**不能定义或缩小本项目**：

- 只研究“是否需要重新观察”；
- 只研究 object search（物体搜索）；
- 只优化 ECE、Brier、NLL 等校准指标；
- 只优化搜索时间、移动距离、询问次数或验证成本；
- 只把项目表述为 partial observability（部分可观测）问题；
- 只训练一个 next-location predictor（下一位置预测器）。

重新观察、信息价值和验证成本是下游决策与评价内容之一，不能取代长期家庭理解、个性化记忆和持续习惯学习。

## 1. 项目愿景

### 1.1 从家庭快照到家庭生活模型

机器人最终维护的不只是“房间里现在有什么”，而是一个随时间演化的 personalized household world model（个性化家庭世界模型）：

```text
家庭里有哪些人、物体、房间、家具和容器？
这些具体物体有什么外观、属性、功能和归属？
哪些场景长期稳定，哪些场景按活动反复变化？
不同人物何时使用哪些物体，并通常从哪里拿、放回哪里？
哪些位置是物体的固定位置、主位置、临时位置或多个常用位置？
主人最近是否形成了新的生活安排？
机器人当前知道什么、推断什么、预测什么、仍不知道什么？
这些长期知识怎样帮助机器人理解语言并提供协助？
```

### 1.2 机器人学习的不只是位置频率

对于一个杯子，完整模型不只是保存 `Kitchen: 0.7`，而是理解：

- 它是哪一个具体杯子；
- 材质、容量、颜色、用途和可放置约束；
- 属于谁、通常由谁使用；
- 早餐、工作、喝水和待客时分别出现在哪里；
- 被拿走后是否经常回到原位；
- 是主人放的、家人放的、访客放的还是无法判断；
- 某次出现在沙发上是偶然异常还是新习惯；
- 主人经常放在哪里与希望机器人放回哪里是否一致；
- 下一次使用前后最可能出现在哪里。

## 3. 世界模型的完整表示

### 3.1 家庭语义场景图

维护长期演化图：

\[
G_t=(V_t,E_t)
\]

节点至少包括：

- person（人物）；
- object instance（物体实例）；
- room（房间）；
- furniture（家具）；
- container（容器）；
- activity（活动）；
- household role（家庭角色）。

关系至少包括：

- `located_at / inside / on / near`；
- `belongs_to / used_by / shared_by`；
- `held_by / carried_by / transferred_to`；
- `supports_activity / normally_stored_at`；
- `observed_by / inferred_from / predicted_by`。

### 3.2 六类彼此分离的长期内容

| 内容 | 回答的问题 | 能否直接当作事实 |
|---|---|---|
| direct observation（直接观测） | 当时真正看见了什么 | 作为带质量的证据，不等于永远有效 |
| episodic event（情景事件） | 谁何时对什么做了什么 | 需保留来源和有效时间 |
| inferred event（推断事件） | 观测间隙可能发生了什么 | 否；保留多个候选 |
| habit distribution（习惯分布） | 长期通常怎样 | 否；只能作为统计先验 |
| future prediction（未来预测） | 下一次可能怎样 | 否；不能反向训练自己 |
| preference/norm（偏好/规范） | 主人希望或家庭规定怎样 | 需与实际行为分开 |

### 3.3 联合概率状态

对物体实例 \(o\) 维护：

\[
B_t=P(L_t,I_t,S_t,R_t,E_t,A_t,Z_t,\Theta
\mid O_{1:t},C_{1:t},K,G_{1:t})
\]

其中：

- \(L_t\)：位置；
- \(I_t\)：实例身份；
- \(S_t\)：被拿取、使用、携带、收纳等状态；
- \(R_t\)：归属、使用者和空间关系；
- \(E_t\)：隐藏事件；
- \(A_t\)：行为者；
- \(Z_t\)：当前习惯阶段；
- \(\Theta\)：长期个性化习惯参数；
- \(O_{1:t}\)：实际观测与用户信息；
- \(C_{1:t}\)：时间、活动、人物在场和家庭情境；
- \(K\)：物体属性、功能和通用常识；
- \(G_{1:t}\)：家庭语义场景图历史。

选择性观察信息只是 \(O_{1:t}\) 的质量与缺失机制之一，不是整个模型的中心变量。

## 4. 物体属性、常识与个性化规律

### 4.1 物体属性模型

每个物体实例至少维护：

- 类别、材质、尺寸、颜色和外观；
- 容器性、易碎性、卫生要求、供电或温度要求；
- 可抓取、可堆叠、可悬挂、可折叠等 affordance（可供性）；
- 功能和相关活动；
- 通常适合的房间、家具、容器和空间关系；
- 当前家庭中的归属、使用者和例外规则。

### 4.2 三层位置知识

\[
P(L\mid o,p,c) \propto
P_{common}(L\mid class,attributes)
\times P_{household}(L\mid o,c)
\times P_{person}(L\mid p,o,c)
\]

- common-sense prior（常识先验）：数据不足时提供合理候选；
- household convention（家庭惯例）：这个家庭如何安排；
- person-conditioned habit（人物条件化习惯）：某个人实际如何使用和摆放。

系统必须允许个性化证据逐渐覆盖常识，但不能因一次异常彻底覆盖长期规律。

## 5. 物体移动性与多位置记忆

物体不应只分成“固定”和“移动”两类。候选 mobility profile（移动性画像）包括：

| 类型 | 含义 | 示例 |
|---|---|---|
| anchored（锚定） | 几乎不发生位置改变 | 冰箱、固定电视 |
| stable（稳定） | 有清晰固定位置，偶尔短暂移动 | 路由器、台灯 |
| home-based mobile（主位置可移动） | 经常被拿走，但大多回到主位置 | 钥匙、遥控器 |
| multimodal（多常用位置） | 长期存在多个情境化高频位置 | 水杯、眼镜 |
| activity-carried（活动携带型） | 位置主要由活动链决定 | 清洁工具、工作本 |
| wandering（游走型） | 位置高熵，难以形成稳定模式 | 儿童玩具 |
| regime-changing（阶段变化型） | 主位置随生活安排持续改变 | 搬家后的收纳物品 |

系统为每个实例保存：

- home location（主位置）及其置信度；
- Top-K 常用位置和条件；
- 位置熵、移动率、返回率和典型停留时间；
- 人物条件化转移矩阵；
- 活动触发位置；
- 当前阶段和历史阶段；
- 异常位置及其解释；
- 下一位置预测及不确定性。

## 6. 个性化习惯模型

核心习惯分布为：

\[
P(location,next\ event
\mid person,object\ instance,time,activity,context,history)
\]

习惯学习包含：

1. **频率规律：** 哪些位置经常出现；
2. **转移规律：** 从哪里被拿走，通常去哪里；
3. **时间规律：** 日间、夜间、工作日、周末和季节差异；
4. **活动规律：** 早餐、工作、清洁、休息和待客；
5. **人物规律：** 主人、家人和访客差异；
6. **返回规律：** 使用后是否回到主位置；
7. **共同移动：** 哪些物体经常成组出现或移动；
8. **生命周期：** 习惯怎样形成、巩固、衰退、改变和回归。

候选方法可以是：

- hierarchical Bayesian model（分层贝叶斯模型）；
- temporal point process（时间点过程）；
- dynamic Bayesian network（动态贝叶斯网络）；
- GNN/Transformer 时空序列模型；
- 结构化状态与神经似然结合的 hybrid model（混合模型）。

这里不预先替用户选择最终模型。结构化 Dirichlet 当前仅作为可解释基线。

## 7. 多人物、隐藏事件与不完整观察

家庭中的物体变化可能来自：

```text
主人 / 家庭成员 / 儿童 / 访客 / 机器人自身 / unknown_actor
```

模型需要结合人物在场、轨迹、交互、物体归属、活动和历史习惯，维护行为者后验，而不是把最高概率人物写成事实。

当物体从书桌消失、后来出现在厨房时，系统保留：

```text
Person_A 携带后放在厨房
Person_B 后来移动到厨房
访客或未知人物移动
机器人漏掉了更早的位置变化
实例关联错误
```

选择性、稀疏和不完整观察在这里用于防止错误推断：

- `not_observed` 不等于不存在；
- 未打开容器不能产生容器内部负证据；
- 低质量视角不能产生强排除；
- 纯模型预测不能成为新的训练证据；
- 无法辨识时必须保留 `unknown_actor` 和多个事件候选。

这些是长期习惯模型可靠运行的条件，不是项目最终目的。

## 8. 非平稳习惯与持续学习

系统区分：

- periodic context（周期情境）：工作日与周末不同；
- temporary exception（临时异常）：一次随手放错；
- gradual drift（渐进漂移）：逐渐改变收纳位置；
- abrupt change（突然改变）：搬家或家具调整；
- recurring regime（阶段回归）：季节性或周期性旧习惯返回；
- contradiction/correction（反证与纠正）：模型或感知曾经判断错误。

M19 负责变化检测、旧模式保留、模型版本切换和记忆生命周期，但不得把“遗忘”“不确定性增长”“证据反证”和“习惯变化”混为一件事。

## 9. 行为习惯、偏好和家庭规范

必须分别维护：

| 类型 | 示例 | 机器人用途 |
|---|---|---|
| observed habit | 主人经常把外套放在沙发 | 预测和寻找 |
| stated preference | 主人说希望外套挂进衣柜 | 整理和操作 |
| household norm | 家庭规定药品放在儿童够不到处 | 安全约束 |
| commonsense norm | 生鲜通常需要冷藏 | 通用安全先验 |

因此：

> “最可能在哪里找到”与“机器人应该放回哪里”是两个不同决策问题。

## 10. 从长期理解到机器人能力

长期世界模型应支持：

### 10.1 查询与解释

- “我的眼镜通常放在哪里？”
- “昨天喝水用的是哪个杯子？”
- “这个遥控器最近是不是换地方了？”
- “谁可能把书拿到客厅了？”
- “你为什么认为钥匙在玄关？”

### 10.2 预测与主动协助

- 预测下一次使用的物体和可能位置；
- 在活动开始前准备相关物体；
- 发现长期未归位或异常位置；
- 在置信度不足或偏好冲突时询问；
- 对习惯变化保持适应而不忘记旧规律。

### 10.3 具身行动

- 搜索、导航和开容器；
- 抓取、递送和交接；
- 按明确偏好整理或放回；
- 执行中持续观察并写回世界模型；
- 失败、滑落和部分完成后重新更新信念。

主动观察和 verification cost（验证代价）只在这一层参与动作选择，不定义上游长期世界模型的范围。

## 12. 完整工作流

### WS1 — 家庭长期观察与常景建模

建立房间、家具、容器、人物活动、日程和稳定/变化场景；支持日常任务中的顺带观察。

### WS2 — 物体实例、属性、功能与常识

实现跨时间实例身份、多视角外观、物理属性、功能、可供性和常识位置先验。

### WS3 — 时间化情景记忆与证据图

保存谁、何时、何地、对什么做了什么；区分直接观察、报告、推断、预测和执行结果。

### WS4 — 物体移动性画像和多位置记忆

学习固定位置、主位置、多个常用位置、返回模式、转移和位置熵。

### WS5 — 人物条件化习惯学习

学习人物、物体、时间、活动、情境和历史条件下的使用与摆放规律。

### WS6 — 多人物与隐藏事件推理

支持同屋多人、访客、交接、未知行为者和 Top-K 未观测事件链。

### WS7 — 非平稳持续学习

处理异常、渐变、突变、回归、巩固、纠错、弱化和遗忘。

### WS8 — 预测、语言查询与解释

输出历史事实候选、习惯分布、下一位置预测、变化解释和证据路径。

### WS9 — 家庭机器人协助闭环

把长期知识用于准备、搜索、导航、递送、整理和放回，并把结果写回记忆。

### WS10 — 隐私、长期基准与真实验证

建设多家庭、多人物、跨月、受控噪声和真实感知轨道；评价完整系统能力。

WS1–WS10 都属于完整主线。实现可以分阶段，但不能因当前只实现 WS4 的一个基线，就把项目重新定义为该基线。

| `HabitLearningEvidence` | M15/M17 的可追溯训练样本入口 |
| `HierarchicalDirichletHabitModel` | M17 的结构化可解释 baseline，不是最终方法 |
| `GTPlacementEvent` | M29/M30 的长期家庭真值原子事件 |
| `simulate_location_observation` | M29 向机器人侧投影受限观测的适配器 |

下一步不应围绕“再验证一次观测代价”，而应扩展：

1. 物体属性与功能常识；
2. 移动性画像；
3. 主位置和多常用位置；
4. 时间与活动条件；
5. 行为、偏好和规范三类记忆；
6. 多人物事件轨迹；
7. 下一位置和返回预测。

## 15. 分层评价体系

评价必须反映完整能力，而不是只看代价。

### 15.1 感知与场景层

- 物体实例关联；
- 人物和事件识别；
- 物体属性和空间关系；
- 家庭场景图完整性与时间一致性。

### 15.2 世界模型与记忆层

- 当前与历史位置准确性；
- 关系和事件查询；
- 隐藏事件覆盖与错误硬化率；
- 证据来源、可重建性和纠错一致性。

### 15.3 习惯与持续学习层

- 主位置、Top-K 常用位置和移动性分类；
- 条件化习惯分布和下一位置预测；
- 人物隔离与访客污染；
- 新习惯适应、旧习惯保持和变化边界；
- 行为、偏好和规范的区分准确性。

### 15.4 查询与具身任务层

- 历史、习惯和预测查询质量；
- 搜索、导航、递送、整理和放回成功率；
- 错拿、错放和错误主动协助；
- 用户纠正和解释质量。

### 15.5 成本与校准层

- 路径、时间、能耗、开容器和验证成本；
- 用户询问和打扰次数；
- NLL、Brier、ECE 和行动效用。

第五层用于检查概率是否可靠、决策是否值得，但不能覆盖或替代前四层。

## 16. 创新空间的组织方式

候选创新不被限定为验证代价，可以来自：

- 完整的长期个性化家庭世界模型表示；
- 物体属性、常识与家庭个体规律的持续融合；
- 动态学习物体移动性画像和多模态位置记忆；
- 同一家庭多人物条件下的习惯获取与事件归因；
- 从不完整事件链学习而不是假设完整轨迹；
- 区分实际行为、表达偏好和整理规范；
- 无任务边界的习惯形成、改变、回归和遗忘；
- 长期记忆、预测、语言查询和具身操作的一体化闭环；
- 真实长期家庭数据、基准或系统研究。

其中哪些成为单篇论文的主贡献，需要后续分别做最强邻近工作比较；文献死亡测试用于判断具体论文主张，不再支配总项目结构。

## 17. 尚未替用户决定的技术选择

以下选择继续保留：

1. 结构化贝叶斯、GNN/Transformer 或混合习惯模型；
2. 因子图、动态贝叶斯网络或粒子滤波的隐藏事件方法；
3. BOCPD、遗忘因子、sticky HMM 或其他持续变化模型；
4. 物体常识采用知识图谱、VLM/LLM、视觉属性模型或组合；
5. 家庭长期数据采用符号生成、物理仿真、真实回放或真实家庭采集；
6. 单篇论文先聚焦哪个研究问题；
7. Habitat、iGibson、Isaac Sim 或多平台组合；
8. 真实机器人平台、传感器和隐私采集方式。

本结构负责保存完整范围、依赖关系和推进顺序，不替用户决定最终路线。
