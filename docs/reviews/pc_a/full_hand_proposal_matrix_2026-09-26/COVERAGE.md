# 完整四帧矩阵的审查覆盖

本轮仍为 A 本机自审，不是两个独立审核者，也未替代 B 的独立验收。实际生产 `src/` 与 PR48 完全相同；本轮修改实验诊断、覆盖核验和执行编排。最终结果以 REPORT、命令回执及冻结源码摘要为准。

|范围|本轮覆盖|不能据此宣称|
|---|---|---|
|完整支持正路径|四帧语法含 pick_up/carry/handoff/place/no_move/unresolved；三网络评分质量、全候选身份和枚举顺序检查|识别了正确隐藏事件，或完整活跃粒子六操作在线内核已闭合|
|遗漏后重新归一化|合法目标子集、重复目标、目标与概率摘要错配均拒绝|仅质量和为1即可通过|
|完整伪造正路径|每个合法目标都有有限、归一化的伪造均匀概率；结构检查可通过，实际采样概率核对拒绝|结构摘要认证了真实模型执行或外部世界真值|
|合法实际编排|真实网络对2试次×4窗口夹具执行，8个结果工件、2个恢复检查、6个明确空恢复字段|8个组合都做过采样恢复|
|状态与后果|评分前后快照含请求/RNG保持；首窗恢复缓存请求、完整重复评分、下一次采样；实际前端core/ledger保持、execution traces为0|自然事件已经发布、训练或产生行动收益|
|手输入与身份回归|沿用来源、未来泄漏、恢复、完整伪造观测、区域重复手和人物歧义专项审查|手候选数等于独立手数，或人物框数等于物理人物数|
|真实输入|预定8试次×4短窗×4原帧，三网络同一权重、全支持、原手/去手/x+1像素|四帧窗口等于完整交接过程，或微小概率变化等于准确率提升|

第二审新增7项：5种分布结构攻击、1个真实网络全窗工件与状态检查、1个完整均匀q伪造对实际采样概率检查；其他项目是前轮来源/恢复回归。第一审与第二审的计数存在回归重叠，不相加称为独立科学证据。

真实矩阵计划96个评分/消融组合；仅每试次首窗共24个组合计划采样恢复及重复完整分布，其他72个组合只做评分与请求/RNG不变检查。中断或超时必须单列未完成分母，不能用旧版本或两帧结果补齐。

信任边界仍开放：若攻击者能同时伪造评分、采样、检查点和信任根，本轮检查不构成外部执行认证。人物同一/不同解释是成对未决假设，没有联合身份分区和传递性解算；手物几何未校准为接触/释放概率。
