## 0. 一句话结论

**从 S3-A/B/D 族的交叉点起步，具体是"开放集 × 非平稳 × 异质动作成本"下的保证型拒答与主动询问。**

这个位置的价值在于：三个方向的机器（open-set conformal、adaptive conformal、conformal information pursuit）在 2025–2026 年**分别**被造出来了，但没有任何一篇把它们放在具身个性化检索上组合，而且每一篇的 stated future work 都指向这个组合。同时两个最相关的 benchmark（PersONAL、FindingDory）各占一半，交集是空的。

## 1. 前人占位图（已查证）

### 1.1 已经被明确占掉的——不要声称原创

| 你原本可能想主张的点 | 已有工作 | 占到什么程度 |
|---|---|---|
| conformal 用于机器人不确定性/求助 | KnowNo (Ren et al., CoRL 2023)；Introspective Planning (NeurIPS 2024) | 完全占掉。LLM planner 的选项集上做 conformal，给 1−α 覆盖，触发求助 |
| 开放集 conformal（含"未知"标签） | **Conformal Good-Turing (CGT)**, arXiv 2510.13037 | **完全占掉方法层**。用 Good-Turing p-value 检验新类，预测集里放一个 joker 符号 ⊗ 表示未知标签，有限样本 1−α 保证 |
| conformal + 选择问哪个问题 | **Conformal Information Pursuit (C-IP)**, arXiv 2507.03279 | **完全占掉**。用预测集大小替代熵来选查询，因为 LLM logits 不可靠 |
| 非平稳/分布漂移下的 conformal | Gibbs & Candès ACI (2106.00170)；**AdaptNC**, arXiv 2602.01629 | 占掉。AdaptNC 已经是机器人版，联合在线适配打分函数与阈值 |
| 代价敏感 conformal + 人在环拒答 | arXiv 2607.27143 | 占掉方法层（临床/表格域） |
| 个性化物体归属检索 benchmark | **PersONAL**, arXiv 2509.19843 | 占掉。HM3D/Habitat，2000+ episode，"找 Linda 的柜子"，含共享归属难度分层 |
| 长时序具身记忆 benchmark（物体会被移动） | **FindingDory**, ICLR 2026 (2506.15635) | 占掉。HSSD，脚本 agent 做 pick-and-place 改变场景，再考记忆 |
| 动态语义记忆 + 物体移动后重定位 | **DREAM**, arXiv 2606.00576 | 占掉工程层 |

**结论：结构三里 S3-A/B/D/E/F 的"方法机器"基本都有人造好了。你的原创不能是"我要用 conformal"，那已经是 2023 年的事了。**

### 1.2 查证发现的真实空白

**空白一：开放集 × 非平稳 的交集是空的。**

- CGT 明确假设 exchangeability，把"放松可交换性以处理分布漂移"列为 future work
- AdaptNC 处理了漂移，但**是闭集**，标签空间固定
- 你的场景**同时**违反两者：目标可能未建图（开放集）+ 用户习惯漂移（非平稳）

这不是我凑出来的组合，是两篇论文各自的 limitation 正好对上。

**空白二：C-IP 的动作是同质的。**

C-IP 里所有查询成本相同，选择准则是"最小化期望预测集大小"。你的动作集是异质的：问人 / 走过去 / 转头 / 开柜门，成本量纲完全不同（时间、移动、打扰、隐私）。C-IP 自己承认局限是"依赖充分且良定义的 query set"——异质物理动作正是这个假设的破口。

**空白三：数据依赖的停止时刻破坏 conformal 有效性。**

C-IP 是"边问边构造预测集，直到不再有信息就停"。但**停止时刻本身依赖数据**，这在统计上会破坏 split conformal 的边际覆盖保证。C-IP 只做了经验验证，没给形式保证。这是一个真实的、有分量的技术缺口。

**空白四：记忆持久性没有任何概率模型。**

- DREAM：ray-casting 确定性删除 + "temporal recency" 启发式
- LTC-Mapping / Probabilistic Object Maps：长期一致性，但不是条件化持久模型
- 没有人做**以人物活动和习惯阶段为条件的 hazard model**

**空白五：benchmark 的交集是空的。**

| | 人物归属 | 时序移动 | 多人 | 不确定性/拒答 |
|---|---|---|---|---|
| PersONAL | ✅ | ❌（作者列为 limitation） | 部分（共享归属） | ❌（作者列为 limitation） |
| FindingDory | ❌ | ✅ | ❌ | ❌ |
| **你的位置** | ✅ | ✅ | ✅ | ✅ |

两篇论文的 limitations 章节写的就是你结构三的核心。

## 2. 提议的新方法

### 2.1 CO-CIP：代价感知的开放集保形信息追踪

**Cost-Aware Open-Set Conformal Information Pursuit**

这是把 C-IP 往你的场景推广，三处改动都有明确动机。

**设定。** 候选集 $\mathcal{C} = \{c_1,\dots,c_n\} \cup \{\otimes\}$，其中 $\otimes$ 表示"目标未建图/未召回"（借 CGT 的 joker 语义）。动作集

$$\mathcal{A} = \{\texttt{ask}(q),\ \texttt{move}(v),\ \texttt{micro\_verify},\ \texttt{open}(k),\ \texttt{stop}\}$$

每个动作有标量成本 $\mathrm{cost}(a) > 0$（由 motion/time/interruption/privacy/safety 合成）。

**改动一：代价归一化的选择准则。**

C-IP 选 $q$ 最小化 $\mathbb{E}[\log|\Gamma_{1-\alpha}(h \cup q)|]$。推广为选 $a$ 最大化**单位成本的期望预测集对数收缩率**：

$$\rho(a) = \frac{\log|\Gamma_{1-\alpha}(h)| - \mathbb{E}_{y \sim p(y \mid a, h)}\big[\log|\Gamma_{1-\alpha}(h \cup (a,y))|\big]}{\mathrm{cost}(a)}$$

**为什么这个改动重要**：你原文档 §8 的 $V(a) = \lambda_I IG(a) - \sum \lambda_\bullet C_\bullet$ 需要把信息和成本放在同一量纲，而 $\lambda$ 无法原则性地定标。比值形式绕开了这个问题——只需要成本之间可比，不需要信息与成本可比。这直接解决了你 G4 那个"打扰成本怎么量化"的死结。

**改动二：$\otimes$ 进入停止规则。**

$$\text{resolve} \iff |\Gamma_{1-\alpha}| = 1 \ \wedge\ \otimes \notin \Gamma_{1-\alpha}$$
$$\text{abstain} \iff \otimes \in \Gamma_{1-\alpha} \ \wedge\ \max_a \rho(a) < \rho_{\min}$$

这替代掉你现在的三阈值启发式（`resolution_threshold` / `ambiguity_margin` / `unknown_threshold`），把三个手调参数换成一个 $\alpha$ 和一个 $\rho_{\min}$，且 $\alpha$ 有语义。

**改动三：anytime-valid 保证（技术核心）。**

因为停止时刻数据依赖，split conformal 的边际保证在停止时不成立。正确工具是 **e-process / confidence sequence**（anytime-valid inference）：构造对每个候选 $c$ 的 e-value $E_t(c)$，预测集取

$$\Gamma_t = \{c : E_t(c) < 1/\alpha\}$$

则由 Ville 不等式，**对任意停止时刻 $\tau$（包括数据依赖的）**，$\mathbb{P}(c^\star \notin \Gamma_\tau) \le \alpha$。

这一步是整篇论文的技术贡献：**C-IP 有算法没保证，CGT 有保证但不允许自适应停止，把 e-process 引进来同时拿到两者。** 而且 e-process 天然兼容非平稳（不需要 exchangeability），顺带解掉空白一。

> 风险提示：e-process 的构造需要对每个候选定义一个非负鞅或 e-变量，在你的多通道似然设定下怎么构造是需要动手推的，不是套公式。这是这条路线上最大的技术不确定性，也是它值钱的原因。

### 2.2 HCS：习惯条件化的生存似然

替代指数衰减。离散时间 hazard：

$$h(\tau \mid a_{1:\tau}, z, o, \ell) = \sigma\Big(\beta_0 + \beta_1^\top \varphi(\text{活动序列}) + \beta_2^\top \psi(\text{习惯阶段} z) + \beta_3^\top \xi(\text{物体类别}, \text{位置类型})\Big)$$

生存概率 $S(\Delta) = \prod_{\tau=1}^{\Delta}\big(1 - h(\tau\mid\cdot)\big)$，以对数似然比接入你现有的 `MemoryReliabilityProjector`：

$$\log \mathrm{LR}_{\text{transition}} = \log \frac{S(\Delta \mid \cdot)}{1 - S(\Delta \mid \cdot)}$$

**挂载点**：`src/cpswm/world_model/grounded_search/memory_reliability.py`，作为 `TRANSITION_SURVIVAL` 因子替换当前的固定似然比。

**可证伪断言**：模型中不含纯 $\Delta$ 主效应项时，仍应优于含 $\Delta$ 的指数衰减基线。若不成立，说明活动证据不足以解释物体移动，你 §10 的立场需要修正。这是一个诚实的、会给出信息的实验。

### 2.3 覆盖率导出的 unknown 质量

不给 $\otimes$ 拍似然，而是

$$P(\otimes \mid h) \propto \underbrace{\int_{\mathcal{X}_{\text{unobs}}} p(\text{target at } x)\,dx}_{\text{未观测体积}} + \underbrace{\sum_{x \in \mathcal{X}_{\text{obs}}} p_{\text{miss}}(x \mid \text{视角},d,\text{遮挡})}_{\text{已观测但漏检}}$$

**与 CGT 的关系**：CGT 从标签频率用 Good-Turing 估计 novel mass。你的是**从空间覆盖率**估计。这给了一个干净的对比论断：

> 在具身场景中，空间覆盖率是比 Good-Turing 频率更强的 novel-mass 估计器。

这是可直接实验验证的，且是 domain-specific 的贡献——审稿人会认可"你利用了 CGT 用不上的结构"。

## 3. 可以在别人基础上加功能的地方

这些不需要原创方法，是明确的增量，风险低、见效快。

| 基础工作 | 加什么 | 为什么合理 |
|---|---|---|
| **PersONAL** | 加时序：物体在 episode 之间被移动；加"谁最后动过它"的事件轨道；加 `unknown` 目标（查询的物体确实不在场景里）；加拒答评价指标 | 这四条**全部是 PersONAL 作者自己写的 limitations** |
| **FindingDory** | 加多人物归属标注；加不确定性/拒答任务；加"询问"动作 | 作者列的 future work 是"更强的干扰机制"和"操作类记忆任务"，人物维度是干净的正交扩展 |
| **C-IP** | 异质动作成本 + 开放集 + anytime-valid 停止 | 即 §2.1 |
| **CGT** | 从 exchangeable 放松到非平稳；从标签频率换成空间覆盖率 | 作者 future work 第一条就是"放松可交换性" |
| **AdaptNC** | 从闭集扩到开放集 | 它是机器人域的，接口最近 |
| **DREAM** | 把 ray-casting 确定性删除换成 HCS 概率持久 | 它的 recency 启发式是明显的薄弱环节 |

## 4. 起步顺序

### 第一步（2–4 周）：建 benchmark 交集

在 PersONAL 基础上扩，因为它的人物归属标注是最贵的部分，已经做好了。加：

1. **时序层**：借 FindingDory 的 rearrangement 机制，让物体在 episode 间移动，移动由"人物 + 活动"驱动而非随机
2. **unknown 层**：一部分查询的目标**确实不在**已建图区域（被拿走 / 在未探索房间 / 从未出现）
3. **风险层**：给物体标注误拿代价（药品 / 私人物品 / 普通物品）
4. **拒答评价**：risk-coverage 曲线、误拿率、不必要询问率

**产出**：这一步本身就是可投的（dataset/benchmark track 或 workshop），且是后面所有方法工作的地基。

**验证**：跑 PersONAL 原论文的两个基线（QS、RPG）在扩展集上，确认性能确实塌了——如果没塌，说明扩展没加到难点上，要重新设计。

### 第二步（4–8 周）：HCS 接入 + 消融

在扩展集上把 §2.2 接进 `memory_reliability.py`，对比：固定衰减 / 指数衰减 / 纯 recency（DREAM 式）/ HCS。指标：NLL、Brier、下游检索成功率。

**为什么放第二**：它不依赖 conformal，可以并行推进，而且是纯监督学习问题，风险最低。先拿到一个确定能出的结果。

### 第三步（8–16 周）：CO-CIP

先做无保证的版本（代价归一化 + 开放集，用 split conformal，接受停止时刻的有效性缺口），拿到经验数字。再攻 e-process 的形式保证。

**分岔点**：如果 e-process 构造推不动，退回到"经验有效性 + 明确声明缺口"，论文仍然成立（C-IP 就是这么做的），只是贡献从理论降为方法。这个退路要提前想好。

## 5. 诚实的风险清单

1. **e-process 构造是真难点**，不是工程问题。如果你没有测度论/鞅的基础，需要先补，或者找一个统计背景的合作者。这也是为什么第三步排在第三。
2. **PersONAL 扩展需要跑 Habitat**，有算力和工程成本。先确认你能跑通原 benchmark 再谈扩展。
3. **这个领域 6 个月翻一次**。上面的占位图是 2026-08 的快照，动手前和投稿前各查一次。
4. **本文档中"空白一到五"是基于检索的推断**，不等于穷尽。arXiv 上可能有我没检索到的近期工作，尤其是尚未被索引的。
