# 统一连续运行版本：执行范围与依赖

用户目标：来源明确、真实输入驱动、能连续修订并影响行动的统一运行版本。
Route C、Architecture A、P5_FIRST、A1+B1、完整 H/R/I/C/Z/r/V、三个 RB blocks、六提议操作及七算子全部保留。

## 可立即推进的工程

1. 单一候选源码：以真实 Unity/数据/联合消费者最新 A 分支为基线，独立审核 B 五边界修复；随后审查接入 W1 执行身份与 W2 比较工具。各分支既有矩阵不得相加签收，当前源码重跑。
2. 真实输入：把独立保留摘要所绑定的原始 RGB-D 转成已有 M05 ObservationEnvelope；仅方法侧像素、深度、身份和三时刻，隔离 evaluator metadata。单个适配成功不等于校准、检测或长期写入。
3. 运行状态：同一 run/session、不可变输入队列、逐步前缀、来源、模型工件、随机数、执行参数、唯一账本与输出；迟到证据引用原步并重算受影响后缀。
4. 消费连接：默认提议器完整 q → 粒子修订核 → 条件统计束 → 唯一账本授权 → 完整后验动作/CIAV → 环境回执 → 新到达证据。任一绑定缺失明确报告，不自动降级冒充完整运行。

## 必须落实的真实依赖

- 人物可见动作及对象持有/交接后端；当前 robot agent 不满足人物证据。保留 ProcTHOR 正式环境，人物资产许可、动作范围和观察证据需另做实测。
- RGB-D 感知到检测/实例关联/角色证据的合法转换和校准；Unity objects/segmentation IDs 不能充当模型已识别。
- 从真实主干历史导出六操作监督：保留当时解释、迟到反证、修订后缀和账本增减，不能按物理动作名字自动填写推断操作标签。
- 全轴神经模型：按已冻结三架构验证选择程序训练；现有原因/阶段 MLP 不是此模型。
- 连续物理状态、测量和实测噪声；当前公式未规定 theta 的物理语义，不能填常数使信息块非零。
- 已冻结规则之外的重采样/训练参数和预算等，必须由用户选择或合法冻结选择程序决定。

## 当前提出的选择（未因等待而视为批准）

1. 信息块 theta 绑定物体世界坐标三维位置，真实 RGB-D 及独立残差校准 R；替代是位置与速度/其他明示物理模型。位置与速度须采用相应时间/过程模型，不能直接共享同一个观测矩阵。
2. 沿已冻结三架构协议，允许拟定同等小规模本地开发配置，或先交具体网络/预算表；不选择单臂，不删全轴或六操作，不启动付费算力。

## 统一成功条件

- 一次同源、明确配置的真实运行中，合法可见输入自动产生非空全轴粒子，三个解析块由合法观测更新；无法观察时保持未知而非伪造数值。
- 同一连续历史含稳定/变化、多人交接、相似实例、未知人物和地点、负观测、迟到纠正、延期/取消/恢复；输入、状态、账本、实际动作和反馈相互可追溯。
- 迟到证据真实撤回/替换既有贡献；保留未受影响历史；局部修订与全重放不等价时执行全重放。
- 有保持同输入的合法对照、完整伪造路径、状态机/中断和实际行动后果，既有科学指标/先验/预算不为过门而改变。
- B 在最终候选 SHA 独立复核后才申请共享集成；开发成功和科学收益保持分离。

本文件是执行依赖清单，不是上述链条已运行的回执。

## 可审查的本地开发配置草案（未执行、未冻结）

目标是把模型和真实主干接通；不能用此草案直接产生正式比较/确认结论。

| 项 | 三臂共同约束 | 各架构实现差异 |
|---|---|---|
| 可见输入 | 同一到达前缀、过去动作、合法类型支持和上一步快照；不挂载真值目录 | 因子图 tokens / Perceiver typed slots / 自回归字段序列 |
| 输出 | 六操作、完整 H/R/I/C/Z/r/V、父子谱系和完整条件 log-q；保留 unknown/unresolved | 仅网络内部计算不同 |
| 开发规模 | hidden width 64、2 层、4 heads；每臂只试同一个配置；不宣称参数量相等 | Perceiver 16 latent slots；其余使用相同 token 上限 |
| 序列/样本 | batch 8、可见上下文至多 32 个 token；更长真实历史仍由持久状态保留，不能截断事件语义 | token 化过程需逐轴覆盖测试；完整事件链超预算时显式拒绝并统计，不能截标签 |
| 资源上限 | 本地 CPU 2 threads；3 个仅训练用 seed；每 seed 最多 5 分钟、最多 1500 optimizer steps；先到即停 | 实际步数/参数量/内存/耗时逐臂报告；不把等时长说成等算力 |
| 训练资格 | 必须先具有合法真实监督、六操作覆盖、来源/分区/时间边界和真实模型接口 | 当前未满足，不能启动训练 |
| 选择 | 沿现有 validation NLL / arm-order tie-break，确认标签隐藏；缺少最低独立单元时不签选择回执 | 任一架构缺实现/缺训练不能宣布另两臂胜出 |

以上是供用户审阅的工程开发预算，不改变正式协议的候选数、粒子数、阈值和计算预算；最终网络/预算要在批准后登记实际配置。若该 token 上限无法保留全链，必须扩展预算或采用合法分层编码，不能为了开发规模删框架。
