## 0. 结论先行

截至 2026-08-13，在本轮检索的来源与查询范围内，可以确认：

1. **方向并未因为已有项目而失去推进价值。** 现有工作已经分别覆盖机会式观察、动态物体地图、部分可观测位置预测、家庭迁移规律、持续学习、人物日常规律、人—物事件图、个性化记忆利用和具身决策。
2. **没有发现一个已核验系统同时把四项困难作为同一个在线学习问题完整解决：** 选择性且非随机缺失的观察、未被直接看到的人—物事件、同一家庭内多人物软归因、可渐变/突变/回归的个体习惯。
3. **最危险的既有对手是组合基线，不是单篇论文。** 最强组合可以写成：

```text
O-STaR 的机会式观察与位置概率
+ GESTO/EGG 的事件图
+ HUMEMBR 的跨日人物身份记忆
+ STREAK 的持续学习
+ WorldLines/ObsMem 的观察—状态—信念分离
+ DynaMem/POCD 的地图更新与负证据
```

4. 因此可辩护的创新目标不是声称“首次学习习惯”或“首次长期记忆”，而是提出新的 observation-process-aware（观察过程感知）、actor-conditioned（人物条件化）、event-latent（隐藏事件驱动）、regime-aware（阶段感知）联合方法，并在相同预算下超过上述组合。
5. 现有公开基准仍存在一个重要空白：很少同时提供**同屋多人、完整事件真值、机器人选择性观察日志、习惯变化阶段和下游行动代价**。数据与评价协议本身也可能形成成果。

这里的“没有发现”严格限定于本文记录的日期、来源和查询，不能写成全球绝对不存在，也不能直接写成“首次”。

## 3. 第一圈：直接最近邻系统

### 3.1 O-STaR：机会式观察与家庭迁移模式

来源：[官方项目页](https://www.hrl.uni-bonn.de/publications/2026/menon26grc)、[官方论文/海报 PDF](https://www.hrl.uni-bonn.de/publications/2026/menon26grc/menon26grc_paper_poster.pdf/%40%40download/file)  
证据：**full text checked（全文核验）**

实际实现：

- 以房间、家具、隔间和动态物体组成 open-vocabulary 3D dynamic scene graph（开放词汇三维动态场景图）；
- Day-0 用 LLM 生成常识位置先验，再用家具几何和容器尺寸删除不可行候选；
- 用 Dirichlet–Categorical（狄利克雷—类别）分布维护物体在家具/隔间中的位置概率；
- 用 Stay+Leak 时间扩散和观测更新适应稀疏重访之间的变化；
- 搜索目标物体时进行 opportunistic multi-target perception（机会式多目标感知），同时更新其他物体；
- 根据位置概率和访问成本排序搜索动作；
- 以 60 天家庭仿真和 Stretch 物理实验评价个性化物体搜索。

与方向二重合：选择性/顺带观察、稀疏跨时观测、个性化位置概率、搜索决策。

尚未统一解决：同一家庭中具体人物的行为者后验、拿取/交接/放置隐藏链、当前状态与长期个体习惯的严格分离、习惯渐变/突变/旧阶段返回、客人污染和多任务效用。

基线地位：**首要单系统基线**。不能再把“首次顺带观察非目标物体并更新家庭位置规律”作为贡献。

### 3.2 Scene Graph Memory / NEP：部分可观测动态图链接预测

来源：[ICML 2023 PMLR](https://proceedings.mlr.press/v202/kurenkov23a.html)、[项目页](https://www.scenegraphmemory.com/)  
证据：**official page + method checked（官方页及方法核验）**

实际实现：

- 把房间、家具和物体建模为随时间变化的图；
- 用 Scene Graph Memory（场景图记忆）累计机器人实际看到的局部子图；
- 提出 Node Edge Predictor（节点边预测器，NEP），从不完整记忆预测查询物体与位置节点之间的边；
- 输出 observation-conditioned posterior（观测条件后验），用于选择下一搜索动作；
- Dynamic House Simulator 从类别位置先验和实例扰动生成多种动态家庭。

尚缺：观测路径本身为何缺失、人物身份/事件、个体习惯参数和非平稳阶段。

### 3.3 Learning Object-Based State Estimators：长期物体状态滤波

来源：[arXiv:2011.03183](https://arxiv.org/abs/2011.03183)、[项目页](https://yilundu.github.io/obm/)  
证据：**full text checked（全文核验）**

实际实现：

- 将经典 data-association filtering（数据关联滤波）与 attention neural networks（注意力神经网络）结合；
- 从带标注的观察轨迹端到端学习 transition model（转移模型）和 observation model（观测模型）；
- 在高维观测与多个物体假设上维护长期状态估计；
- 在模拟和真实图像上评价动态物体记忆。

尚缺：人、活动、习惯、非平稳阶段和主动决策，但它是“联合学习观察模型与转移模型”的重要先例。

### 3.4 HOMER / STOT：跨日家庭物体迁移生成模型

来源：[PMLR](https://proceedings.mlr.press/v205/patel23a.html)、[arXiv:2211.15501](https://arxiv.org/abs/2211.15501)  
证据：**full text checked（全文核验）**

实际实现：

- 用 temporal object arrangement graphs（时间物体布置图）表示物体—位置关系；
- 用 generative GNN（生成式图神经网络）学习统一的时空物体动态；
- 预测未来物体是否移动以及移动到哪里，并据此主动调整环境；
- 发布 HOMER：5 个模拟家庭、50+ 天日常活动与物体移动数据；
- 相对先前基线，正确位置预测增加 11.1%，错误位置预测减少 11.5%。

尚缺：真实选择性观察、多人物归因、事件链和习惯阶段；数据更接近完整状态序列。

### 3.5 SLaTe-PRO：活动条件化的物体使用预测与主动询问

来源：[arXiv:2309.06252](https://arxiv.org/abs/2309.06252)、[PMLR](https://proceedings.mlr.press/v229/patel23a.html)  
证据：**full text checked（全文核验）**

实际实现：

- Sequential Latent Temporal model（顺序潜变量时间模型）把当前物体图、历史状态和用户活动编码进循环潜空间；
- 从潜空间 rollout（滚动预测）物体使用和位置变化；
- 发现低一致性活动难以预测后，以 information-gain threshold（信息增益阈值）决定是否询问活动或物体意图；
- 在 3 个 HOMER 家庭、24 类活动上，F1 从先前 0.43 提升到 0.52；加入活动识别为 0.57，加入有限查询为 0.60；
- 在 Stretch 机器人晨间协助案例中演示预测、失败和询问纠正。

尚缺：同屋多人物、隐藏交接、选择性观测偏差和长期习惯阶段；活动标签在实验中常由 oracle 或受控可用率提供。

### 3.6 STREAK：家庭上下文漂移下的持续物体迁移学习

来源：[arXiv:2411.05549](https://arxiv.org/abs/2411.05549)  
证据：**full text checked（全文核验）**

实际实现：

- 将每个家庭的时序图变化写成 Spatio-Temporal Streaming Neural Network（时空流式神经网络）的图增量；
- 以节点分类、位置边分类和情境嵌入损失学习物体迁移；
- 用 Fisher information（费舍尔信息）加权参数偏移惩罚，抑制灾难性遗忘；
- 用 Mean Feature Criteria（平均特征准则）选择 rehearsal buffer（回放缓冲区）样本，并随会话控制旧数据量；
- 在 HOMER 的 5 个家庭上顺序训练，每个家庭 50 天训练、10 天测试；
- 评价旧知识保持、新任务迁移预测、时间和内存效率。

关键边界：论文明确说明数据**不含同一家庭内多用户**，而是把不同家庭依次视为不同用户。因此它解决的是跨家庭/用户的顺序上下文漂移，不是同屋多人同时干扰和行为者归因。

### 3.7 GESTO：持久 4D 场景中的人—物活动层次

来源：[arXiv:2608.10886](https://arxiv.org/abs/2608.10886)  
证据：**full public text checked（公开全文核验）**；v1 提交于 2026-08-11，尚应视为新近预印本

实际实现：

- 在 persistent 4D scene graph（持久四维场景图）上加入两层活动表示；
- 细粒度层存储带时间戳的 atomic human–object interactions（原子人—物交互），如“冲洗杯子”；
- 高层把相关交互分组为 goal-driven events（目标驱动事件），如“准备咖啡”；
- 从 RGB-D 观察流自动切分短片、抽取交互、关联持久物体、聚合事件；
- 利用事件上下文重新修正不确定的物体关联；
- 用 relation-aware tool-calling agent（关系感知工具调用代理）在物体、地点、交互和事件之间查询；
- 在既有 EGG 类别和新增 Space2Event / Event2Space 问题上评价回顾式推理。

与方向二重合：人物—物体—地点—事件的持久化连接，事件层次和不确定物体关联修正。

尚缺：没有以未观测转移的概率后验为中心；没有学习同屋不同人物的摆放分布、抗污染巩固和习惯阶段；主要下游是 retrospective QA（回顾式问答），不是长期习惯驱动的具身决策。

基线地位：**隐藏事件/活动表示的首要强基线**。

### 3.8 HUMEMBR：跨日人物身份与规律预测

来源：[arXiv:2606.30404](https://arxiv.org/abs/2606.30404)  
证据：**full text checked（全文核验）**

实际实现：

- 在真实办公室以 Spot 机器人连续构建人物中心记忆；
- 对图像做相似度过滤、VLM captioning（视觉语言模型描述）和稠密向量存储；
- 以人脸 anchor（锚点）、body re-identification（身体重识别）、在线聚类维持跨日人物身份；
- 提供按语义、位置、日期、人物历史和每日人物摘要检索的函数；
- LLM 通过函数调用回答 PersonEQA，并把预测的人物日常位置用于 routine-conditioned navigation（规律条件导航）；
- 真实数据覆盖多日、多人物和不同拥挤程度环境。

与方向二重合：跨日具体人物、稀疏机器人观察、长期规律、预测式导航。

尚缺：主要预测“某个人何时/在哪里”，未联合推断“谁移动了哪个具体物体”、隐藏交接和人物条件化摆放习惯；记忆更偏描述检索而非校准的生成式事件后验。

### 3.9 WorldLines / ObsMem：观察、状态、信念与计划的长期分离

来源：[arXiv:2606.18847](https://arxiv.org/abs/2606.18847)  
证据：**full text checked（全文核验）**

实际实现：

- 构造跨多日的 project-driven household traces（项目驱动家庭轨迹），包含对话、动作、执行反馈和物体/设备状态改变；
- 从同一轨迹生成 evidence-linked Memory QA（证据连接记忆问答）和 Embodied Task Planning（具身任务规划）样本；
- ObsMem 保存 typed memory views（类型化记忆视图）：事件、状态、信念、承诺和证据；
- 维护 action-native state trails（行动原生状态轨迹）和 visibility-aware（可见性感知）状态；
- 根据后续事件、行为者、矛盾和新鲜度把信念标记为 fresh / stale / uncertain / contradicted；
- 评价部分可观测、状态覆盖和长期记忆向计划转化。

与方向二重合：选择性可见、历史证据、当前状态、信念和具身计划分离。

尚缺：习惯状态更接近结构化规则/检索，不是从多人不完整观察在线估计的个体概率规律；公开设置以合成轨迹和确定性执行器为主。

### 3.10 UcON：显式用户习惯驱动的物体导航

来源：[arXiv:2602.06459](https://arxiv.org/abs/2602.06459)、[代码库](https://github.com/whcpumpkin/User-Centric-Object-Navigation)  
证据：**full text checked（全文核验）**

实际实现：

- 构造约 22,600 条自然语言用户习惯，覆盖 489 个物体类别；
- 用 GPT-4 生成候选位置/习惯并进行物理和语义校验，形成 habit-shaped scenes（习惯塑造场景）；
- 每个回合向代理提供包含 300+ 条习惯的知识库；
- Habit Retrieval Module（习惯检索模块）依据目标物体和已知场景检索相关习惯，减少长上下文干扰；
- 在模拟和 3 个真实环境的 Unitree GO2 上评价 Success Rate 和 SPL。

关键边界：它研究 **habit utilization（习惯利用）**，不是机器人如何从选择性长期观察中 acquisition/update（获取/更新）习惯；习惯作为预先提供的自然语言知识，不含多人行为者后验和非平稳阶段。

### 3.11 PerSim：何时值得个性化的刚性门控搜索

来源：[arXiv:2607.00022](https://arxiv.org/abs/2607.00022)  
证据：**full text checked（全文核验）**

实际实现：

- 用 placement rigidity（摆放刚性）把物体划分为稳定、适中和个体敏感区间；
- 将 continuous Big Five（连续大五人格）注入预测器，输出 room prior（房间先验）和 within-room co-occurrence cue（房内共现线索）；
- 用人类 anchor 约束生成模型，在 OmniGibson 数字孪生中合成摆放转移；
- 通过 N=200 人类研究验证合成转移 plausibility（合理性）和不同刚性下个性化偏好；
- rigidity gate（刚性门）在人口频率先验与人格条件先验之间混合；
- 以 ERV、CP@5 和 Expected Search Cost（期望搜索成本）评价两阶段搜索。

与方向二重合：不同移动性物体不应同等个性化、个体先验必须改善搜索成本。

尚缺：没有从某个真实住户的长期被动观察在线学习；刚性和人格主要来自外部/合成校准，不含多人事件和阶段变化。

### 3.12 HERMES：习惯、情景和用户偏好的时序场景图检索

来源：[OpenReview PDF](https://openreview.net/attachment?id=IkUhq9v0JX&name=pdf)  
证据：**full text checked（索引全文核验）**

实际实现：

- 用两层 temporal scene graph memory（时序场景图记忆）保存各时刻场景图，并用 Event 边连接物体移动、容器状态变化和用户纠正；
- 在时序结构之上维护 PreferenceNode（偏好节点），保存目标实体、偏好/习惯内容、情境、时间状态和支持证据；
- 偏好与习惯通过对话中的语言注册工具写入，而不是从长期选择性视觉观察中概率学习；
- 在 TEACh 轨迹上注入用户偏好和更新，构造 5–25 episode 的合成历史；
- 评价 preference QA（偏好问答）、command resolution（指令消歧）和 temporal update reasoning（时间更新推理），并与 flat-context（平铺上下文）基线比较；
- 主要优势是严格偏好检索准确率、token 和延迟效率；作者明确把真实噪声观察、显式状态版本、recency-aware conflict resolution（近因感知冲突消解）和稳定习惯巩固列为未来工作。

与方向二重合：时序场景状态、事件边、用户习惯/偏好节点、来源链接和长期查询。

关键边界：它没有建模 MNAR 观察产生过程、同屋多人物行为者后验、未观测事件候选或从被动观察中学习非平稳个体习惯；也没有用搜索、放回、递送等物理行动效用验证习惯信念。因此，“时序场景图 + 习惯节点 + 检索”本身不能作为方向二的新颖性表述，但应成为查询/指令任务的直接强基线。

## 4. 第二圈：动态地图、事件记忆与长期检索

### 4.1 POCD：概率物体级变化检测

来源：[arXiv:2205.01202](https://arxiv.org/abs/2205.01202)  
证据：**full text checked（全文核验）**

实现要点：为每个物体联合维护 stationarity score（稳定性分数）和 TSDF 几何变化量，以融合语义和几何的 Bayesian update（贝叶斯更新）判断物体是否移动，并在线更新半静态体素地图。

方向二借鉴：对象稳定性、概率变化和地图维护。  
边界：状态是“变没变”，不是“谁在什么习惯阶段为什么移动”。

### 4.2 DynaMem：在线动态开放词汇三维记忆

来源：[arXiv:2411.04999](https://arxiv.org/abs/2411.04999)、[项目页](https://dynamem.github.io/)  
证据：**full text checked（全文核验）**

实现要点：

- 稀疏 voxel map（体素图）保存位置、观测计数、来源图像、CLIP/SigLIP 特征和最近观测时间；
- RGB-D 点经 SAM2 分割和 VLM 特征回投后加入体素；
- 用 ray casting（射线投射）删除在当前可见视锥内却不再存在的旧体素；
- 文本查询先检索语义体素/最近图像，再以开放词汇检测或多模态 LLM 确认，也可 abstain（拒答）；
- 以“最久未看”和“语义相关性”价值图引导探索；
- 闭环导航过程中反复扫描、更新地图和重规划；
- Stretch 动态环境实验中总体任务成功率 70%，静态 OK-Robot 对照为 30%。

边界：重点是最新三维状态与移动操作，不学习人物习惯或隐藏事件因果。

### 4.3 Where Did I Leave My Glasses?：物体稳定性驱动的主动地图维护

来源：[arXiv:2509.19851](https://arxiv.org/abs/2509.19851)；IEEE RA-L 2026  
证据：**full text checked（全文核验）**

实现要点：

- 对开放词汇物体实例维护 probabilistic stationarity（概率稳定性）；
- 系统跟踪移动、移除和重新出现的物体以及 missing-object library（缺失物体库）；
- 主动地图维护优先重访长时间未看且可能过时的区域；
- 物体目标导航时用 LLM 语义推理生成上下文相关区域优先级；
- MPC（模型预测控制）执行安全目标导向探索；
- 三个真实环境平均检测 95% 地图变化，相对随机/巡逻提高 29% 以上效率，物体导航比次优策略快约 14%。

边界：学习的是实例稳定性与地图新鲜度，不是人物条件化摆放习惯；也是方向二“移动性画像→观察策略”的强参考。

### 4.4 DovSG：长期移动操作的动态开放词汇场景图

来源：[arXiv:2410.11989](https://arxiv.org/abs/2410.11989)  
证据：**abstract only（仅摘要）**

实现要点：从 RGB-D 和 VLM 检测构建动态开放词汇三维场景图；在交互后局部增删/更新图节点，避免全场景重建，并服务长期语言指导移动操作。

边界：更偏地图数据结构和操作后的图同步，不做人物习惯和隐藏事件后验。

### 4.5 EGG：事件—空间实体连接

来源：[arXiv:2510.18697](https://arxiv.org/abs/2510.18697)、[代码](https://github.com/aalto-intelligent-robotics/EGG)  
证据：**official abstract + code metadata checked（官方摘要及代码元数据核验）**

实现要点：Event-Grounding Graph（事件落地图）把事件交互连接到场景中的持久空间特征，例如把“洗杯子”事件连接到具体蓝色杯子，并支持时空查询。

边界：需要/依赖外部事件边界和物体对应的程度高于 GESTO；不负责长期个体习惯和非平稳更新。

### 4.6 DAAAM：大规模实时 4D 场景图

来源：[CVPR 2026](https://openaccess.thecvf.com/content/CVPR2026/html/Gorlo_Describe_Anything_Anywhere_At_Any_Moment_CVPR_2026_paper.html)、[arXiv:2512.00565](https://arxiv.org/abs/2512.00565)  
证据：**official page + method checked（官方页及方法核验）**

实现要点：通过优化式前端批处理 localized captioning（局部描述），把丰富开放词汇语义一次性落到几何对象上；构建空间和时间一致的分层 4D 场景图；工具调用代理完成时空问答和顺序任务落地。

边界：对象/观测中心的 4D 记忆，不直接描述活动、行为者习惯和未观察事件。

### 4.7 ReMEmbR：检索增强长时空记忆

来源：[arXiv:2409.13682](https://arxiv.org/abs/2409.13682)、[项目页](https://nvidia-ai-iot.github.io/remembr)  
证据：**full text checked（全文核验）**

实现要点：按固定短窗口从长视频生成 VLM 描述，连同位置、时间和文本向量写入数据库；LLM agent 以位置、时间和语义三类函数迭代检索，输出文本、时间或可导航坐标；NaVQA 含 7 段长视频和 210 个问题。

边界：检索观察记录，不学习习惯分布或事件转移模型；但其多步检索和可导航输出适合方向二的查询层基线。

### 4.8 Enter the Mind Palace：记忆检索与主动探索

来源：[CoRL 2025 PMLR](https://proceedings.mlr.press/v305/ginting25a.html)  
证据：**official paper page + method checked（官方论文页及方法核验）**

实现要点：把情景经验编码为 scene-graph world instances（场景图世界实例）；在过去记忆检索、当前主动探索和回答之间规划；用 value of information（信息价值）停止准则判断何时信息足够。

边界：中心任务是长时主动具身问答，不学习多人对象习惯；对方向二的观察/询问/停止策略有直接方法价值。

### 4.9 STAR：时间检索与空间行动统一

来源：[arXiv:2511.14004](https://arxiv.org/abs/2511.14004)、[项目页](https://amrl.cs.utexas.edu/STAR/)  
证据：**official page + method checked（官方页及方法核验）**

实现要点：非参数 long-term memory（长期记忆）与 working memory（工作记忆）并用；VLM 在每一步选择 temporal action（检索过去）或 spatial action（现场搜索）；STARBench 覆盖可见、交互、常识和时空对象检索，并在 Tiago 机器人上验证。

边界：检索/行动闭环强，但没有从多人长期行为中学习习惯参数。

### 4.10 Worth Remembering：贝叶斯惊讶门控情景记忆

来源：[arXiv:2606.03787](https://arxiv.org/abs/2606.03787)  
证据：**full text checked（全文核验）**

实现要点：

- 用 V-JEPA-2 对连续 64 帧窗口编码；
- 在潜空间滑动窗口拟合对角高斯，用标准化预测误差近似 Bayesian surprise（贝叶斯惊讶）；
- 以 median + MAD（中位数加绝对中位差）阈值和非极大值抑制选出事件峰值；
- 每个峰值保存短视觉片段、时间、位姿、惊讶分数和检索向量；
- 将情景层附加到 DAAAM 4D 场景图；平均仅存 1.7% 帧，却在 OC-NaVQA 提高问答准确率并降低时空误差。

边界：选择的是“哪些已看到的片段要记住”，不是“机器人为什么没看到”；惊讶也未与人物习惯污染和变化阶段联合。

### 4.11 Forgetting in Robotic Episodic Long-Term Memory：在线/离线遗忘

来源：[KIT 元数据](https://publikationen.bibliothek.kit.edu/1000174346)、[公开 PDF](https://h2t.iar.kit.edu/pdf/Plewnia2024.pdf)  
证据：**full text checked（全文核验）**

实现要点：ARMAR 机器人将工作记忆快照向长期记忆巩固；在线快速过滤与离线慢速删除结合；比较相似度、年龄、巩固频率和时间衰减；组合机制在保持历史物体位置搜索能力的同时减少存储。

边界：解决存储选择和遗忘，不估计个体习惯变化；但提醒方向二必须区分“真实习惯衰退”和“存储策略造成的证据消失”。

## 5. 第三圈：个性化记忆、偏好、常识和整理

### 5.1 MEMENTO：个性化记忆利用评测

来源：[arXiv:2505.16348](https://arxiv.org/abs/2505.16348)、[项目页](https://connoriginal.github.io/MEMENTO)  
证据：**full text checked（全文核验）**

实现要点：把评测分为 Memory Acquisition（记忆获取）和 Memory Utilization（记忆利用）两阶段；前期任务中积累个性化知识，后期用隐含表达要求代理识别个人物体语义或用户布置模式；分别测试单记忆、联合记忆和检索质量。即使 GPT-4o 在需要多条记忆时也出现明显性能下降。

边界：个性化知识通过任务交互显式进入记忆；不解决长期被动观察、多人归因和概率习惯变化。适合作为“记忆是否真正被用到”的评测设计参考。

### 5.2 POLAR：长期交互的多模态个性化知识图

来源：[arXiv:2605.26256](https://arxiv.org/abs/2605.26256)  
证据：**full public text checked（公开全文核验）**

实现要点：把长期交互组织为 object-centric multimodal knowledge graph（物体中心多模态知识图）；semantic memory（语义记忆）保存个性化语境和视觉概念，episodic memory（情景记忆）保存轨迹和具身经历；当前任务检索相关记忆解释隐含指令，并进行多跳推理和更新跟踪。

边界：核心是历史交互的组织和利用，不是从选择性观察中学习带行为者后验的物体习惯。

### 5.3 TidyBot：少样本个性化收纳偏好

来源：[arXiv:2305.05658](https://arxiv.org/abs/2305.05658)、[项目页](https://tidybot.cs.princeton.edu/)  
证据：**official abstract + project checked（官方摘要及项目页核验）**

实现要点：从一个用户的少量“物体→收纳位置”示例出发，让 LLM 归纳可泛化的语言规则；结合开放词汇感知、抓取、导航和放置；未见物体基准准确率 91.2%，真实整理成功率 85%。

边界：示例表达 preference（偏好），不是长期被动观察到的行为习惯；没有多人、隐藏事件、非平稳阶段和证据污染。

### 5.4 Housekeep：人类整理常识分布

来源：[arXiv:2205.10712](https://arxiv.org/abs/2205.10712)

实现要点：收集 1,799 个物体、268 类、585 种摆放和 105 个房间的人类 tidy-placement preferences（整洁摆放偏好）；模块化代理组合规划、探索、导航和微调 LLM 常识规划，在未知环境整理未见物体。

边界：人口级“应该放哪”，不是某位住户长期“实际放哪”。

### 5.5 TIDEE：视觉—语义常识整理

来源：[arXiv:2207.10761](https://arxiv.org/abs/2207.10761)、[项目页](https://tidee-agent.github.io/)  
证据：**official abstract + project checked（官方摘要及项目页核验）**

实现要点：三个模块依次完成 visuo-semantic out-of-place detection（视觉语义错位检测）、associative neural graph memory（关联神经图记忆）推断合适承载物/表面、visual search network（视觉搜索网络）寻找该承载物；在未见过的 AI2-THOR 房间从像素和深度直接整理。

边界：依靠训练房屋的通用常识，不学习当前家庭的长期个体模式。

### 5.6 LLM-enhanced Scene Graph / AEG：功能与多有效位置

来源：[ACM TOG 2026](https://doi.org/10.1145/3795693)、[arXiv:2408.12093](https://arxiv.org/abs/2408.12093)  
证据：**full public HTML checked（公开正文核验）**

实现要点：从 RGB-D 重建 vanilla scene graph（基础场景图）；LLM 将承载物节点增强为 Affordance Enhanced Graph（可供性增强图），加入由场景诱导的功能属性和非局部关系；多模态模型结合 AEG 与关键帧检测错放物体、选择目标位置并规划执行；新基准允许每个物体有带排名的多个有效位置。

边界：从当前场景推断 functionality + preference alignment（功能与偏好对齐），不是跨天观察到的具体人物习惯。

### 5.7 Interpretable Constructs：可解释的人类整理偏好

### 5.8 Interactive Continual Learning Architecture：用户教学的长期个性化

来源：[arXiv:2403.03462](https://arxiv.org/abs/2403.03462)  
证据：**full text checked（全文核验）**

实现要点：把 interactive machine learning（交互式机器学习）、conceptual spaces（概念空间）、短期/长期记忆、巩固与淡化连接起来；由用户逐步教机器人新物体和上下文；在物理移动操作机器人上进行两个月、20 个物体和两个上下文的取物评测。

边界：知识主要由用户显式教学，不是机器人从被动稀疏观察中推断习惯；但其长期人机纠正和知识巩固机制可复用。

### 5.9 Household Robot Utilizing Location Information：位置感知活动与习惯计划识别

来源：[Robotics and Autonomous Systems 2026](https://doi.org/10.1016/j.robot.2026.105369)、[NTU 元数据](https://scholars.lib.ntu.edu.tw/entities/publication/67dfb3a1-1e9c-41fc-a0db-7dbf1184fe09)  
证据：**official publisher method preview checked（出版社方法预览核验）**

实现要点：融合 ResNet50-Places365 场景分类与“人物—附近物体距离”位置估计；将位置概率和 3D skeleton（骨架）输入 Activity-Location GCN；用可更新 plan library（计划库）、Loc-NextAct Tensor 和 Loc-Objective Tensor 学习用户历史，预测下一活动、目标和计划；部署到自制移动机器人。

边界：学习的是活动/计划习惯，不是具体物体摆放和未观测移动；多人身份、选择性缺失和阶段变化并非中心。

## 6. 数据集和评价资源的可用性

| 数据/基准 | 提供的主要内容 | 能否直接支撑方向二完整问题 |
|---|---|---|
| HOMER | 5 个模拟家庭、50/60 天物体与活动序列 | 部分；缺同屋多人和真实选择性观测 |
| Dynamic House Simulator | 多家庭动态场景图、局部观察和对象搜索 | 部分；缺人物、事件和阶段标签 |

| WorldLines | 多日对话、行动、状态、可见性、QA 与规划 | 强部分支持；人物/习惯生成仍偏合成和规则化 |
| PersonEQA / HUMEMBR | 真实跨日、多人物、地点和日常规律 | 支持人物规律，不含完整物体摆放事件真值 |
| EGG / GESTO query set | 人—物事件与时空查询 | 支持事件表示，不含非平稳个体习惯评测 |
| STARBench | 动态开放世界时空对象搜索 | 支持记忆—行动，不含习惯学习阶段 |
| NaVQA / OC-NaVQA | 长视频的时空问答与位置/时间输出 | 支持长期检索，不含家庭习惯真值 |
| POCD / semi-static real scenes | 物体变化与几何地图真值 | 支持状态变化，不含行为者和习惯 |

由此得出的数据结论：不能把上述任一数据集直接当成方向二的完整 benchmark。更现实的做法是在 M29/M30 的可控轨中形成全真值，再把 HUMEMBR、GESTO/EGG、DynaMem/POCD 一类真实感知日志转成部分标注的外部有效性轨。

## 8. 可吸收的技术积木与不可直接继承的假设

| 可吸收积木 | 来源 | 需要改造的地方 |
|---|---|---|
| 动态场景图 + 语义/几何候选 | O-STaR、DAAAM、DovSG | 加入人物、事件、阶段和证据版本 |
| Dirichlet 位置基线 | O-STaR | 分离当前状态与长期习惯，人物软门控 |
| 观察条件后验 | Scene Graph Memory | 显式建模 MNAR 观察策略和可见性 |
| 转移/观测模型联合学习 | Object-Based State Estimators | 扩展到行为者和事件链 |
| 概率稳定性与负证据 | POCD、Where Did I Leave My Glasses? | 从“物体变了”扩展到“谁/为何/是否成习惯” |
| 稀疏动态语义地图 | DynaMem | 防止地图更新直接污染习惯统计 |
| 时空生成 GNN | HOMER | 用不完整观察和人物/活动后验训练 |
| 循环潜变量 + 主动询问 | SLaTe-PRO | 询问具体人物/事件/偏好，纳入打扰成本 |
| Fisher 正则 + rehearsal | STREAK | 改成同屋多人和阶段复用，而非只跨家庭任务 |
| 分层人—物事件图 | GESTO | 加入未观测事件概率、因果候选和习惯参数 |
| 跨日人物重识别与检索 | HUMEMBR | 与具体物体实例和交接事件联合 |
| 观察/状态/信念分离 | WorldLines | 从规则标签升级为学习式、可校准后验 |
| 个性化记忆获取—利用评测 | MEMENTO | 加入被动观察、多人物和非平稳轨迹 |
| 刚性门控个性化 | PerSim | 在线学习实例移动性和人物条件，而非固定人格先验 |
| 信息价值停止 | Mind Palace、SLaTe-PRO | 融合主任务、隐私和长期习惯价值 |
| 惊讶门控记忆 | Worth Remembering | 区分视觉新奇、事件价值和习惯证据价值 |

不可直接继承的常见假设：

- 把没检测到物体当作它不在；
- 把两次快照差直接当作某人的移动事件；
- 把家庭等同于单一用户；
- 把当前状态频率等同于长期习惯；
- 把用户实际行为等同于用户希望机器人采取的规范；
- 把不同家庭顺序学习等同于同一家庭多人并发；
- 把完整真值图序列等同于机器人的真实长期观察；
- 只用离线预测指标证明机器人决策改善。

## 10. 方向二最可辩护的新方法空间

结合上述紧邻工作，当前最有辨识度但仍需实验证明的方法空间是：

### 10.1 观察过程感知，而不只是可见性标签

现有方法常把 visibility（可见性）作为输入或规则。方向二可以进一步学习/显式推断 observation process（观察产生过程）：机器人任务、路径和过去信念怎样共同决定训练数据，从而纠正自选择偏差。

### 10.2 事件、人物和习惯的联合后验，而不只是串联模块

GESTO 擅长事件层次，HUMEMBR 擅长人物身份，O-STaR 擅长位置概率，STREAK 擅长持续学习。新的方法机会在于这些变量之间的反馈：人物后验影响习惯更新，习惯先验帮助隐藏事件归因，事件连续性帮助实例关联，而观察似然控制负证据。

### 10.3 抗污染巩固，而不只是更强预测器

访客、家庭成员、重复帧、相似实例和机器人自身操作是不同污染源。可以提出带隔离区、软人物门控、独立证据检验和可撤销派生状态的巩固算法，以 owner contamination（主人模型污染）为核心指标。

### 10.4 具有历史版本和复现能力的非平稳习惯

STREAK 主要保留跨任务知识，普通变化点模型主要检测新阶段。方向二可以维护“当前阶段 + 候选新阶段 + 历史阶段库”，支持季节/工作安排恢复时快速重新激活旧规律。

### 10.5 多下游共用、可归因的信念效用

UcON/O-STaR 证明搜索价值，HOMER/SLaTe-PRO 证明主动协助价值，WorldLines/MEMENTO 证明记忆利用价值。方向二可用一个共同信念在至少两类任务上评价，并记录每个决策使用的证据和后验，形成比单任务增益更强的科学论证。

### 10.6 “已有组件”仍然可以是方法创新对象

本节的覆盖判断不能解释为“别人用过事件图、BOCPD、GNN、Dirichlet 或持续学习，所以本项目不能再研究它们”。正确边界是：**组件名和普通拼接不是贡献，但改变其假设、状态空间、更新算子或学习目标，仍然可以形成直接的方法创新。**

本项目可以沿已有技术主干提出：

- CHEH：保留互斥隐藏事件链、人物责任、实例关联和可撤销来源的反事实假设事件超图；
- CF-BOCPD：将 run length、变化原因与习惯阶段联合推断，并按原因选择性重置参数块；
- OPCEU：把选择性观察和证据相关性写进期望充分统计量，而非对软人物权重做普通计数；
- PCHMP：在合法类型边和互斥假设集合上执行来源约束消息传递；
- RGRC：根据人物责任、变化原因、独立性和行动代价执行可逆长期巩固；
- CIAV：以变化原因辨识信息和下游任务效用共同选择主动微验证；
- CCRR：在保持、新建、恢复历史阶段和未决之间进行情境条件化竞争。

对应完整定义、公式与直接对照见 `方向结构二_技术路线创新改进与首轮死亡测试_v0.1.md`。根据当前项目决定，这些创新单元全部进入同一个统一系统并共同支撑一篇论文；每一项仍必须和其未改进版本直接比较，才能判断该项创新是否成立。

### 10.7 发现已有覆盖时的处理原则

近邻检索发现某系统已经实现项目框中的功能时，后续报告必须同时做两件事：

1. **已有覆盖提醒：** 明确系统/论文、证据等级、已实现功能、具体方法、重合范围和限制；
2. **同路线方法创新：** 保留该功能，继续检查能否改变其假设、潜变量、表示、更新算子、目标、监督/干预、保证或决策闭环。

不得因为已有工作覆盖而绕开、删除或降级项目模块；也不得隐瞒重合或把普通复现称为创新。暂时找不到实质改进时，标记 `innovation unresolved（创新方案待解决）`，继续共同设计并把已有方法作为直接强基线。

## 13. 最终判断

方向二的科学空间不是“没人做过其中任何组件”，而是：

> 已有系统各自建立了有价值的能力，但目前公开方法仍把选择性观察、人物身份、事件结构、个体习惯和持续变化分散处理。方向二应正面吸收这些方法，构造忠实而强的组合基线，再检验新的联合模型能否在同屋多人污染、未观察事件、习惯变化和真实具身决策中取得不可由简单拼装解释的收益。

这使方向具有两条并行的创新路径：

1. **方法创新：** 观察过程感知的多人物隐藏事件—习惯阶段联合推断；
2. **基准创新：** 同时具备多人、隐藏事件、选择性观测、非平稳阶段和行动效用的长期家庭评测。

两者都必须服从同一原则：已有工作是必须提醒、忠实复现并力求超过的基线，不是缩小 CPSWM 总项目范围的理由。方向结构二框内的全部核心能力共同实现，并组织为一篇统一方法论文。

项目内最高组织约束见：`方向结构二_全框架统一单篇论文创新总纲_v1.0.md`。
