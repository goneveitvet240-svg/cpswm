# 第一部分：结构二完成情况（0:00–10:00）

## 第 1 页：开场（0:00–0:40）

各位老师好，今天我把汇报严格分成两部分。第一部分只回答结构二目前做到哪一步，不把工程完成和科学成功混在一起；第二部分再回到整个 CPSWM，也就是 Continual Personalized Semantic World Model（持续个性化语义世界模型）的总项目纲领。

先说结论：我们已经把结构二从概念框架推进成一个全状态、有状态、七算子同环的 D0 开发系统；但它还没有证明优于强基线，外部有效性和论文级结论也都没有建立。

## 第 2 页：结构二到底解决什么（0:40–2:00）

可以想象一个多人家庭：一个杯子昨天在书桌上，今天不见了。机器人没有看到中间过程。可能是主人拿走了，可能是家人移动了，可能发生了交接，也可能只是机器人没有经过那个位置，或者物体被遮挡。与此同时，主人的习惯会变化，访客还会带来以前没有出现过的行为。

普通系统在这里容易犯四类错误：第一，把“没看到”当成“不存在”；第二，把最可能的一条隐藏事件直接写成事实；第三，把家人或访客的行为写进主人的长期习惯；第四，习惯改变以后，要么适应太慢，要么把未来可能恢复的旧习惯彻底删除。

所以结构二研究的不是单次位置预测，而是：在 selective observation（选择性观察）、hidden events（隐藏事件）、multiple residents（多人共享）、open-world unknowns（开放世界未知）和 non-stationary habits（非平稳习惯）同时存在时，怎样维护一个带来源、可撤销、可保持未决的个体化联合信念。

## 第 3 页：三层七算子与 Route C（2:00–4:10）

七个算子不需要逐字背缩写，可以压成三层因果链。

第一层是 Observation-aware counterfactual inference（观察感知的反事实推断）。OPCEU 先判断机器人是否真的有观察机会；ORRER/CHEH 为未观察间隙保留多条人—物事件链；PCHMP 在物体、人物、事件、位置和来源之间传递受约束的信息。这里的原则是：没看见不自动等于不存在，top-1 猜测也不自动等于事实。

第二层是 Cause-aware continual memory（原因感知的持续记忆）。CF-BOCPD 判断变化来自观察方式、人物、实例身份、真实习惯还是噪声；RGRC 决定证据应隔离、晋升、撤销还是纠正版提交；CCRR 让保持当前阶段、新建阶段、恢复历史阶段和继续未决共同竞争。这里的目标是既能适应新习惯，也不让访客或一次误识别污染主人记忆。

第三层是 Utility-grounded active verification（效用落地的主动验证）。CIAV 决定下一步是否换视角、查容器、调整路线、询问用户，或者暂时不行动；执行结果再作为有来源的证据写回。

项目负责人已经选择 Route C，也就是 stateful joint inference（有状态联合推断）。每个粒子跨时间维护 `H/R/I/C/Z/r/V` 七个轴：事件链、人物角色、实例关联、变化原因、习惯阶段、游程长度和修订谱系；同时维护位置 Dirichlet、RLS 自然统计量和 information-form belief（信息形式信念）三个解析块。神经模型只有 proposal（提议）权，类型粒子负责约束和修订，只有可逆 RGRC 账本拥有长期写入权。

## 第 4 页：我们已经完成了什么（4:10–6:10）

目前可以确认的完成项有三层。

第一是定义层。结构二已经统一定义了选择性观察、隐藏事件、多人责任、未知人物、习惯变化、迟到反证和执行反馈；七个算子有共同输入输出与权限边界，而不是七个互不相干的模块。

第二是系统层。Route C 已经实现完整七轴状态的跨时间递推、三个 Rao–Blackwellized 解析块、可逆账本、动作读出和反馈再加权。旧 Task 8 只做三乘三九分类代理，不能代表完整世界状态；这一代表性缺口已经被全状态闭环补上。

第三是证据治理层。仓库已经形成来源绑定、回放、哈希链、状态机、伪造正向路径拒绝和 fail-closed（失败关闭）授权。这里必须强调：本地内容一致性不等于历史真实性，也不等于独立托管。最新审核自己也只称 partial adversarial coverage（部分对抗覆盖）。

## 第 5 页：实验告诉了我们什么（6:10–8:20）

Task 7 研究迟到反证能否通过局部修订接近完整重跑。当前只有 `reservoir-only` 路线在 D0 上达到 belief 与 action 的精确等价，并把 marginal likelihood evaluations（边际似然计算）从约 `571,808` 降到 `474,848`，大约减少 17%；`backward-only` 和 `combined` 仍失败。因此 Task 7 是 partial pass（部分通过），不是整体完成。

在较早的 v0.6 开发结果中，Project Two 的累计行动遗憾是 `3.455556`，matched AMG 是 `3.933333`，搜索端出现了正信号；但主人污染为 `0.007292`，而 AMG 为零，所以硬护栏没有通过，这个结果不能升级为论文结论。

在当前 Route C D0 工件中，共有 `62` 个可读出动作步骤；联合交互在其中 `13` 步产生非零动作后验变化，平均 total variation（总变差距离）为 `0.000459`，最大为 `0.004431`，但一次也没有改变最终 argmax 动作。joint 与 matched full-state factorized（匹配的全状态因式分解）行动遗憾都为 `0.244792/step`，而独立调参 AMG 为 `0.171875/step`。

这定位出了一个非常具体的瓶颈：现在的问题已不是“联合状态没有维护”或“联合信息没有到达动作后验”，而是它还没有跨过 action ranking（行动排序）的 decision margin（决策间隔）。也就是说，概率变了，但行动和效用没有变。

## 第 6 页：哪些还没有完成（8:20–10:00）

我们不能说“结构二已经完成”，更准确的状态是：完整科学对象已经被实现和运行过，但科学证明仍未完成。

正式任务上，Task 9 的四耦合协议已经定义但没有正式运行；Task 10 的本地工程复算没有形成正式通过；Task 11、12、13 和 P5 只有本地诊断，依赖回执尚未闭合。Gate B v0.8 仍是 `FROZEN_NOT_EXECUTED`，七算子正式消融没有授权。六个 external component cores（外部组件核心）不等于 native reproduction（原生复现）；ProcTHOR 只有 runtime preflight，D1 replay 尚未采集，D2 真实 RGB-D 尚未采集，独立托管和外部信任锚也没有建立。

而且演讲前的 fresh check 发现，Route C 当前工作树仍在加固：定向测试已达到 `8 passed`，当前工件的静态结构、源码绑定和 matched full-state fairness 都能通过；但同一工件触发 fresh-source replay 时仍得到不同的 deterministic replay digest（确定性重放摘要），验证器因此拒绝通过。也就是说，当前问题已经从 schema/fairness 修复推进到重放确定性仍未闭合。

下一步不是删掉七算子或缩小结构二，而是按证据门排序：先修复当前源码—工件回归；随后只在 validation set（验证集）上预注册 decision-sensitive readout（决策敏感读出）和交互参数，再用 fresh seeds 同时比较 full-state factorized 与独立调参 AMG。只有出现可重复的核心价值信号，才继续推进完整污染干预、Task 10–13/P5、Task 9、外部强基线、ProcTHOR、D2 和独立 sealed run（密封运行）。

第一部分可以用一句话收束：

> 结构二完成的是“可执行、可证伪的完整科学对象”，还没有完成“优于现有方法的科学证明”。

# 第二部分：总项目纲领（10:00–20:00）

## 第 7 页：从空间快照到长期家庭理解（10:00–11:30）

到这里回答了结构二做到哪一步。接下来把镜头拉远，说明它为什么存在于整个 CPSWM 项目中。

传统语义地图主要回答“这里有什么”和“某类物体最后在哪里”。我们的总项目要进一步回答：这是哪个具体实例，谁拥有或使用过它，它昨天在哪里、现在可能在哪里，谁可能移动了它，这条记忆来自直接观察还是事件推断，哪些位置是长期习惯，哪些只是一次异常，以及机器人为什么相信这件事。

因此目标不是通用常识数据库，而是 personalized household model（个性化家庭模型）：机器人长期生活在同一个家庭中，让具体物体、人物关系、时间事件、习惯和自身不确定性共同积累和演化。主动搜索只是它的下游能力，不能反过来取代长期世界模型这个中心。

从总纲的研究问题和基线原则可以归纳出一个总体可证伪假设：在感知、导航、语言模型、观察与行动预算相同的条件下，如果系统统一维护实例级长期记忆、人物条件化习惯、隐藏事件多假设、可追溯且可逆的证据，并让行动反馈持续写回，那么它应当同时改善世界模型质量与下游行动效用，并在习惯变化时减少错误污染和灾难性遗忘。这是待验证假设，不是已经成立的结论。

## 第 8 页：结构一、二、三怎样分工（11:30–13:20）

三条结构可以用三句话区分。

结构一回答“机器人最终要理解什么”：它定义跨天、跨周、跨月的家庭世界模型，包括人、物、关系、事件、习惯、偏好和规范。

结构二回答“在最困难的长期观测条件下怎样可靠地学到”：它处理选择性观察、隐藏事件、多人干扰、未知参与者和习惯变化，输出可撤销的联合后验和长期记忆更新。

结构三回答“学到的东西怎样被语言调用，并在具身闭环中被使用和验证”：它把模糊语言编译成可检查查询，在身份或位置不确定时主动确认，并把成功、失败、未找到和部分完成等结果写回。

这三者不是三个互相替代的独立系统，也不是简单的先后阶段。它们共享同一套 M01–M32 契约。结构一规定完整知识边界，结构二提供困难条件下的可靠学习机制，结构三既消费结构二的后验，也用实际任务检验这些后验有没有价值。

## 第 9 页：六层三十二模块与两条不能断的链（13:20–15:20）

工程上，总项目被拆成六层、三十二个稳定职责模块。

第一层是公共契约与运行底座；第二层是具身观测、感知与空间建图；第三层是长期世界模型、记忆与推理；第四层是查询、语言与解释；第五层是任务、搜索、导航、操作与写回；第六层是仿真、数据、评价与系统治理。

模块数量不是贡献数量，也不等于三十二个服务。它的意义是让任何模块都不能偷偷改变实体 ID、时间、事件、证据或写入权限。

系统有两条不能断的主链。第一条是证据进入链：传感器到观测、关联、事件、信念，再到长期记忆。第二条是任务闭环链：语言到查询、候选、计划、执行，再产生新证据并更新世界模型。

LLM 的边界也放在这两条链里：它可以做 temporal grounding（时间语义落地）、reference resolution（指代消解）和候选生成，但不能凭语言猜测直接覆盖地图事实。

## 第 10 页：研究问题、路线图和评价纪律（15:20–17:40）

总纲的七个研究问题可以合成三组。

第一组是表示与身份：长期记忆怎样把类别—位置地图升级成实例、关系、事件、习惯和证据谱系共同存在的概率世界模型；具体物体怎样跨天、跨房间和遮挡保持身份。

第二组是推断与持续学习：怎样从有限而有偏的观察中学习不同人物的习惯，推断未观察的移动与交接，并在适应新习惯的同时保留仍有效的旧知识。

第三组是查询与行动：怎样让 LLM 查询真实且可追溯的世界模型，以及怎样让搜索、导航和操作产生的新证据反过来改善地图。

实施上有 Phase 0 到 Phase 6：先统一任务、地图和证据标准；再建立实例级三维长期地图；加入人物关系、事件和习惯；处理隐藏状态；建立语言查询与解释；闭合任务和地图共同更新；最后才进入跨周数据和长期家庭机器人部署。阶段化用于控制依赖，不代表永久删除后续能力。

评价上必须同时看地图、实例与关系、时间事件、持续学习、语言查询和具身任务。所有方法收益都要在同感知、同信息、同计算和同动作预算下比较。换一个更强的 VLM、LLM 或导航器，不能被包装成长期记忆或世界模型的创新。

## 第 11 页：端到端目标（17:40–19:20）

总纲给出的端到端任务很直观：用户说，“找我昨天喝水的杯子。”

机器人不是只做文本与物体标签匹配。它要联合人物—物体使用事件、昨天的时间约束、具体实例外观、历史位置和未观察携带的可能性，生成多个候选；在搜索中继续更新地图，排除客人使用过的相似杯子；完成后把成功或失败作为新证据写回，并说明为什么做出这个判断。

总项目真正完成时，应同时得到三类成果：科学上形成长期、个性化、事件化、关系化且可持续学习的语义世界模型；工程上形成统一 API、长期事件数据库、语言查询和具身行动闭环；数据与评价上形成多人物、跨 session 的家庭数据、强基线和可复现实验协议。

## 第 12 页：总结（19:20–20:00）

最后总结三点。

第一，结构二已经跨过“只是想法”的阶段，形成过完整全状态 D0 闭环；但它当前最重要的事实是负结果和未闭合回归，而不是胜利叙事。

第二，结构二不是总项目本身。结构一规定长期家庭理解的完整范围，结构二研究怎样在困难观察下学对，结构三研究怎样通过语言和行动把它用对、验对并写回。

第三，我们最终研究的不是一个“找东西”系统，也不是一个“要不要重新观察”的决策器，而是：

> 家庭机器人如何通过长期生活经验，形成一个持续演化、个性化、可推理、可查询、可行动的语义世界模型。

| 七个算子都证明有贡献了吗？ | 没有。接口和同环执行已经实现过，但 Task 9、正式七算子消融和多项直接强对照尚未完成。 |
| 外部验证做到哪里？ | ProcTHOR 只有运行时预检；D1 replay、D2 RGB-D、原生强基线和独立托管都没有完成。 |
| 对抗审核完整了吗？ | 没有。当前仓库明确只允许称 partial adversarial coverage；本地哈希和一致性不等于外部真实性或独立保管。 |
| LLM 会不会污染长期记忆？ | LLM 只能解析语言和提出候选，没有长期 commit 权限；写入必须通过来源、人物责任、结构约束和可逆账本。 |

## 禁止和推荐表述

| 不要这样说 | 建议这样说 |
|---|---|
| “结构二已经完成。” | “结构二已形成完整 D0 科学对象；论文级证明尚未完成。” |

## 最值得背熟的三句话

1. 我们完成的是可执行、可证伪的科学对象，不是优越性结论。
2. 联合信息已经在部分步骤进入动作后验，但还没有跨过行动排序的决策边界。
3. 项目终点不是找东西，而是让世界模型随着家庭生活经验持续成长。
