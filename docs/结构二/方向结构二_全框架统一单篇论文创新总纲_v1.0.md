## 0. 已确定、不得静默缩减的项目决定

本文件记录方向结构二的明确范围决定：

1. 项目框架内的选择性观察、隐藏事件、同屋多人、个体习惯、非平稳阶段、长期巩固、主动验证和具身决策全部实现；
2. 这些内容不是拆成多篇互不完整的论文，而是共同组成一篇统一方法论文；
3. 已有项目覆盖某项功能，不是绕开、删除、降级或另找小空白的理由；
4. 遇到功能重合时，必须先明确提醒已有系统、已实现功能、使用方法和证据等级；
5. 随后必须区分“功能已存在”与“方法仍可创新”，围绕旧方法的假设、隐变量、更新算子、目标函数、监督信号或闭环决策提出新机制；
6. 如果新机制暂时还没有想清楚，应标记为 `innovation unresolved（创新方案待解决）`，继续共同设计，不能把已有功能直接写成自己的创新，也不能为图省力删除该模块；
7. 某一局部方法被强基线击败时，触发的是 redesign（方法重构），不是删除这一科学问题、缩减统一框架或自动拆分论文；
8. 所有新机制最终仍需经过忠实强基线、独立调参、消融实验、具身效用和外部有效性验证，不能仅凭名称不同宣称创新成立。

这八条同时约束后续文献检索、架构设计、代码实现、实验和论文写作。

## 1. 一篇论文的统一科学主张

本项目不是把七个模块罗列在一起，而是研究同一个耦合问题：

> 在机器人观察由任务、路径和已有信念共同决定的长期家庭环境中，怎样联合维护物体状态、实例身份、同屋人物责任、未观察事件链、变化原因和个体习惯阶段；怎样只把可信且属于目标人物的证据可逆地写入长期记忆；又怎样用低打扰主动验证解决关键歧义，并让统一信念改善查询、预测、搜索、放回、递送和协助？

统一后验可写为：

\[
\mathcal{B}_t =
p(L_t,I_t,S_t,A_t,E_t,Z_t,C_t,\Theta_t
\mid O_{1:t},M_{1:t},\pi^{obs}_{1:t},U_{1:t})
\]

其中：

- \(L_t\)：位置或容器；
- \(I_t\)：物体实例身份；
- \(S_t\)：静置、使用、携带或收纳状态；
- \(A_t\)：主人、家人、访客、机器人或未知行为者；
- \(E_t\)：直接观察或隐藏的人—物事件链；
- \(Z_t\)：当前或历史习惯阶段；
- \(C_t\)：观察、人物、身份、习惯或噪声变化原因；
- \(\Theta_t\)：人物—物体—情境条件化的长期习惯参数；
- \(\pi^{obs}_{1:t}\)：产生训练数据的观察策略；
- \(U_{1:t}\)：用户纠正、偏好、授权和行动反馈。

论文的中心贡献不是“组件数量多”，而是这些变量必须互相约束：

- 观察过程决定缺失证据怎样进入事件与习惯后验；
- 隐藏事件和人物责任决定哪些位置变化可以成为个体习惯证据；
- 变化原因决定应重置观察模型、人物混合、身份关联还是习惯阶段；
- 巩固机制决定证据应隔离、晋升、撤销还是重激活历史阶段；
- 主动验证根据哪个未决原因最影响具身任务来选择动作；
- 行动结果以有来源的反馈进入下一轮世界模型更新。

## 2. 必须全部完成的创新机制

下面七项不是七篇论文的菜单，而是统一模型的七个新算子。每项都保留“已有覆盖提醒”，避免把已有功能误写成创新；同时保留“我们要改什么”，避免因为已有覆盖就绕开。

| 统一机制 | 已有工作已覆盖的功能，必须提醒 | 本项目要提出的方法创新 | 在统一模型中的不可替代作用 |
|---|---|---|---|
| **OPCEU**：Observation-Process-Corrected Evidential Update（观察过程校正的证据更新） | O-STaR 等已处理机会式观察、可见性负证据和位置概率更新；Learning Object-Based State Estimators 已学习状态转移与观测模型 | 把任务、路径、视野、容器访问、过去信念与检测过程写成观察产生模型；对未见事件和相关证据簇计算后验期望充分统计量，而非普通计数或只做 inverse propensity weighting（逆倾向加权） | 为全部后续模块提供不把“没看见”等同“不存在”的证据权重 |
| **CHEH**：Counterfactual Hypothesis Event Hypergraph（反事实假设事件超图） | GESTO、EGG、HERMES 等已覆盖人—物事件、时序场景图和事件边 | 一个观察间隙保留多条互斥 `pick-up → carry → handoff → place` 事件链超边；每条边绑定人物责任、实例、时间、观察支持和来源，并支持跨时间 `branch/revise/retract/rebuild` | 不把 top-1 猜测永久写成事实，为人物归因和习惯学习保留可撤销的不确定性 |
| **PCHMP**：Provenance-Constrained Hypothesis Message Passing（来源约束的假设消息传递） | 异构 GNN、Transformer 和事件图消息传递已经广泛使用 | 在来源类型防火墙、互斥假设归一化、人物置换等变性和物理事件约束下传递消息；输出预测的同时返回证据子图，禁止推断结果循环充当独立事实 | 把 OPCEU、CHEH、人物和当前状态放进一个可审计联合推断器 |
| **CF-BOCPD**：Cause-Factored Bayesian Online Change-Point Detection（原因因子化贝叶斯在线变化点检测） | BOCPD、多模型 BOCPD、STREAK 等已覆盖变化检测或非平稳持续学习 | 联合推断 \(p(r_t,C_t,Z_t\mid D_{1:t})\)，并设计 cause-specific reset operator（原因特定重置算子）：观察、人物、身份、习惯与噪声分别改变不同转移核和参数块 | 防止把机器人路线改变、访客到来或身份错误误写为主人习惯改变 |
| **RGRC**：Responsibility-Gated Reversible Consolidation（责任门控的可逆巩固） | replay、EWC/Fisher 正则、软人物更新和分层计数已覆盖防遗忘或个体统计 | 根据人物责任、变化原因、证据独立性、观察支持、授权和行动错误代价，在 `quarantine/promote/retract/reactivate` 之间决策；所有派生统计可从日志重建 | 防止家人、访客、相似实例、重复帧和机器人自身操作污染主人长期习惯 |
| **CCRR**：Context-Conditioned Regime Reactivation（情境条件化阶段重激活） | recurrent concept drift、sticky HMM/HDP-HMM 和历史模型库已经覆盖阶段复用 | 在 `stay/create/reactivate/unresolved` 之间维护后验竞争；恢复历史阶段前同时排除观察策略复现、访客再次出现和身份切换等替代原因 | 同时实现真实新习惯适应、旧习惯恢复和错误阶段复活抑制 |
| **CIAV**：Cause-Information Active Verification（变化原因信息主动验证） | active perception、value of information 和 active BOCPD 已覆盖状态/变化点信息获取 | 以变化原因互信息、任务效用增益、运动成本、隐私和打扰联合选择微观察、容器检查、路线调整、适时询问或保持未决 | 当被动日志不足以识别原因时，用最小代价补充能够改变巩固与行动的证据 |

除七个方法算子外，论文还包含一个统一评价贡献：

**Belief-to-Utility Attribution Protocol（信念到效用归因协议）**：在同感知、同日志、同计算、同询问和同动作预算下，追踪每次查询、预测、搜索、放回、递送和协助具体使用了哪些信念与证据；评价真实环境 regret（遗憾）、错误人物/位置成本、隐私和打扰，而不只报告 ECE、NLL 或离线准确率。

## 3. 七个算子怎样形成一个算法，而不是模块拼盘

统一在线循环固定为：

```text
任务、路径、视野和检测机会
→ OPCEU 建立观察似然与校正证据簇
→ CHEH 生成互斥隐藏事件链与人物/实例假设
→ PCHMP 在来源和物理约束下联合更新信念
→ CF-BOCPD 识别变化原因并选择性更新参数块
→ RGRC 决定证据隔离、晋升、撤销或重激活
→ CCRR 保持、新建、恢复或暂不决定习惯阶段
→ CIAV 在关键不可识别处选择低打扰验证动作
→ 查询、预测、搜索、放回、递送和协助
→ 观察与行动反馈带来源写回
```

为了证明不是普通流水线，训练/推断时需要至少三个跨模块耦合量：

1. OPCEU 的观察似然直接进入 CHEH/PCHMP 的事件权重，而不是只作为预处理掩码；
2. CF-BOCPD 的原因后验直接决定 RGRC 可以修改哪些长期参数，而不是检测后仅输出标签；
3. CIAV 的动作价值同时依赖原因不确定性、预计巩固改变和下游任务效用，而不是单独最大化状态熵。

统一目标可以组织为：

\[
\mathcal{J}=
\mathcal{L}_{state}
+\lambda_E\mathcal{L}_{event}
+\lambda_A\mathcal{L}_{actor}
+\lambda_C\mathcal{L}_{cause}
+\lambda_Z\mathcal{L}_{regime}
+\lambda_{cal}\mathcal{L}_{calibration}
+\lambda_U\mathcal{R}_{task}
+\lambda_K\mathcal{C}_{observation/privacy}
\]

各项权重、是否使用端到端训练以及结构化推断的具体形式仍需实验决定，但所有损失必须绑定同一事件、人物、阶段和来源语义。

## 4. 一篇论文中的贡献层次

七个新算子不能在摘要里写成七条松散贡献。论文按一个总贡献、三个方法层和一个验证层组织：

### 总贡献

提出一个在选择性观察下联合推断隐藏事件、多人责任、变化原因和非平稳个体习惯，并通过可逆巩固与主动验证改善长期具身决策的持续个性化世界模型。

### 方法层一：Observation-aware counterfactual world-state inference（观察感知的反事实世界状态推断）

由 OPCEU + CHEH + PCHMP 组成，解决“看到了什么、没看到什么、可能发生了哪些事件、由谁造成”。

### 方法层二：Cause-aware continual personalized memory（原因感知的持续个性化记忆）

由 CF-BOCPD + RGRC + CCRR 组成，解决“为什么分布变了、哪些证据能写给主人、应建立新阶段还是恢复旧阶段”。

### 方法层三：Utility-grounded active verification（效用落地的主动验证）

由 CIAV 和多任务 belief-to-action（信念到行动）接口组成，解决“下一步获取什么信息最值得，以及信念是否真的改善行动”。

### 验证层

建立覆盖选择性观察、隐藏事件、多人、身份噪声、渐变/突变/回归习惯和真实感知误差的长期评测，并与单篇忠实基线和独立增强组合基线比较。

## 5. 遇到已有项目时的强制提醒—创新协议

后续每发现一个近邻项目，必须先给出以下卡片，不能只说“别人做过了”，也不能隐瞒重合：

```text
【已有覆盖提醒】
系统/论文：
证据等级：unverified / abstract only / full text checked / official metadata only
它已经实现的功能：
它采用的具体方法：
与本项目重合的输入、输出和场景：
它尚未解决或依赖的假设：

【本项目创新状态】
功能是否仍在统一框架：是，默认不得删除
当前新方法：已定义 / 待共同设计 / 已实现 / 已通过对照
拟改变的数学对象或算法步骤：
最强直接对照：
能否区分新旧方法的实验：
失败后的动作：修改新算子并复测，不自动删模块
```

共同寻找方法创新时，至少逐项检查八个改进轴：

1. **assumption（假设）**：旧方法依赖完整观察、单用户、静态分布或独立证据吗？
2. **latent state（潜变量）**：是否缺少人物责任、事件链、变化原因、历史阶段或观察策略？
3. **representation（表示）**：确定边能否改成互斥假设集合、超图或带来源版本？
4. **update operator（更新算子）**：是否需要选择性重置、隔离、撤销、重建或重激活？
5. **objective（目标）**：能否从预测损失升级为污染—适应—效用—隐私联合风险？
6. **supervision/intervention（监督/干预）**：能否利用软责任、反事实场景、微验证或自然实验？
7. **guarantee/calibration（保证/校准）**：能否显式输出未决、控制错误巩固或给出识别条件？
8. **decision loop（决策闭环）**：方法是否改变机器人真实搜索、放回、递送、询问或观察行为？

若八个轴仍找不到实质改变，该功能暂时标为 `innovation unresolved`，继续检索和共同设计；不得把普通实现包装成创新，也不得因此绕开它。

## 7. 一篇论文所需的对照与消融

### 7.1 系统级强基线

- O-STaR-style 位置概率与成本感知搜索；
- STREAK-style 持续物体迁移学习；
- HERMES-style 时序场景图和习惯检索；
- GESTO/EGG-style 事件表示；
- 标准 BOCPD 或独立多模型变化检测；
- 上述组件经过独立调参后的增强组合 B\*。

### 7.2 逐创新直接替换消融

| 完整方法中移除/替换 | 必须替换为 | 主要观察指标 |
|---|---|---|
| OPCEU | 普通计数、只用可见性、inverse propensity | observation-to-habit leakage、校准、任务 regret |
| CHEH | top-1 事件边、独立候选图 | hidden-event Top-k、错误链传播、可撤销性收益 |
| PCHMP | 普通异构 GNN/Transformer | 人物 ID 捷径、来源泄漏、联合后验与行动效用 |
| CF-BOCPD | 标准 BOCPD、BOCPD 后分类、多独立 BOCPD | 原因 F1、false owner-habit change、适应延迟 |
| RGRC | soft count、hard reject、replay/EWC | owner contamination、promotion delay、行动错误成本 |
| CCRR | 永远新建、最近阶段匹配、sticky HMM | 历史阶段恢复精度/延迟、错误复活率 |
| CIAV | 随机检查、最大状态熵、最大变化点信息增益 | 原因信息/成本、任务效用、隐私和打扰 |

### 7.3 联合性证明

除逐项消融外，必须证明至少以下交互不是独立模块相加：

- OPCEU × CF-BOCPD：观察偏差校正是否减少虚假习惯变化；
- CHEH/PCHMP × RGRC：事件与人物不确定性是否减少长期个体污染；
- CF-BOCPD × CCRR：原因识别是否减少错误历史阶段恢复；
- RGRC/CCRR × CIAV：主动验证是否优先解决真正会改变长期记忆和任务行动的歧义；
- 完整模型 × B\*：同预算下是否产生组合基线无法解释的全链路收益。

### 7.4 七条技术路线审核整改门（更新至 2026-08-26）

本节把“代码中有模块”和“论文中有方法贡献”分开。统一门禁现拆成三层：`structure_two_evidence_artifacts.py` 只接受 declarative receipt（声明回执）和文件引用，`structure_two_artifact_verifier.py` 逐文件打开并重算字节哈希、验证独立 authority attestation（权威认证）并从机器可读产物推导结论，`structure_two_technical_route_audit.py` 只消费验证器签名的 verified bundle（已验证证据包）。调用者不能直接填写 `paper_innovation_established`、`independently_tuned` 或 `powered_mechanism_test`；当前代码中的门禁实现本身仍不是论文通过证据。

| 路线 | 本轮固定的算法/审计语义 | 仍未成立的论文证据 |
|---|---|---|
| OPCEU | propensity support diagnostic（倾向支持诊断）分别输出 `identifiable / weak_overlap / positivity_failure / non_identifiable`；若 passive MNAR 仍受未测选择变量影响，即使能计算权重也必须报 `non_identifiable` | 受控干预或充分测量协变量下的识别证据；选择偏差校正对最终行动效用的增益 |
| CHEH / ORRER | 保留开放人物、多机制、多假设和可逆父子修订 | matched open-world AMG 已在现有链准确率上同为 1.0；下一门改为长期 owner contamination（主人污染）、recovery latency（恢复延迟）、revision cost（修订成本）和 action utility（行动效用） |
| PCHMP | 人物置换等变、canonical evidence payload（规范证据载荷）、record/cluster/semantic fingerprint（记录／证据簇／语义指纹）单次消费，以及 leave-one-cluster-out 敏感性审计进入可执行测试；`trace_id`、入库时间和随机包装 ID 不参与语义指纹，同一主张的独立传感器／模型证据只有在 authority-attested independence certificate（权威认证独立性证明）存在时才可分别计数，证明哈希随消费回执进入事件历史 | 普通 heterogeneous GNN（异构图神经网络）独立调参与同输入预算对照；还必须通过改变封存 evaluator truth 而输出不变的 noninterference（非干扰）反事实测试 |
| CF-BOCPD | 原“五个结果”正式降级为 five single-factor intervention probes（五个单因子干预探针），不再称 factorial。若使用 powered factorial intervention（功效充足的因子干预），必须登记五因子的水平、完整 Cartesian cell manifest（笛卡尔实验单元清单）、seed/household/episode、独立实验单位、功效目标、簇级区间及预注册交互项，并实际拟合 observation×actor、identity×noise、visitor×habit、selection×habit 等交互 | 真实 powered factorial 结果，以及 ordinary BOCPD、BOCPDMS、switching HMM 独立调参对照；“原因变量存在”仍不等于原因可识别 |
| RGRC | 可逆 ledger（账本）增加 full-rerun equivalence receipt（完整重跑等价回执）；混合统计量逆更新须另交 numerical downdate stability（数值逆更新稳定性）产物 | contamination—recovery—cost—utility Pareto frontier（污染—恢复—成本—效用帕累托前沿）和行动收益；event sourcing（事件溯源）本身不作为 ML 创新 |
| CCRR | `stay/create/reactivate/unresolved` 保持归一化后验竞争；权限边界固定为 CCRR 只提出阶段目的地、RGRC 只判断证据准入／撤销、reversible ledger（可逆账本）是唯一最终阶段与统计量写入者，决策记录不得自授权写入 | powered 历史阶段恢复精度、恢复延迟、错误复活率，以及账本提交写入相对替代方法的收益 |
| CIAV | 从纯 entropy（熵）扩展为 cause information + expected optimal consolidation decision value + terminal task utility（原因信息＋预期最优巩固决策价值＋终端任务效用），在同一动作集上施加 privacy hard constraint（隐私硬约束）；巩固项比较观察前后的最优 `commit/quarantine/retract` 长期效用，不再比较 prior/posterior MAP cause 对应的概率；实现 never-act、always-verify、random、max-entropy 和 IPS/SNIPS OPE | 真实 observation/outcome model、可执行动作接线、充足 overlap（重叠）下的离策略行动效用和具身在线结果 |

统一门还强制以下共同条件：

1. matched open-world AMG、普通异构 GNN、ordinary BOCPD、BOCPDMS、switching HMM、never-act、always-verify、random、max-entropy 九个基线必须分别提交独立调参完成产物、真实可打开的同输入／同预算文件、样本级效应产物和可复算的 cluster-bootstrap confidence interval（簇级自助法置信区间）；
2. `causal_coupling_established` 与 `paper_benefit_claim_allowed` 是两道不同门：显著正或负效应均可说明模块确实改变最终行动，但收益门只接受预注册主要效用的正向 superiority（优效）或 non-inferiority（非劣）；三个显著负效用耦合不能包装成论文收益；
3. OPCEU→CHEH/PCHMP、CF-BOCPD→RGRC、CF-BOCPD→CCRR、RGRC/CCRR→CIAV 四种耦合均可测试；因果门至少三种有效，收益门还要求至少三种正向／非劣并通过全部 matched baseline benefit gate（匹配基线收益门）；
4. RGRC 的 Pareto 评价只在已验证 `full_rerun_equivalent=True` 的方法中计算；候选必须真实位于 contamination—recovery—cost—utility 前沿，不能只提交一个 Pareto 文件哈希；
5. 当前七条路线全部保持在统一框架中；任何基线持平或失败只会把对应创新标为 `unresolved`，不会自动删除该功能，也不会把已有工程实现包装为新方法。

### 7.5 五条跨领域路线的职责边界

- **Reversible Belief Data Systems（可逆信念数据系统）**：账本、哈希链、撤销和重放是可信基础设施；只有当它们改变污染—恢复 Pareto 前沿和行动效用时，才支持学习方法贡献。
- **Epistemic Information-Flow Control（认识论信息流控制）**：类型枚举是第一层防火墙；论文门另要求 counterfactual noninterference（反事实非干扰）回执，即保持可见输入不变、只改变封存真值时模型输出哈希必须不变。
- **Regime-Localized Reversible Learning（阶段局部可逆学习）**：与核心算法最一致；除代数等价外，必须记录条件数、误差界或重放回退，并提交数值逆更新稳定性回执。
- **Object-Centric Latent Process Inference（物体中心潜过程推断）**：object track（物体轨迹）与 object identity（物体身份）分离；多视角身份验证保留候选后验和显式 unknown identity（未知身份）质量，未知不能被转成已确认 UUID。
- **Task-Aware Self-Adjusting Decision（任务感知自调整决策）**：`belief invalidation / cache invalidation / policy replanning`（信念失效／缓存失效／策略重规划）分别记录。信念或缓存更新可以不改变动作；只有相关变化或时效超限才触发重规划／取消。

## 9. 推进原则

1. **全部做，不等于同时乱做。** 依赖顺序为基准真值与指标 → 观察过程 → 隐藏事件/联合信念 → 原因化阶段 → 可逆巩固/重激活 → 主动验证 → 全下游和真实验证。
2. **先接口和成对反事实，再做大模型。** 这样是为了能判断每个新算子是否工作，不是缩减最终范围。
3. **发现近邻，先提醒再创新。** 明确它已经做了什么，然后保留该功能并共同改变其方法。
4. **局部失败，重做而不逃避。** 可以替换具体算法、表示或训练方式，但方向结构二的完整功能和单篇统一目标不自动改变。
5. **一篇文章，一个中心因果链。** 选择性观察影响事件后验，事件/人物影响巩固，变化原因影响阶段，阶段不确定性影响主动验证，最终影响具身行动。

本文件优先于此前关于“在 A/B/C 中择一”“只实现通过某项死亡测试的模块”或“拆分成多篇论文”的工作性表述；那些路线继续作为统一系统中的子系统和对照，不再作为范围取舍选项。
