# 手物提议输入的两轮覆盖

第一轮覆盖同源严格连接、手部未运行/已运行但空结果、图像外关键点的未决人物归属、区域重叠候选保留、未知人物、人物对与actor support的标识连接、迟到前缀重建、未来观测不见、来源/版本元数据不进入神经特征。三种现有网络在同一完整候选集合和同一候选ID上，对真实数值改变产生不同概率；这是受控消费测试，权重未做自然训练。

第二轮为完整一致的伪造手部测量生成真实q和完整支持，自封摘要后恢复、重试和下一次采样均能运行，但只能保留未校准提议权限。同一request偷偷替换输入、重新封装后只改来源/坐标/有无手/权限字段、强行篡改嵌套冻结对象均拒绝，RNG与请求状态不变，合法重试和恢复相同。实际前端产物包含手部特征，core/snapshot/ledger/execution traces逐项保持；独立固定结果摘要约束上下文文件，模型执行前拒绝被换上下文。

原身份歧义、连续窗口和完整来源重封攻击一并回归。人物对仍是两两可能关系，并非联合身份划分；候选人物类别和区域手数也不是人物/物理手的真实数量。完整一致伪造能够通过的路径明确保留在结果中，来源一致性不等于检测正确、模型执行认证或独立人工标注。

A自审，不是B验收。自然输入尚不能产生GroundedTransition或可靠接触/释放/身份/位姿误差分布；本轮仅闭合到提议输入、q计算与恢复，不宣称自然后验、长期习惯或动作闭环收益。
