# 公共视觉 / RGB-D 进入原生神经提议

用户授权的主干推进继续保留完整结构二、纯 RGB、原分类任务和主动澄清任务。此轮新增显式 `use_owned_visual_context`；默认语义对照不变。原生 `NativeJointContext` 的公开原始观测已有来源，但旧网络投影丢弃它们；现在完整视觉候选和表面几何进入既有类型化网络。

运行时从已送达动作、配对公共原件及绑定检测器重建截止时间内的来源。网络只收到副本；来源登记钥匙留在拥有者中。消费者重建输入后用真实权重复算 q；新进程和行动读出还会重新推理原件，检查来源目录。来源目录是审计证明，不是另一份可写世界记忆。整个拥有者、采集系统或部署信任根被一致替换的物理真实性不由这些哈希证明。

像素框、局部身份假设、世界表面点仍不等于世界实例、物体中心、6D 位姿或校准概率。私有对象 ID、掩膜、资产/场景 ID 没有进入网络输入。对授权理想自位姿的变化，图像 IoU 关联重建片段；未实现运动补偿或跨场景再识别。

原生目标候选及条件统计仍为 `OpenWorldJointFixture`。q 是提议分布，有限精确枚举中在积分系数与提议分母正确抵消；本轮不新增目标密度、校准似然、负观测/长期写入权限，也不改变任务效用。开发权重仍是受控单样本、2 步训练产物，没有自然联合训练结论。

## 完整归档攻击

在真实视觉历史副本中，把相机位置改为(91,92,93)，一致重建三路传感器包/回执和几何，随后恢复拥有者原件；再用真实checkpoint重算全部11个来源、22条原生记录、q、输入指纹与核心锚点。其原生内部一致性核验通过，11个q均改变，原始观测、账本及动作历史保留。拥有者在决策读出和SQLite恢复两处重新推理原件，均以 `fresh owned visual neural source differs` 拒绝。它覆盖完整重封装的假阳性，不只测试缺字段或坏哈希；并不声称能认证整套拥有者/采集信任根一起被替换后的物理真实性。
