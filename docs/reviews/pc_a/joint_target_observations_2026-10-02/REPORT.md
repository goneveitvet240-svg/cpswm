## 实现与边界

新增闭合注册 profile `natural-target-temporal-joint-raw@1`，原单帧和双帧 profile 的单次限制保持有效。每次采集由原 owner command / issue / delivery / raw anchors 验证；观测更新绑定当时真实父后验。自然检测初始全部候选形成不同身份假设，沿用可失败的像素跟踪，不提供外部目标框、不按后来检测强制匹配；失去像素支持只停止增加位置证据，保留历史推断、未知分支和失败原件。

位置模型采用声明的静态状态与共享误差：`y_t = H theta + b + epsilon_t`，`Cov(b)=rho R`、`Cov(epsilon_t)=(1-rho) R`。每个新读数通过给定过去读数的条件创新更新，累积信息量与整个相关序列的一次联合计算一致；背景也使用持续的宽位置隐变量，不能每帧重置未知密度。开发默认 rho=0.5、未知初始分支质量=0.2，两个参数显式写入配置与绑定。rho=0/0.5/0.9 的精度矩阵、自然参数与联合对数密度均有直接矩阵对照。这里的等价是数学和实现性质，不是参数已经校准。

同一 action 的重复消费幂等；不同 action 若 RGB、depth、自身位姿和采集配置相同，则保留采集但不重复增加位置证据。RGB 相同、depth 不同仍属于新的相关测量。当前位置种子是确定的候选表面代表，不是 SDK 物体中心；短序列静态目标与相关结构均是模型假设。初始自然语义锚定、人物、先验、残差和测试效用仍受控，不能据此宣称自然身份正确或统一世界模型完成。

## 原子事务与撤回

原事务覆盖生产者历史/分支状态、真实粒子权重和条件统计、owner 消费目录、原始输入锚点、当前发布标记、动作状态及 SQLite。计算失败回滚推断，已成功执行的物理采集不消失。持久化结果不确定时封闭旧实例，由恢复流程判定提交是否发生，不再拍一次。

新增 `withdraw_owned_position_observation(action_id, reason=...)`：保留物理原件与原消费记录，登记有 core 锚点的撤回记录并原子重放。撤回中间采集时，从剩余原始输入重新计算轨迹、相关条件增量及后续分支；撤回最早跟踪锚点时同时排除依赖它的全部采集，禁止在同一序列里自动恢复旧消费。原语义来源撤回仍移除依赖于该来源的所有观测更新。重放不重新执行相机动作。

该 API 撤回的是本 profile 的位置证据，不擦除通用传感器原始档案，也不声称实现了所有感知模块的全局遗忘。新源版本改变实现绑定；没有承诺旧源码 SQLite 的跨版本迁移。长时段的全历史复算成本仍需后续评估。
