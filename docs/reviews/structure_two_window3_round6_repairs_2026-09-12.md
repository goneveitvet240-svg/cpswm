## W3-1：后验来源真实性——已修并验证，投影能力仍未完成

原生准备入口没有实现可解析后验内容、对象、源父链与消费权限的投影注册器。现明确拒绝 `posterior_projection_not_likelihood`，原因是 `posterior projection consumption is not bound in native runtime`；即使 UUID 恰好等于当前快照也不构成消费授权。原始似然模式夹带 posterior source 同样拒绝。随机、当前、跨运行、真实其他对象以及纠正后失效来源均有拒绝/原子性/合法重试测试。

未删除方法合同中的后验投影能力，也没有把所有候选拒绝。原始似然的真实支持链候选仍通过公开入口产生非空粒子、真实权重及边缘读出，未知 actor、未知实例和 unresolved 均保留。该入口继续明确标记 `explicit_prepared_inputs_not_calibrated`。调用方提供的似然/条件统计不是已校准生产模型。

共享 `normalize_particle_revisions` 是数值核，不是来源授权器。评估器局部的投影合同及路径仍保留，其来源真实性不由本轮原生入口验收背书。要接通原生投影，需要真实后验生产者、按运行/对象/证据链的内容绑定、撤销/失效状态、消费规则及避免与原始似然重复计入的合同；本轮没有伪造这套权威。

## W3-2：地点支持越界——已修并验证

公开入口从 `core.locations` 传入本运行既有世界支持集；支持集进入输入内容绑定。每个候选的条件统计必须覆盖相同的完整地点集合，完整重算条件统计引用也不能赋予外部 UUID 注册资格。

- 重排允许：地点和 α 成对保留，边缘概率按地点核对。
- 子集拒绝：使用完整注册集合并将不承载质量的地点设为零 α。
- 重复、全外来以及合法/非法混合集合拒绝，包括在已有父粒子之后。
- 零 α 全部进入 unresolved；未知实例质量仍独立保留，不被重新分配到已知地点。

本入口没有动态地点扩展授权。地点初始化沿用既有运行世界构造；任意 UUID 不构成扩展请求。今后若提供扩展，需要经真实世界注册入口更新支持版本及相关统计，不是放宽集合检查。

## W3-3：派生数值溢出——已修并验证

权重项按输入二进制浮点值精确求和，归一化在精确相对差上计算，再补偿指数参数舍入。保留巨大公共偏置下的微小相对证据；可抵消的中间溢出不会错误拒绝。公开 log-weight 的有限 float 合同仍保留：派生总值超出可表示范围时明确报错，不把 `+inf` / `NaN` / 算术 `-inf` 静默当成零权重。结构拒绝保留拒绝原因，只有这类候选按合同具有结构性负无穷分数。

条件 α 先按最大值缩放再归一化，使用稳定求和累计地点与未知质量，沿用既有概率质量容差，没有改科学阈值。对无法保留正 unresolved 的原生批次明确拒绝并恢复整个事务。归一化核允许可解释的极小指数下溢为零；原生入口更严格，禁止因此丢掉全部显式 unresolved。零质量、最小非正规数、1e308 尺度、混合尺度、极端 log-q、抵消、拒绝候选和未知质量均有解析/高精度参考。

参考独立性边界：权重参考使用 Decimal 1100 位独立构造原始项及指数，未调用被测权重或归一化函数；α 参考使用精确有理数表达输入与总和。生产也使用 Python Fraction 表达精确二进制输入，因此 α 参考共享标准库有理数叶运算，但不共享缩放或累积实现。这是数值/存储工程验证，不是统计模型、因果来源或科学校准的完整独立证明。尚未做大粒子规模性能预算实验。
