# 第三轮预先固定：同条件、有动作后果的开发比较

先完成第二轮两审及真实Unity闭环，再实现本轮；本计划先于新比较结果固定。不是B正式比较协议，也不重新选择研究先验/架构/论文指标。

已有场景只有同一房屋两个固定苹果位置，属于局部相机主动观察诊断，不含导航、抓取、人类角色或个人偏好真值。所有组使用同一原始语义过渡、相同原生候选/目标密度、初始相机位姿、官方SSDLite像素检测器、0.5既有开发过滤值、最大3条相机命令预算；场景位置只进入评估端。每组重新初始化同一场景，保留原始RGB、动作、检测、掩膜可见性和实际目标/相机位姿核对。

组别预先固定：三种既有神经架构分别使用第一轮的开发检查点、启用相机后验更新；另用首个架构的相同原生初始后验关闭相机概率更新作为消融；固定左先与右先的覆盖扫描作为强简单参照。两个位置均完整运行，不能只报告检测成功或方法获胜的分支。

关闭概率更新的组仍能读取实际图像测量并执行相同的检测停止与已看视角排除规则，不通过让基线忘记已经看到的信息来制造优势。扫描组使用同一检测停止规则和实际动作预算，不读取目标摆放标签。首次相机候选ID由公开视角固定，不由场景/图像摘要或随机UUID播种，避免无关ID改变平局方向。比较前验证语义意义上的初始联合概率在各组相同；差异不能归因于冷启动默认值。

开发读数：实际转动次数/角度、各步目标像素数与SDK可见性（分列）、像素检测器是否报出苹果、候选框与目标mask框连续IoU、何时停止、首动作及下一动作是否不同、联合概率变化、计算用时。目标出现于图像不等于实例辨认或机器人取回；positive category（类别阳性）也可能是误报。零观测、失败启动或执行失败保留，不作成功。

由于当前采用有限支撑精确枚举，三网络的q/q抵消后原生后验应相同；这三组提供接线一致性检查，不预期或宣称神经架构任务优势。小场景中覆盖扫描可能与后验方法相同或更快；结果必须如实保留。即使全部小任务完成，也不能升级为完整结构二有效、长期个性化收益或多场景泛化。

新增代码冻结后依次两轮A自审：一轮验证共同输入/预算和合法实际执行，二轮针对隐藏元数据泄漏、同像素非干扰、空结果/完整伪造结果、动作和像素来源、汇总重建以及断点状态。B独立审查人数保持单列，仍为未验收。

追加的前端诊断条件（比较运行前固定）：同一组别矩阵分别用仓库现有SSDLite和Faster R-CNN执行，仍使用各自固定官方权重与0.5既有开发过滤值，总计6组×2位置×2前端=24次场景运行。依据是第二轮同图像复算暴露前端差异；两种前端全部保留，不把较好的一种事后选为正式模型。各前端内部保证所有方法完全相同的检测和停止条件，跨前端结果分别报告。

比较实现的来源核查：逐动作报告必须与持续状态库内的拥有者命令、已交付RGB字节、评估端原始RGB/掩膜逐一对应；汇总重算动作数、角度、目标像素及候选框IoU，拒绝仅填汇总分数、漏掉失败场景、重复场景或完整重封但不对应实际状态的结果包。初始Pass也保留并验证目标不可见，不把初始图像忽略扩展为一般场景能力。各组的已看视角与阳性停止仅依赖已交付像素和命令，不读取位置、mask、SDK visible或真相文件。跨次渲染像素若不完全相同须报告，不能以同房屋配置冒充逐字同图像。

暂停条件记录为类别阳性、视角用尽、行动预算耗尽或执行异常；类别阳性与真实目标框重叠分列，0次动作不会自动成为成功。执行异常保存原始退出/错误记录并进入24次总分母。正式科学指标不变，本轮只给上述明确局部读数，所有位置与前端均完整报告。
