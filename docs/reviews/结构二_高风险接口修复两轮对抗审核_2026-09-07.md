# 结构二高风险接口修复：两轮对抗审核（2026-09-07）

## 审核结论

本轮完成 neural `q` / posterior weight（后验权重）契约、Task 7 五臂历史支持恢复、CF-BOCPD/CCRR 的 `(C,r,Z)` 语义、全局 evidence-factor consumption trace（证据—因子消费轨迹）、CIAV→OPCEU 观测闭环，以及 belief/readout cross-swap（信念/读出交叉互换）与 contamination trace（污染轨迹）。

两轮审核后，运行时与本地工程信任门通过；但以下边界保持失败关闭：

- Task 7 只有 `reservoir_only` 通过 D0 equivalence gate；`backward_message_only` 和 `combined` 仍失败。
- cross-swap 只能给出首错候选链，`causal_first_fault_claim_allowed=false`。
- evidence trace 的哈希链是 in-process content binding（进程内内容绑定），不是外部真实性或独立托管证明。
- CIAV actor likelihood table（主体似然表）在 opportunity（观测机会）产生前绑定，但当前仍是 D0 本地标定，不是外部校准证据。
- 七算子消融仍未授权；external confirmation（外部确认）仍为 `BLOCKED_FAIL_CLOSED`。

## 第一轮：接口一致性与后果输出审核

审核范围覆盖所有会改变 belief、长期统计或动作的正向输出：OPCEU likelihood、PCHMP posterior、CF-BOCPD `(C,r)`、CCRR `Z`、RGRC commit/non-commit、CIAV fast verification、execution feedback revision、neural particle posterior 和 action readout。

发现并修复：

1. Task 7 reservoir 被截在错误观测之后，无法恢复已淘汰支持。改为 pre-correction boundary（纠正前边界），保存并校验 RNG state，从该边界重放。
2. backward-only 原路径没有形成真实 conditional suffix message（条件后缀消息）调用。现已物化逐后代消息、前缀/后缀哈希和条目哈希，并验证 stale prefix/suffix。
3. full-rerun feedback 会对已变换记录第二次施加 stress transform，造成同一 record ID 绑定不同 payload。重放现在显式标记 evidence already transformed。
4. neural proposal 只拥有 `q`；每个 revision receipt 明确保存 `log q`、structured target terms（结构化目标项）和 posterior projection。posterior projection 不能被标记为 observation likelihood，同一 source snapshot 不能重放消费。
5. CCRR 原 token 只验证成员资格，未绑定完整决策内容。现 token→decision content hash 绑定；伪造尝试不会烧毁真实 token。
6. `STAY` 不再输出合成字符串 `"current"`，而绑定 scoring 时真实 active regime ID；`Z` 使用 `p(Z|C,r,context,library)`，identity 只提升一次到 `C=identity,r=0`。
7. evidence trace 的 RGRC commit 已物化为可被 action readout 消费的节点；action feedback 是独立 `ACTION_LIKELIHOOD`，不再伪装成非似然结果。

第一轮全量运行最初暴露本地 manifest/provenance drift（清单/来源漂移）以及上述 full-rerun 二次变换问题。修复后进入第二轮，不把中途失败当作通过。

## 第二轮：字段齐全的伪造、重放与状态机攻击

第二轮不重复正常路径，重点攻击 forged-but-complete（字段齐全但伪造）的正向输入：

| 攻击 | 预期 | 结果 |
|---|---|---|
| posterior snapshot 伪装成 observation likelihood | 拒绝 | 拒绝，source semantics 与 factor kind 不兼容 |
| posterior 经 DERIVE/COMMIT 再铸造成 likelihood | 拒绝 | 拒绝，只有 primitive PRODUCE 可产生 likelihood |
| 同一 record ID 换 payload | 拒绝且失败原子化 | 拒绝，receipt 数不增加 |
| duplicate commit 使用不同 idempotency key | 拒绝且失败原子化 | 拒绝，commit 节点保持可追踪 |
| neural 同一 source snapshot 重放 | 拒绝 | 拒绝，trace 不增加 |
| CCRR 改写 score/kind/cause/stream 后保留真实 token | 拒绝 | 拒绝，完整 decision hash 不匹配；真实 token 仍可用 |
| CF snapshot 与 CCRR clock/index/content 不一致 | 拒绝 | 拒绝 |
| Task 7 stale prefix、篡改 message、伪造 RNG checkpoint | 拒绝 | 拒绝 |
| CIAV 返回注册 outcome 但注入任意 actor posterior/location | 接口上不可表达 | realizer 不再含 posterior/object/location/actor-likelihood 字段 |
| CIAV 更换 model ID、返回未注册 outcome、零支持 likelihood | 拒绝且不产 evidence | 全部拒绝，trace 为空 |
| cross-swap report 改写参数但保留旧 hash | 校验失败 | `verify_payload_hash=false` |
