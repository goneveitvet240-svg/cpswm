# 自然输入来源核查（2026-09-15）

本轮重新读取作者发布渠道，没有下载或声称取得合格连续多人标注数据。

- [HOH官网](https://hohdataset.github.io/)仍注明完整数据需要向作者申请密码；访问申请状态不能替代取得数据。本轮未发送新邮件。
- [HOH-Grasps作者代码](https://github.com/Terascale-All-sensing-Research-Studio/HOH-Grasps-Dataset)提供抓取前／交接时两个关键时刻的手、物体分割点云及派生标签。它不是完整连续RGB片段，分割角色和标签也不能当作方法自行感知的输入。不能直接据此声称自然多人连续角色生产完成。
- [HO-Cap官方页面](https://irvlutd.github.io/HOCap/)提供无动捕的RGB-D采集和半自动手物体位姿标注，但说明中的handover为双手间操作。它可以进一步评估为位姿组件的开发数据；目前没有取得／验证该数据，且不能替代本项目多人有序角色的完整验收。

没有改变正式评估数据、自然外观路径、C位姿或预算。此来源核查不是数据交付；本轮真实新语义候选、真实标定、正式训练运行和真实闭环验收均未建立。

本轮另执行已连接邮箱的只读定向搜索，结果仅有原访问申请的SENT记录，未找到作者回复。没有发送新邮件，也没有取得访问密码。
