## 七算子与主干：已证明什么，仍欠什么

本次 647 矩阵包含原逐算子因果输入干预、无关变化对照、反馈、账本、纠正/撤回、故障注入和行动读出，故不只是检查名字/调用次数。以下仍是局部路径证据，不是全部同一联合运行的证明。

| 连接 | 当前受测证据 | 完整预期尚缺 |
|---|---|---|
| OPCEU → 数值状态 | 逆倾向公式、visibility 干预、无关字段不变 | 联合条件统计中的校准 |
| ORRER → PCHMP | unresolved/未知 actor 干预、真实反馈引擎 | 完整神经六操作提议与来源绑定 |

| CF-BOCPD → 原因/CIAV | 变化与恒定序列对照、原因快照消费 | 完整联合粒子阶段重放 |
| CCRR → RGRC | 身份与确认窗口干预、合法非空晋升 | adaptive 同位置/负观测固化及身份校准 |
| RGRC → 账本/读出 | 原子增量、纠正/撤回/回滚与参考对照 | 条件粒子统计批准聚合、延期取消父贡献恢复 |

完整验收应固定一个整合后的 SHA、原生模型和实际运行环境，从公开默认入口跑连续非空历史：H/R/I/C/Z/r/V 与三个 RB blocks → 七算子真实消费 → 后验/长期唯一账本 → 已执行行动 → 环境后果 → 后续反馈修订。每条重要连接都要有有效输入干预和应不变对照，检查数值、账本、行动及后续后果；跨提交、纠正、延期、晋升、取消、恢复必须含合法正路径、非法完整回滚、重复/乱序、完整伪造依赖与真实中断。调用凭据和局部数值收据不能替代这条闭环。
