## 一、555次漏检是什么

通过无标签的 `capture_hocap_detector_stages.py` 再次推断同180帧，观察现有Faster R-CNN RoI后处理函数输入和输出，返回原函数结果，不改其权重、阈值、NMS或top-k。保留后的预测文件SHA256仍为 `ffb6609d01552c9beb28b129d4fb395aa43b36a276e005ca1d9d5ea60ee69d7d`，与PR26逐字节一致。之后，独立评价进程才读取作者标签与阶段数组。

720个可见目标—帧中165匹配；555漏检互斥分解：

| 机制 | 数量 | 直接证据 |
|---|---:|---|
| 应用层0.5分数过滤 | 422 | 原生输出已有IoU≥0.5的非人物框，但分数<0.5 |
| RoI原生0.05分数过滤 | 125 | 原生输出没有足够重叠框；RoI筛选前有，但最高定位候选分数≤0.05 |
| 原生尺寸过滤／NMS／top-k | 8 | RoI筛选前有分数>0.05、IoU≥0.5框，原生输出没有 |
| 一对一匹配竞争 | 0 | 无漏检目标被保留下来的合格框覆盖却未分配 |
| 无足够重叠的RoI框／无空间重叠RoI框 | 0 | 在此次保留的RoI范围内未观察到 |

这里的“存在框”是**类别无关的定位机会**，不是正确语义类别或实例。该层级从RPN过滤之后开始，不能证明所有锚点的生成机制；尺寸/NMS/top-k合并而没有进一步拆分。多类别回归可产生低分偶合框，所以零“定位不足”不能提升为定位已解决。改变阈值后的误报、关联、角色和运行成本没有被这次计数评估。本轮不调0.5，不重新校准旧留出，不以降低阈值冒充能力修复。

### 窗口与配对

`evidence/detection_event_windows.json`保留每个序列／目标的0–19、20–39、40–59帧，以及最大相邻可见框中心位移±5帧。三个主要变化窗口为：

- `112303/G15_2`：32–42帧，11次出现中9匹配、2次应用分数过滤。
- `113202/G18_1`：52–59帧，8次中7匹配、1次应用分数过滤。
- `113535/G19_1`：50–59帧，10次中2匹配、8次应用分数过滤。

这些是**可见框运动代理窗口**，可受遮挡影响；没有把它们称为真实接触／释放时刻。180帧没有合格独立交接事件标签，因此实际语义关键事件窗口仍待建立。数据使用帧序数开发时钟，窗口不换算为测得的物理时长。

每条原始观测、序列、相机、帧号、标注成员名及文件哈希精确配对。9帧（每序列0/29/59）RGB与作者框叠加抽查未见明显整帧错配，但哈希/成员一致和抽查不等于作者标注无误。标注框是可见分割掩码的包围框，和检测器可能输出的完整物体范围不完全同义。当前召回评价逐帧匹配检测框，**没有使用跨帧关联**；因此555这个数字不能反推出稳定实例关联质量。

## 二、校准事件与已发现的范围错误

[CALIBRATION_SCOPE.md](CALIBRATION_SCOPE.md)逐项规定定位匹配、类别、实例、角色／事件、位姿似然和机会／效用模型的标签和适用范围。

旧校准只针对“已返回且分数≥0.5的非人物候选，是否按固定一对一IoU规则匹配可见操作目标”，不是角色概率、实例概率或全图召回。旧Brier `0.2824723606262733 → 0.381764054570158`失败原样保留。

本轮实际检查`obj_class_names`发现三序列对象组为G15、G18、G19；PR26“同对象组”描述和工具签名写死G15不准确。已补勘误，并把未来工具签名改成真实raw manifest、序列、相机与开发范围，逐序列报告标注目标。**旧错误范围校准产物退役，本轮没有重拟合。** 第三段仍是已消费的开发留出，不因对象不同升级成确认集。

## 三、自然更新推进与明确未完成项

[NATURAL.md](NATURAL.md)记录无作者答案注入的RGB-D表面几何生产。原始深度、独立相机文件、固定像素预测在同一个`ContinuousEvidenceInput`中消费；保留413个候选的来源、缺深度与物体/手/桌面/背景歧义。1个框无有效深度；334个框5%–95%深度跨度>0.10m，该阈值仅描述，不是校准误差界。

实际自然`GroundedTransition=0`、核心条件测量=0、语义账本更新=0、动作=0。180次advance均证据不足。6帧候选状态的中断恢复与不中断相等，但不是完整语义恢复验收。

已核实通用`ConditionalMeasurement`允许3×6部分测量更新六维状态；不能继续笼统声称数学接口必须观测所有六维。真正尚缺的是：表面像素到物体状态的测量函数、具名/对称性假设下实例责任、独立拟合并评价的误差模型、观察机会来源，以及合法transition生产连接。专用`PoseConditionalHistory`才固定6D观测。名义针孔位置还保留未处理畸变，不能直接当物体中心；未观测朝向不能填零，像素跨度也不能填进协方差。

## 四、受控主干缺口、修复和机制结果

[CONTROLLED.md](CONTROLLED.md)保留完整oracle轨和缺失歧义轨，明确采用模拟场景及假定似然。两者都经过真实`GroundedTransition → ContinuousEvidenceInput(registered_p5_first) → P5_FULL_EAGER`，每步实际算子轨迹和多解释后验可检查；不是自然识别或经验校准证据。

实际发现：前面反证触发重建后，一条曾发布记忆退出committed集合，但其来源仍留在observed且active。原实现只接受对committed的撤销，使该合法迟到反证抛KeyError，留下重建复活风险。修复允许RETRACT撤销有历史发布绑定、仍保留的观测；不放宽CORRECT或未发布观测的权限。派生后代遍历归档/observed/committed集合并tombstone，只有现存提交贡献才执行Hybrid撤销，整笔事务仍回滚。

完整轨12次P5、缺失轨10次P5。缺失输入无写入；移除角色等证据保留人物歧义。修后3条／4条迟到反馈均消费，目标退出observed且资格失活；中断恢复、恢复后再次重建相等且无复活，下一建议位置改变。物理执行仍0；这证明受控注册路径的机制，不证明训练好的全轴神经生产、真实执行器闭环或科学优势。
