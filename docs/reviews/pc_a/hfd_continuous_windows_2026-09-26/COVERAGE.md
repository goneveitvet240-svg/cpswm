# 本轮范围和覆盖矩阵

本轮是连续原帧窗口和手物几何的局部工程审查；两次均由 A 在本机执行。不是 B 独立复核、独立人工标签或结构二统一验收。完整 H/R/I/C/Z/r/V、三个 RB blocks、七算子、隐藏事件、多人物、开放世界、可逆归因、具身反馈及 C 的位置/朝向范围均保留。

| 检查面 | 本轮执行 | 边界 |
|---|---|---|
| 合法完整正路径 | 原始视频解码、窗口重建、同生产者手/物推理、几何关联、角色候选、完整候选支持、恢复、记忆/账本/动作检查 | 合成检测结果验证程序语义；真实检测结果不作准确率真值 |
| 源覆盖 | 固定四个均匀窗口，每窗四原帧；首尾保留；2/3/4/5/7/16/20/249/584 帧边界 | 短源重叠按唯一帧和呈现次数分别统计，窗口不是独立试次 |
| 完整伪造 | 修改全部时钟行并重封完整引用链；保留既有像素/标签/权限/索引完整重封矩阵 | 自报摘要只证明自洽，来源核验必须回到固定原归档 |
| 窗口依赖 | 重封后缺帧、总数、起点、时间顺序、scope、策略不一致；第二次清单读取期间额外成员 | 不一致包在模型构造和输出目录创建前拒绝 |
| 答案隔离 | 前端只读 runtime；作者行文件读取守卫；交换 outcome 不改变原始运行观测 | 八层试次选择本来就使用作者结果作开发分层；不是盲测或在线选帧策略 |
| 失败与恢复 | 手推理失败不改变已接受感知状态、重试成功、坏手来源恢复失败且不改状态；区域来源回归 | 模型推理不是精确接触、人身份或位姿校准 |
| 最终后果 | 每窗检查 semantic memory identity、snapshot、hybrid ledger、execution traces；恢复后感知一致 | 合法/伪造诊断可以产生候选，但本轮无语义发布、记忆写入或动作授权 |
| 真实视频 | 同八类作者训练试次，128 唯一原帧 / 32 短窗；源包全 337 试次重建 | 前端不处理其余 141,334 帧，不声称全序列跟踪 |
| 视觉核查 | A 查看 8 张拼图的全部 128 个缩小原帧，未见额外阶段/结果答案叠字；包装/书封文字保留 | 约 438×329 显示像素的缩略核查，不保证微小文字或其他未看帧；不是独立人工审核 |
| 科学门 | 既有模型/1 秒关联门保持；无新增训练或科研选型 | 手物测量尚未进入提议网络输入/监督；机器人参与者、目标物、真实接触/释放、长时闭环和公平比较仍未验证 |

正式命令、SHA、失败记录及真实结果见 REPORT、COMMANDS 和 FINDINGS；只以最终受测版本为准。
