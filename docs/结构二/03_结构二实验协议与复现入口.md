## 2. 主效用与硬护栏

### 主效用

PCT（惩罚后任务完成时间）使用等效秒数。优效要求：

```text
相对点估计改善 ≥ 10%
绝对点估计改善 ≥ tau_verify
配对一侧 95% CI 下界 > 0
任务成功率下降不超过 2 个百分点
全部硬护栏通过
```

`tau_verify=max(5秒,D2 pilot 标准验证行动中位时长)`。每个任务族的
`T_max=向上取整到5秒(max(2×匹配基线成功时长中位数,匹配基线成功时长p95))`。D1 的动作秒数
来自 D2 pilot，不使用 Unity 程序墙钟时间。

### 污染与恢复

| 门 | 阈值 |
|---|---:|
| C1 短期、未影响行动 | 点估计 ≤1%，95% 上界 ≤2% |
| C2 已影响行动、可恢复 | 点估计 ≤0.5%，95% 上界 ≤1% |
| C3 长期人物污染 | 最终未恢复 0；发生率 95% 上界 ≤0.5% |
| recovery p95 | 首次决定性反证后 ≤3 次有效机会、≤10 行动步；D2 ≤60秒 |
| C1/C2 最终未恢复 | 点估计 ≤1%，95% 上界 ≤2% |
| 安全/隐私严重事件 | 0 |

### Full-rerun equivalence

- belief：关键轴 TV p95 ≤0.05，最大值 ≤0.10；
- action：top-1 一致率 ≥99%，action TV p95 ≤0.05；
- utility：TOST 90% 区间同时在相对 ±2% 和绝对 ±0.2 `tau_verify` 内；
- 人物身份、提交/撤销、权限、安全和隐私状态：完全一致。

## 3. 对照与消融

系统级必须比较：

- 完整结构二；
- matched AMG/full-rerun 类强邻居；
- learned matched two-stage；
- 普通 RBPF/粒子方法；
- append-only、reweight-only 和 full-rerun 修订策略；
- no-VLM、VLM prior-only、VLM evidence-proposal、VLM direct-decision、oracle。

七算子消融只有在依赖回执全部通过后才可正式运行。每个移除算子都要换成信息、容量和计算匹配的
直接替代方法，不能简单设成 no-op 后宣称贡献。

Route C v0.2 的 seven-operator neutralization（七算子中和）是正式消融前的**开发诊断**：算子仍在
调用图和回执链中，只把独有作用替换为预先注册的中性元，用来检查作用路径是否到达动作后验。它
不能替代上述信息/容量/计算匹配的正式替代臂，也不能单独授权“算子有贡献”。

## 4. 数据切分与统计单位

- D0：按 household/scenario seed cluster 配对；
- D1：按 house + schedule block 切分；
- D2：按 actor + environment 切分；

- 没有纠错机会就按 right-censored（右删失）处理；
- 所有 C3 个案保留完整时间线。
