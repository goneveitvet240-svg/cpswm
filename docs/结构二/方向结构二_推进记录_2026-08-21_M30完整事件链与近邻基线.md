## 4. 本轮实现

### M30 `synthetic-routines@0.3`

- 每个日常移动生成有稳定 `event_chain_id` 和连续 `sequence_no` 的完整链；
- direct chain：`pick_up → carry → place`；
- handoff chain：`pick_up → carry → handoff → place`；
- 显式绑定 initial actor、recipient actor、handoff location、source/destination、regime 和 context；
- `RoutinePlan` 拒绝缺步骤、乱序、人物角色不连续或物理位置不连续的链；
- evaluator-only ground truth 同时保留完整 interaction events 和向后兼容的 PLACE 投影；
- `synthetic-routines@0.2` 的已冻结计划 ID/hash 和单 PLACE 语义保持不变。

### 直接近邻领域适配

- `BernertRamparany2021SequenceBaseline`：枚举所有与两个端点兼容的 direct/handoff 序列，只在所有解释责任人物一致时输出 entailed actor；严格保留原工作“所有兼容序列/必然与可能事实”的核心语义。
- `DamenHogg2012AMGGlobalMAPBaseline`：用完整事件语法和角色/共享约束构造候选，以事件 likelihood ratio 和角色似然选择一个全局 MAP；这是 object-relocation domain adaptation，不冒充原视频检测器、半高斯训练、RJMCMC-SA 或 IP solver 的完整复现。
- CHEH handoff 顺序修正为 `PICK_UP → CARRY → TRANSFER → PLACE`，并由契约验证初始携带者、交接者、接收者和最终放置者的角色连续性。

## 6. 创新状态与下一道死亡测试

当前 CHEH 只能写为：`complete M30 truth + prior-art adaptations runnable + mechanism case passed`。不能写为 `direct baseline passed` 或“首次多假设隐藏事件推断”。

真正需要验证的新方法差异是：

1. **revision across time（跨时间修订）**：同一假设集合在迟到人物/身份证据下重排，而不是重新跑一次无历史 MAP；
2. **retraction and rebuild（撤销与重建）**：错误链已经影响长期记忆后，能定位所有派生统计并恢复；
3. **normalized unresolved mass（归一未决质量）**：不可识别时不被迫提交一个 MAP；
4. **evidence-cluster accounting（证据簇核算）**：重复帧和换包装证据不能反复增强同一解释；
5. **unknown actor and identity noise（未知人物与身份噪声）**：超出 2021 已知居民和 2012 当前领域适配假设；
6. **belief-to-utility effect（信念到效用效果）**：减少主人长期习惯污染、错误放回/递送和真实行动 regret。

下一批 matched death test 必须覆盖多 seed、多家庭/物体、direct/handoff 比例、人物间歇可见、unknown actor、相似实例、迟到证据和重复证据簇，并给每个基线独立调参。若 CHEH 在 late-evidence recovery、owner contamination 或行动效用上仍不超过 2021/2012 适配和增强组合基线，应重构 CHEH 的修订算子与 PCHMP/RGRC 耦合；不删除方向结构二的隐藏事件和多人能力。
