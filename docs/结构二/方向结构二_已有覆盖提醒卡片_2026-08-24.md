## 卡片 1：MEMORA

```text
【已有覆盖提醒】
系统/论文：MEMORA: Embodied Action Memory from Egocentric Videos for Reasoning and Planning
        arXiv:2607.14252
证据等级：official abstract + method summary checked（官方摘要与方法摘要核验）

它已经实现的功能：
  - formation–consolidation–retrieval（形成—巩固—检索）记忆生命周期；
  - 四类类型化记忆：Environment / Entity / Activity / Inferred Knowledge；
  - 在线编辑跟踪物体身份与状态变化；
  - 离线巩固把重复经历抽象为可复用流程（procedures）；
  - 显式提取 participant-specific regularities（参与者特定规律）。

它采用的具体方法：
  在线编辑 + 离线巩固两阶段；记忆按类型分store；检索驱动的长时程规划。
  评测：MEMORA-Bench，45 小时 EPIC-KITCHENS-100 扩展视频、18 名参与者；
  记忆评估准确率最高 +20.5 点，分布外规划相对增益 16.6%。

与本项目重合的输入、输出和场景：
  - 与 RGRC 的「巩固」一侧高度重合：重复证据被抽象并晋升为长期结构；
  - 与「个体规律」目标重合：participant-specific regularities 就是人物条件化规律；
  - 与情景/实体分层记忆重合。

它尚未解决或依赖的假设：
  - 输入是**第一人称完整视频**，不是机器人任务驱动的选择性观察；
    没有 MNAR 观察产生过程，也没有 propensity 校正；
  - 没有未观测事件的概率后验——它抽象的是**看到过**的重复行为；
  - 没有可撤销谱系：巩固是单向的，没有 retract / 派生后代递归撤出 / 墓碑；
  - 没有变化原因分离：不区分观察策略变化、人物变化、习惯变化与噪声；
  - 多参与者是**跨参与者**（18 个人各自的视频），不是同屋多人对同一物体的并发干扰。

【本项目创新状态】
功能是否仍在统一框架：是。
当前新方法：RGRC 已实现（Hybrid 可逆充分统计量）；MEMORA 的对照未做。
拟改变的数学对象或算法步骤：
  巩固决策从「重复即抽象」改为「人物责任 × 变化原因 × 证据独立性 × 行动错误代价」
  门控的 quarantine / promote / retract / reactivate 四路决策，且全部派生统计可从日志重建。
最强直接对照：MEMORA 式「重复次数阈值巩固」+ 完整重跑，在同一 D0 日志上跑 put-back / recovery。
能否区分新旧方法的实验：能——注入访客污染与习惯回归后比较 owner contamination 与 recovery cost。
失败后的动作：修改 RGRC 门控函数并复测，不删除模块。
当前状态：`implementation complete`（未越过 direct baseline）。
```

## 卡片 2：H²-EMV（Learning to Forget）

```text
【已有覆盖提醒】
系统/论文：Learning to Forget — Hierarchical Episodic Memory for Lifelong Robot Deployment
        arXiv:2604.11306
证据等级：official abstract + method summary checked（官方摘要与方法摘要核验）

它已经实现的功能：
  - 增量构建的分层情景记忆；
  - 用**用户反馈**学习「该记住什么」的自然语言规则；
  - 以语言模型做 relevance estimation（相关性评估），据此丢弃记忆；
  - 用户对被遗忘细节给出反馈后，规则动态更新。

它采用的具体方法：
  LLM 相关性评估 + 学习得到的自然语言保留规则 + 用户反馈闭环。
  评测：仿真家庭任务 + ARMAR-7 人形机器人 20.5 小时真实记录；
  记忆体积 −45%、查询算力 −35%、第二轮查询准确率 +70%。

与本项目重合的输入、输出和场景：
  - 与 RGRC 的「遗忘/保留」一侧直接重合，且**已在真实机器人长期部署上验证**；
  - 与「用户纠正进入记忆策略」重合（本项目的 U_{1:t} 通道）。

它尚未解决或依赖的假设：
  - 保留规则来自**用户显式反馈**，不是从被动观察推断的行为者责任；
  - 摘要未涉及同屋多人归因、习惯阶段变化与错误遗忘的撤销机制；
  - 遗忘是「删除以省空间」，不是「这条证据不该算作主人的习惯」——
    两者的失败代价完全不同：前者失去信息，后者污染个体模型；
  - 没有区分「真实习惯衰退」与「存储策略造成的证据消失」
    （这正是 KIT Plewnia 2024 已经提醒过的同一陷阱）。

【本项目创新状态】
功能是否仍在统一框架：是。
当前新方法：RGRC 的 `quarantine → promote / retract / reactivate` 已实现。
拟改变的数学对象或算法步骤：
  遗忘/保留从「相关性标量 + 用户规则」改为「以人物责任与变化原因为条件、
  且可逆」的操作；被撤销的证据留下墓碑与谱系，而不是消失。
最强直接对照：H²-EMV 式「LLM 相关性 + 规则遗忘」在同一日志上跑，比较
  owner contamination、recovery cost 与记忆体积三者的联合前沿。
能否区分新旧方法的实验：能——错误遗忘后再给出反证证据，比较恢复延迟。
失败后的动作：重构 RGRC 门控，不放弃可逆性。
当前状态：`implementation complete`。
```

## 卡片 3：MUP-QBAF

```text
【已有覆盖提醒】
系统/论文：Multi-User Personalisation in Human-Robot Interaction:
        Resolving Preference Conflicts Using Gradual Argumentation
        arXiv:2511.03576
证据等级：official abstract + method summary checked（官方摘要与方法摘要核验）

它已经实现的功能：
  - 用 Quantitative Bipolar Argumentation Framework（定量双极论证框架）
    表示多用户的正负偏好；
  - 结合机器人对环境的动态观察，迭代重算论证强度；
  - 在护理者与被照护者偏好冲突的辅助机器人案例上验证，并做敏感性分析。

它采用的具体方法：
  偏好即论证（arguments），环境观察作为额外论证输入，梯度式强度重算。
  作者明确定位为「data-driven 方法的有原则替代」，强调透明与结构而非学习。

与本项目重合的输入、输出和场景：
  - 同屋多人 + 偏好冲突 + 机器人须做出单一行动，这三点与方向结构二重合；
  - 「观察进入偏好推理」的通道形式上与本项目相似。

它尚未解决或依赖的假设：
  - 输入是**已声明的偏好**（stated preference），不是从观察推断的行为；
    本项目的核心难题恰恰是「没人告诉机器人是谁动的」；
  - 不做行为者归因：它解决「A 想要 X、B 想要 Y 怎么办」，
    不解决「这次移动是 A 还是 B 干的」；
  - 没有隐藏事件、没有变化点、没有非平稳习惯阶段；
  - 没有长期统计的写入/撤销语义。

【本项目创新状态】
功能是否仍在统一框架：是（属于 PCHMP + 用户纠正通道 U_t）。
当前新方法：PCHMP 仍是 working specification；行为者责任证据接口已实现，算法未实现。
拟改变的数学对象或算法步骤：
  从「声明偏好之间的论证强度」改为「在来源类型防火墙与互斥假设归一化下，
  对未观测事件链上的行为者责任做消息传递」，且推断结果禁止循环充当独立事实。
最强直接对照：MUP-QBAF 式论证解冲突 + oracle 行为者标签，
  对比本项目从观察推断行为者后验。
能否区分新旧方法的实验：能——去掉行为者声明、只留观察，看两者是否还能作对。
失败后的动作：重设计 PCHMP，不把「偏好冲突消解」当成「行为者归因」。
当前状态：`method specified`（**不得进入论文贡献列表**）。
```

## 卡片 4：GLEN（Learning to Evolve Scenes）

```text
【已有覆盖提醒】
系统/论文：Learning to Evolve Scenes: Reasoning about Human Activities with Scene Graphs
        （GLEN, Graph-Language Edit Network）arXiv:2607.02425
证据等级：full public HTML checked（公开正文核验）

它已经实现的功能：
  - 提出 activity-conditioned graph edit forecasting（A-GEF，活动条件化图编辑预测）：
    把场景的时间演化建模为「以活动描述为条件的图编辑」；
  - Graph Encoder（TripletGCN + 与文本的 cross-attention）、Text Encoder、
    Graph Edit Model 三件套，预测节点增删与边修改；
  - 发布 SG-Ego：从 Ego4D 标注的 380 万时空场景图，
    1,480 个物体类、387 种关系，三阶段流水线（MLLM 关系抽取 → GroundingDINO 落地 → SAM2 时序合并）。

它采用的具体方法：
  图编辑序列预测；评测覆盖 EgoSchema 66.0%、EgoMCQ 91.2/56.2、
  EgoCVR R@1 15.3/47.7、A-GEF Triplet Recall@100 48.49%、EXPLORE-Bench S_obj 65.59%。

与本项目重合的输入、输出和场景：
  - 「场景图随人类活动演化」的表示与 CHEH 的事件链在形式上邻近；
  - 大规模真实第一人称数据 + 关系词表，可作为感知层参考。

它尚未解决或依赖的假设：
  - 预测的是**给定活动描述后**的图编辑，活动描述是输入而非推断结果；
  - 明确不预测物体位置坐标、不建模隐藏/未观测事件、不建模多人交互、
    不建模个性化习惯（正文自述）；
  - 没有概率后验与不确定性：图编辑是确定性预测，没有互斥假设集合、
    没有 unknown-mechanism / unresolved 质量；
  - 没有可撤销修订，没有长期个体统计。

【本项目创新状态】
功能是否仍在统一框架：是（CHEH 的表示层近邻）。
当前新方法：CHEH/ORRER 已实现；GLEN 的对照未做，且不构成直接对照
  （它的任务是有活动条件的图编辑预测，不是无标注间隙的事件溯因）。
拟改变的数学对象或算法步骤：
  从「确定性图编辑」改为「一个观察间隙上的互斥事件链超边集合 +
  unknown_mechanism / unresolved 显式质量 + 可逆父链修订」。
最强直接对照：GLEN 式图编辑预测 + top-1 事件链，
  在同一 D0 日志上比较隐藏事件 Top-k 与错误链传播。
能否区分新旧方法的实验：能——在活动标签不可得的间隙上评测。
失败后的动作：重设计 CHEH 表示，不放弃互斥假设与开放世界余量。
当前状态：`implementation complete`（matched AMG 对照未胜出）。
```

## 本批检索对新颖性表述的影响

1. **RGRC 的「巩固/遗忘」不再是空白区。** MEMORA 与 H²-EMV 都已经实现巩固或遗忘，
   且 H²-EMV 在真实人形机器人上做了 20.5 小时长期部署验证。
   RGRC 可辩护的差异只剩下三点，且**都还没有对照证据**：
   人物责任门控、变化原因条件化、以及**可逆**（撤销 + 谱系 + 墓碑）。
2. **「多用户个性化」也不再是空白区**，但 MUP-QBAF 处理的是声明偏好冲突，
   与本项目的「从观察推断行为者」不是同一问题。这个区分必须在论文里写清楚，
   否则审稿人会认为已被覆盖。
3. **GLEN 不构成 CHEH 的直接对照**，但它的 SG-Ego 数据规模会抬高「表示够不够真实」的门槛。
4. 四张卡片中没有一张改变现有的新颖性边界表述，
   但 **RGRC 与 CHEH 的可辩护空间都比 2026-08-13 时更窄**。
