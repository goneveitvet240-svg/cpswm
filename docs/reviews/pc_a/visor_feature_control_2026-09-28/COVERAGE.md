# 两轮局部对抗审查覆盖

本文件描述设计范围；实际通过数量/完整SHA见REPORT.md与命令回执。两轮均为电脑A顺序自审，不是两个独立审核人、电脑B或完整系统验收。

|层面|合法正路径|对抗/反事实路径|边界|
|---|---|---|---|
|新视频来源|完整源重建、两类接触、未知/无手保留|标注/ZIP伪造、源自封、漏项/多项、软硬链接|来源摘要为官方HTTPS实取后固定，非作者独立签名|
|监督和训练|有效像素梯度、真实SGD、两个预算全部报告|均衡偏置合法驻点、图像改变时偏置不变、void梯度|仅开发线性读出，未训练三类完整提议网络|
|常数参照|手算不同有效像素数下逐帧最优常数|防止用池化像素比例替代逐帧比例、缺类显式None|没有新增正式评估阈值|
|数据隔离|原RGB特征、完整单独视频诊断|训练/诊断同字节或同解码像素重叠拒绝、诊断标签翻转不影响权重/更新/训练结果/常数|driver测试使用合成冻结特征；真实骨干由实际执行及新进程重放验证|
|图像依赖|逐帧对齐计算|完整循环错配(i+1)%N，无自配，逐行与独立构造索引对照|相邻稀疏帧相关，错配并非独立随机样本|
|恢复和消费|保存/恢复完整输出、原模型与恢复模型的下一次更新一致|合法形状参数与报告全部改写并重封摘要后仍被重新计算拒绝|消费验证运行同一实现，不是独立算法复现|
|持久化|原子提交、合法重试、完整回读|写入中断、缺额外文件、软硬链接|不覆盖任意并发敌对进程或操作系统失陷|
|自然下游|已有连续输入/状态恢复回归、报告无法作为ProposalSample|既有像素假监督完整重封反例|本轮没有自然语义/账本/动作正例，系统矩阵仍部分覆盖|

既有VISOR像素/接触测试和上轮第二审原样进入本次命令。源代码变动后前一轮证据不作为最终通过，失败尝试保留各自SHA/日志。
