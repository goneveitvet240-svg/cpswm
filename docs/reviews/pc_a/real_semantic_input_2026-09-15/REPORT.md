## 实现与真实发现

1. `adapters/hocap_rgbd.py` 将原始 JPEG／16-bit PNG 绑定到固定来源，保持 RGB 像素、深度毫米转米并进入现有 M05 格式；拒绝错误哈希、格式、帧身份和未来到达顺序。其参数没有作者物体、手侧、位姿或事件标签。
2. `prepare_hocap_development_archive.py` 生成现有连续入口可消费的原始历史。使用明确的 100ms/帧开发序数时钟，**不是曝光时间／真实帧率／物理时延证据**。三个原始序列独立分组，不跨序列关联实例。
3. 初始真实运行显示旧 SSDlite 默认 0.5 过滤下只剩 147 个人物、2 个冰箱候选；720 个可见操作物体—帧全部漏检。该失败完整保留，没有改标签或把未检出当不存在。
4. 增加可选 `FasterNaturalAppearanceDetector`，使用官方 Faster R-CNN ResNet50 FPN v2 COCO_V1、原生 800/1333 输入变换，保持 0.5 筛选。权重 SHA256 `dd69338a24b8d7381807e247652bdc356325bcbaf1cd3e092e00e0a1a58706bf`，175,221,657 bytes；[官方权重](https://download.pytorch.org/models/fasterrcnn_resnet50_fpn_v2_coco-dd69338a.pth)。离线完整哈希验证、严格 weights-only 加载，候选 ID 和恢复配置均绑定相应模型权重；旧 SSDlite 默认兼容保留。
5. 更强前端首次连续运行暴露 native resize 浮点边界 `480.0000305 > 480`；保留失败日志。修复只允许两个 float32 ULP 内的舍入夹取，并逐帧记录 `resize_roundoff_clamps`；明显越界、非有限值、退化框仍拒绝。该修复不改坐标系／物理位姿范围。
6. `hocap_evaluation.py`／`evaluate_hocap_candidates.py` 在预测文件已固定后才打开作者标签，以分数排序一对一匹配可见操作目标，保留全部 IoU 备选、歧义和每个漏检目标。使用 IoU≥0.5 定义开发测量，非记忆提升门。

评价含义是“定位到标注的操作目标”，不是类别识别、人物身份、接触、角色或完整 6D 位姿正确。数据未标注房间中所有物体，因此未匹配的椅子等候选不等价于物体幻觉。三序列只构成一次原始历史重放；预录输入不响应模型动作。本次实际使用既有 `legacy_component_diagnostic` 感知通路；没有运行 `registered_p5_first`。校准产物在预测结束后拟合／评价，未进入运行时核心。

## 最终运行结果

同一 `521d4f17` 源码、相同180帧／360条原始观测、0.5筛选值，依次执行；各自使用两条 CPU 线程。单位“物体—帧”是每帧一次目标出现，不能解读为165个独立物体。

| 前端 | 非人物候选 | 匹配的可见目标—帧 | 漏检目标—帧 | 连续推断循环耗时 |
|---|---:|---:|---:|---:|
| 原 SSDlite | 2 | 0 / 720 | 720 | 34.53s |
| Faster R-CNN v2 | 413 | 165 / 720（22.9%） | 555 | 379.25s |

更强前端有239个人物候选（不是239个人），非人物类别包含 bottle/book/remote/chair 等；“book”框可能定位到纸盒，**几何目标匹配不代表类别识别正确**。每个框、来源观察UUID、RGB摘要、模型摘要、目标对应／漏检均保留在 `corrected_faster_frames.json` 和 `corrected_faster_eval_per_frame.json`。176帧共446个 native 输出框发生允许范围内的舍入修正，含后续被分数过滤的框；已记录原始数值失败与修复边界测试。

定位分数校准已实际执行：前两段277条候选拟合，第三段136条候选评价。留出 Brier 从 **0.28247 增至0.38176**（越低越好），校准后 NLL 1.03127。校准未显示改善，**不标记校准通过／可消费生产证据**；产物仅为保留的失败开发结果。拟合目标比例33.6%，留出52.9%；仅用拟合比例的常量 Brier 0.28664，也优于当前拟合校准器。分布变化是失败解释线索，不作为调参后重新签收同一留出的依据。分段匹配为79／14／72，不能把整体均值掩盖的第二段低检出当作稳定能力。

两个前端的自然 `GroundedTransition`、真实语义长期记忆更新与物理行动仍为 **0**。本批没有运行完整 P5 语义闭环，未训练主干／提议网络，未使用付费计算。定位候选的增加同时付出了更高局部推断开销；上述耗时不是全生命周期成本，也不是正式强对照。
