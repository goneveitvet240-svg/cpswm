# 结构二：类型化提议线失败门结案（2026-09-02）

协议：`structure-two-backbone-falsifier@0.1`
结论等级：**Failed gate（验证门失败）**
决定：**停止在该线上调整超参，转任务 8。**

## 1. 被判定失败的是什么

「类型化粒子提议（观察锚定的候选邻域 + 逃逸混合），无论固定半径还是自适应，
在匹配预算下优于普通 RBPF」这一主张。**七个算子中的类型化修订能力不被删除**——
按统一总纲 §0.7，失败门触发的是 redesign 或搁置，不是缩减框架。

## 2. 三个独立轴一致否定

| 轴 | 证据 | 出处 |
|---|---|---|
| 后验质量（TV） | $G=1$：RBPF 用 1/3 的基础似然调用拿到 4.8 倍更好的 TV（0.048 vs 0.228） | `..._redesign_and_correction_v0_2_2026-09-02.md` |
| 真值覆盖 | $G=2$：等 elementary 时 RBPF 11/12 vs 类型化臂 7/12 | 第三组两轮审核 |
| 决策相关指标 | RBPF 用 **1,920** 次基础似然调用达到的水平，与自适应臂用 **222,240** 次的在噪声内不可区分 | `..._interface_v0_3_2026-09-02.md` |

**116 倍的代价买不到可测量的收益。**

## 3. 已经试过、且不再继续的补救

- 固定 $\le1$ 轴邻域 → $K=1536$ 被 RBPF 反超（覆盖天花板，真值覆盖饱和在 0.55）；
- 自适应邻域半径 + 自适应逃逸（`fit` 用未解释轴数，尺度无关）→ 相同粒子预算下的领先
  **落在种子噪声之内**（差 `0.0042`，差值标准误 `0.0055`，$n=48$）；
- `_legal_gaps` 记忆化（消掉 72–86% 的重复构造）→ 只改墙钟，计数器完全不变。

三次补救之后结论方向没有变化。继续调 `ADAPTIVE_FIT_TARGET`、半径上限或 $\varepsilon$ 边界
只是在噪声里挑数字，本文件据此关闭该线。

## 4. 这个失败**不**证明什么

- 不证明类型化约束在真实家庭数据上无用——本仪器是 D0 合成，$G\le2$；
- 不证明结构二的七算子框架有问题——被否的是一个提议器设计，不是一项能力；
- 不证明摊销提议无用——神经提议器从未在本仪器上运行过（它自己的失败门在 2026-08-29）。

## 5. 重新打开的条件（预先写死，避免事后找理由）

同时满足才可重开：

1. 有一个 $G\ge3$ 的任务，且 bootstrap 提议在其上真值覆盖 < 0.3
   **且该覆盖在 $K\ge6144$ 处仍然 < 0.3**（不绑预算口径的话，这个子句在小 $K$ 下平凡为真、
   在 $K{=}6144$ 下平凡为假——$G{=}2$ 实测 RBPF 覆盖 $K{=}384$ 时 `0.000`、$K{=}6144$ 时 `0.667`）；
2. 在该任务上，类型化臂在**等基础似然调用**口径下的决策相关指标优于 RBPF，
   且差值 > 3 个标准误、跨 ≥5 个 scenario seed 稳定。
   **参照分布由一个高预算 RBPF 参考臂给出，不得要求精确枚举**——
   初版把条件 1（精确不可行）与条件 2（指标以精确后验为参照）写在一起，
   两者互斥，那个门按字面读永远无法被满足；
3. 优势不依赖任何未经扫描的超参默认值。
