# 结构二：四项实际能力交付与监督映射

日期：2026-09-15。接续 PR23；完整 H/R/I/C/Z/r/V、三个 RB blocks、七功能算子、Route C、Architecture A、P5_FIRST、位置＋朝向及本地小预算均保留。

六操作是粒子提议／修订操作：branch、revise、retract、reactivate、rejuvenate、preserve_unresolved。它们与 OPCEU、ORRER/CHEH、PCHMP、CF-BOCPD、CCRR、RGRC、CIAV 七功能算子是不同层次。

## 四项交付和实际边界

| 优先项 | 实际入口／本批产物 | 本批验证 | 尚未交付 |
|---|---|---|---|
| 可用语义候选 | 既有 NaturalVisionEvidenceProducer、人物／物体几何关联；核查公开手物体接触模型下载 | 既有真实回放只支持框／关联；本批未产生新的真实角色候选 | 独立标注自然多人片段、可靠交接物体、手部接触／释放、跨遮挡身份与角色事件似然；自然生产者仍未返回 GroundedTransition |
| 完整主干训练和消费 | proposal_learning.py 完整九因子监督与兼容集可微损失；pose_observation_model.py 实测位姿输入的偏差／完整协方差拟合及三块条件统计消费；fit_pose_observation_model.py | 完整六操作样例、九列梯度、合成闭式协方差／留出NLL、纠正／撤销与重算 | 像素位姿估计器、真实测量标定、角色/习惯等条件项生产者、三架构完整解码器与训练循环、原生六操作监督 |
| 同次运行模型选动作 | ContinuousEvidenceInput.current_joint_decision_view → prepare_posterior_observation → 原有 execute_observation／resume | 配置 P5-first 路径、实际原生后验投影／候选消费、CIAV选择或停止、执行夹具回传新原始输入、同库恢复不重发 | 经过独立校准的真实动作—观测似然、自然视觉语义返回、同一次真实人物运行多解释→行动→晚反证→撤记忆→下一行动变化 |
| 冻结版本比较与恢复 | 本批源码冻结、专项及相邻回归、独立审核；记录工程验证时间／CPU／峰值RSS | 仅覆盖本批工程证据 | 同一实际完整主干上的强对照、Task7五臂、关键耦合、真实任务质量与全生命周期成本；不以工程耗时替代科学比较 |

本表的新增接口不是另一个默认完整主干。损失接口不等于训练器，位姿测量模型不等于像素姿态检测器，当前相机策略入口不等于已校准物理策略。需要真实生产连接后才能签收完整能力。

## 七轴：输入、监督、运行时消费

损失顺序与既有概率回执共用 `proposal_factor_values`：operation → parent → H → R → I → C → Z → r → V。`model_input` 只取可见前缀、父假设、修订上下文和合法支持；完整目标与标注来源保持分离。不截断历史，不把真值列表当推断候选支持。

| 轴 | 模型可见输入 | 独立监督／运行轨迹来源 | 运行消费 |
|---|---|---|---|
| H 隐藏事件链 | 已见物体、时间、接触／释放、遮挡与历史假设 | 多条兼容事件序列；未观测处保留 unresolved，不强制唯一链 | ORRER/CHEH 分支，PCHMP 约束与联合推断 |
| R 有序角色 | 人物轨迹与可见手物体交互 | pickup_actor、carrier、handoff_giver／receiver、placer 的时间顺序和不确定标注 | PCHMP 责任归因，禁止仅凭同框写入人物习惯 |
| I 实例关联 | 检测／外观／几何支持及已有实体 | 独立轨迹对应、遮挡后关联与未知实例 | 候选身份约束；与 R、H 保持联合相关性 |
| C 变化原因 | 任务、检测条件、反馈、历史残差 | observation／actor／identity／habit／noise／unresolved 原生原因证据；不可由动作结果单独指定 | CF-BOCPD 原因后验、RGRC 污染门控 |
| Z 阶段 | 历史已知阶段、变化证据 | stay／create／reactivate／unresolved 及阶段身份 | CCRR 阶段恢复与条件统计 |
| r 运行长度 | 完整到达顺序与原生修订轨迹 | 依据轨迹重算，不从文件名或人工递增猜测 | CF-BOCPD/阶段持续性 |
| V 修订谱系 | 父粒子、修订上下文、现有账本引用 | 原生父子关系、替代区间、撤销与重放结果 | 唯一账本、修订与可逆巩固；神经输出不能授予写权限 |

## 六操作：需要怎样的训练目标

| 操作 | 必须对应的实际情形 | 需要的监督 |
|---|---|---|
| branch | 当前观测允许多个事件／人物解释 | 真实父粒子及完整兼容候选；不只监督 top-1 |
| revise | 新证据修订既有解释 | 新旧修订对应与证据依赖；不得伪造无父修订 |
| retract | 反证撤去既有支持 | 被撤销谱系与原生账本后果；不能只有 retract 标签 |
| reactivate | 原有习惯阶段重新出现 | 可追溯的历史阶段与新证据；不把创建新阶段当恢复 |
| rejuvenate | 重采样后替换历史后缀 | 被替代修订区间、完整后缀、必要重放；不能作为追加新事实 |
| preserve_unresolved | 证据不够或支持在开放世界之外 | 未决候选及质量；不得强填角色、实例或姿态 |

`compatible_proposal_nll` 对完整候选计算 `-log(sum q(compatible full proposal | visible prefix))`，保留九因子的梯度。模型必须给出真实完整支持上的条件概率，不能只在标注候选之间归一化。当前接口会检查基本质量与顺序，但不证明尚未实现的解码器正确。

## 测量与条件统计

位姿模型拟合的是同一估计器、领域、坐标系／局部旋转参考下的六维误差：位置以米计、旋转在参考物体局部坐标以弧度计。使用独立标签估计偏差和完整协方差；留出按序列及输入去交叉，输出NLL、Mahalanobis与分量RMSE。不会自动设科学通过阈值。

`PoseConditionalHistory` 将偏差修正后的测量交给既有 `ConditionalMeasurement`／`rebuild_conditional_state`；Dirichlet位置质量与RLS特征／目标／权重仍必须来自各自模型，不能由位姿置信度冒充。纠正替换同簇保留输入；撤销删除输入后从先验重算全部三块。对象／时间／参考变化不能隐式当作静止世界；跨时间预测和重新线性化仍需另外实现。

标注声明、文件摘要和模型ID仅给出可追溯性，不证明标注真实或误差分布适用。对称物体或多峰朝向必须保留多假设／未知；单高斯接口不替代这些情况。

## 相机策略与比较接续

动作读取当前原生批次的完整原子（包括未决质量），调用系统已有CIAV规划器，消费与该后验绑定的观测似然、任务效用和代价。选择出的动作映射为明确的 Pass／RotateLeft／RotateRight 请求；完整决策问题随命令持久化。无有益动作时停止，旧问题不能替代当前后验，执行成功／失败由执行器返回并进入同一原始历史。

真实语义生产者、测量模型和动作观测模型连通后，按原协议在同一源码上运行：合法强对照；`reservoir_only`、`backward_message_only`、`combined`、`full_rerun_reference`、Task7 v0.4历史失败实现五臂；关键耦合。记录采集、推断、训练、重采样、修订、动作等待、恢复、数据准备和存储成本，保持工程诊断与正式确认分开。B持有的比较与跨机验收文件由B继续维护。

本地训练准备继续沿用 `structure_two_pose_local_development_v0_1.json`：三架构、每架构三种子、CPU两线程、每次最多1500步／300秒、批次最多9次；这些上限是后续训练器必须执行的预算，当前损失函数并不等于已经执行预算控制。合格输入缺失时不开始伪训练。
