# 覆盖范围

第一审：人物全身/局部嵌套、多人物重叠、分离框均保留两种物理身份解释；三人物三对六角色完整、检测重排序、轨迹中断、重复轨迹拒绝、单人无虚构人物对。另含既有连续原帧、ROI、手物、恢复和提议语法回归。

第二审：同一完整检查点删除同人分支、删除所有身份对、角色错引 pair、伪造已确认身份、篡改 IoU、置换轨迹；拒绝必须原子，随后原合法检查点成功恢复。完整伪造所有检测置信及重算所有派生关系可以通过一致性恢复，实际 infer 仍无语义输出。另执行整个可接受多人物检测 → 连续观测 → 完整候选 → 恢复 → 实际 core/snapshot/ledger/execution traces 检查，以及既有重封包来源攻击。

这里没有选择联合人物划分，也没有身份概率。两两假设不能随意独立选择；下游联合推理必须满足同一身份的传递性。当前身份尚未解决，角色只是条件候选。真实重叠人物正路径由受控几何夹具验证；HFD 原样本不是独立多人交接金标准。

A 自审，不是 B 验收。覆盖是该组件和本次实际后果路径的局部审查；不宣称统一研究框架全面验收、所有欺骗性输入安全或模型执行真实性认证。
