## 第二轮：数学与实现

### 先确认无误的部分（均为数值验证，非读码推测）

- `AnalyticBlock.log_marginal()` 的高斯部分：与独立闭式推导、与一步预测分解、与 20 万次
  蒙特卡洛 $\int p(y\mid\theta)p(\theta)\,d\theta$ 三路一致。公式正确。
- Dirichlet-multinomial 部分：与 40 万次 Dirichlet 采样直接积分一致。
- `_det3` / cofactor 求逆：与 Leibniz 展开、独立线性求解一致。
- `_systematic_resample`：4 组权重 × 20 万次重复，无偏且满足 systematic 的确定性保证
  $\lfloor Nw\rfloor\le \text{count}\le\lceil Nw\rceil$，0 次违反。无 off-by-one。
- `_prior_log_density` 与 `_sample_prior_gap` 同分布：100 万次采样、948 个 cell 的卡方检验
  $\chi^2=972.2$（df=948，$z=0.56$）。DIRECT 下 receiver 不独立采样的处理正确。
- sampled-$\theta$ 与 RB 的**序贯**权重对同一目标无偏（40 万次 MC 交叉验证）。

### 三个真 bug（全部已修，且都补了确定性回归测试）

**F1/F4 —— 度量退化，最严重。** 旧实现在收尾时丢弃全部粒子权重，改用精确目标对
已发现 support 重新打分。后果是报告的 total variation **恒等于** $1-P_{exact}(\text{support}\cup\{\text{unresolved}\})$。
本轮独立复现，误差 $\le5.6\times10^{-17}$：

```
rbpf        TV=0.716940446   1−P_exact(sup∪unres)=0.716940446   差=0.00e+00
typed_rbpf  TV=0.413539114   1−P_exact(sup∪unres)=0.413539114   差=5.55e-17
```

也就是说这台仪器只在测「提议找到了多少目标质量」，从不惩罚权重错误——**这正是让旧仪器
退役的那类病换了一种形式**（旧的是"精确枚举+排序截断"，新的是"精确重打分+采样截断"）。
在 sampled-$\theta$ 臂上后果更坏：收尾时每条链现抽新 $\theta$，噪声项随预算单调增大，
以至于该臂的 TV 在 384→1536 之间**反向上升**（0.692→0.749），而它真实找到的质量还在变好。

**修复**：后验改为粒子自归一化权重，未决质量通过 SMC 证据估计 $\hat Z$ 与 $\tilde p_{unres}$
的比值给出；覆盖率作为独立指标 `proposal_coverage` 由评估器单独报告，绝不冒充 TV。

**F2 —— typed 臂逃逸分支漏乘 $\varepsilon$。** 逃逸采样落在 typed 候选集之外时，代码用了
$q_{prior}$ 而非 $\varepsilon\cdot q_{prior}$，`log_q` 偏大 $\log(1/\varepsilon)=2.3026$ nat。
枚举验证：某真实场景的 948 个合法后继中 942 个只能经逃逸分支到达，每一个的偏差**恰为 +2.3026**；
一步归一化常数估计量的期望比值 0.685566，与预测的 $m_{in}+\varepsilon m_{out}$ 完全吻合。
端到端 $\log\hat Z$ 低偏 0.38–0.52 nat。**已修**，并补了确定性回归测试
`test_importance_weights_estimate_the_normalizer`（枚举真值，容差 0.15 nat）。

**F3 —— ESS 在最后一次重采样之后测量。** 重采样把权重全置 0，于是退化最严重的两臂报满分 ESS，
唯一健康的臂反而报低分。独立复现：

```
sampled_theta_pf ESS=[48.0, 48.0, 48.0]   rbpf ESS=[48.0, 48.0, 48.0]   typed_rbpf ESS=[46.7, 45.4, 43.6]
```

**已修**（最后一步不重采样，ESS 与 support 在 reweight 之后取），并补回归测试。

**F8 —— `action_regret` 退化路径。** 近似臂把全部质量放进 unresolved 时动作边缘全为 0，
`argmax` 静默返回 bin 0，于是「什么都没预测」的臂在 bin 0 恰为最优时拿满分。
**已修**：改为返回 `None`（弃权），并由扫描单独报告 `action_abstention_rate`。

### 设计选择，不改实现但必须声明（已写入协议）

- **F9 先验口径**：`_AXIS_PRIOR` 是未归一化势函数。$G=1$ 下目标隐含的实际先验为
  `habit 0.232`（声明 0.20）、`stay 0.788 / unresolved 0.172 / create 0.039`（声明 0.55/0.12/0.18），
  admissible gap 上先验总质量 0.698。各臂共用同一目标，比较仍然公平，但论文不得引用声明值。
- **F6 成本计数器口径**：bootstrap 分支每次采样只记 1，typed 分支按候选逐个计数，
  且两者上游构造的约 990 个候选都不计数——typed 的真实生成量被低估约 50 倍。
  真实工作量以 `elementary_likelihood_evaluations` 和墙钟为准。已写入协议 §3.1。
- **F7 连续块的信息量**：$G=2$ 抽样下离散项 sd=5.179，连续项 sd=0.629 且只有 19 个不同取值。
  RB 化作用的那个分量本身携带的关于 $\chi_t$ 的信息只有离散项的约 1/8，这削弱 B→C 对照的功效。

## 第三轮：跨产物、可绕过性、修复自检

### R3-1 · 病灶是可复发的，必须写成常设禁止

旧仪器与新仪器 v0.1 的病同源：**任何用 oracle 目标去重新打分某臂输出的度量，测的都是那个臂的
support，而不是它的估计量。** 旧的截断来自排序，新的截断来自采样，形式不同、后果相同。
本轮已把这条写进协议作为常设禁止项，而不是当作一次性 bug 修掉了事。

### R3-2 · 降级纪律必须适用于我自己的结果

bring-up artifact `artifacts/project_two_v04_development/structure_two_backbone_falsifier_bringup_v0_1.json` 与首次扫描 `artifacts/project_two_v04_development/structure_two_backbone_budget_sweep_g1_v0_1.json` 是在
有缺陷的度量下产生的。它们**不被改写、不被删除**，而是加注取代声明，与本轮对旧粒子证伪器
的处理完全一致。bring-up 文档 §4 的「8/8」结论作废。

### R3-3 · 修复后，C→D 的方向性结论被推翻

把 $G=1$ 预算扫描扩到 $K=1536$（协议原定只到 96）：

| $K$ | TV：sampled / rbpf / typed | 真值覆盖：sampled / rbpf / typed |
|---:|---|---|
| 96 | 0.803 / 0.664 / **0.453** | 0.150 / 0.133 / **0.500** |
| 384 | 0.621 / 0.400 / **0.365** | 0.450 / 0.383 / **0.533** |
| 1536 | 0.388 / **0.192** / 0.242 | 0.733 / **0.783** / 0.550 |

**typed 臂的优势只在 $K\le384$ 成立，$K=1536$ 时被 RBPF 反超**：$\le1$ 轴偏离的候选邻域
构成覆盖天花板（真值覆盖在 0.55 附近饱和），而两个 bootstrap 臂继续改善。
若按协议原定的 $K\le96$ 收工，会得到"typed 一直最好"这个方向相反的结论。
协议 §4 已改为强制包含 $K=384,1536$。

### R3-4 · B→C 的收益成立，但机制未证实

RB 的收益稳健且随预算增强：$K=1536$ 时 ESS 201.2 vs 45.7（4.4×），TV 0.192 vs 0.388（2×）。
但结合 F7，该收益可能主要来自"不把采样噪声注入一个低信息量的项"，而不是"对一个信息丰富的
参数做解析边缘化"。**机制归因未解决**，登记为 Unresolved。

### R3-5 · $G=1$ 时"局部提议"实为全局构造

实测：初始粒子的 `_legal_gaps` 返回 **948** 个后继，恰等于 $G=1$ 的 admissible 链总数；
其中只有 19 个（2.0%）被 typed 打分。禁止令强制在**整链枚举入口**，逐间隙后继集合仍完整构造，
$G=1$ 时二者重合。因此 $G=1$ 的一切结论都必须带这条限定；只有 $G\ge2$ 在这条轴上是干净的。

### R3-6 · 一条设计因子从未被取反

`registered_scenarios` 里 `open_world_actor = seed % 2 == 1`，而 bring-up 与两次扫描用的
scenario seed 全为奇数（11/23/37/41/53）。该因子在所有已登记运行中恒为 True，从未对照。

### R3-7 · 墙钟轴上，$G=1$ 没有任何近似臂优于精确枚举

精确枚举 $G=1$ 为 0.0104 s / 948 states。修复后的扫描：

| $K$ | typed 墙钟 / 相对精确 | rbpf | sampled-$\theta$ |
|---:|---|---|---|
| 24 | 0.0152 s / **1.46×** | 0.03× | 0.03× |
| 96 | 0.0613 s / **5.89×** | 0.12× | 0.10× |
| 384 | 0.2447 s / **23.5×** | 0.46× | 0.41× |
| 1536 | 0.9799 s / **94.0×** | 1.85× | 1.67× |

在 $K=1536$（即近似臂真正接近后验的那一档），**三臂全部慢于精确枚举**。
$G=1$ 因此不存在近似臂在墙钟上取胜的区间；只有 $G=2$（精确 16.70 s / 901,008 states）
才有——那里 typed 为 0.031–0.478 s，快 35–540 倍。任何 accuracy–compute 结论必须区分这两档。

### R3-8 · 修复自检：未决质量的 SMC 估计校准良好（正面结论）

新的未决质量依赖 SMC 证据估计 $\hat Z$，存在被噪声污染的风险。实测（10 个独立种子）：

```
exact unresolved = 0.004235
K=8     mean=0.004286  sd=0.001751     K=96    mean=0.004441  sd=0.000906
K=24    mean=0.004927  sd=0.001758     K=1536  mean=0.004256  sd=0.000293
```

无偏且随预算收敛。该修复未引入新问题。

### R3-9 · 新回归测试的容差不是预注册的

`test_importance_weights_estimate_the_normalizer` 的 0.15 nat 容差与预算 4000 由作者选定，
只覆盖 $G=1$。它足以捕获 F2 的 0.38 nat 偏差，但不是预注册阈值。

### R3-10 · 证据链在版本控制之外

`.gitignore` 忽略整个 `artifacts/`。证据总表要求每条主张可追溯到 artifact，
而协议又要求记录 git commit——两者当前无法同时满足。这是既有结构性问题，本轮新增
四个 artifact 使其更突出。
