# 原始证据保存方式

独立审核脚本按执行时原始字节保存为 `.py.gz`，解压后恢复原报告中引用的 `.py` 文件名；原始摘要见 ARCHIVED_SCRIPTS.json。独立审核者的原件保留在各自 /private/tmp 审核目录。不能对已执行脚本运行格式化后仍称其为原执行版本。

文档首次提交被统一 Ruff hook 拒绝并自动格式化了归档副本；该提交没有成功。已从审核者原件恢复并无损压缩，未绕过生产源码检查，也未用格式化后的副本覆盖原执行证据。原始报告提到的脚本名需要先解压；bundle 保存独立伪造输入的Git对象/引用，真实输入仍以固定Git SHA读取。

result/started JSON 压缩后解压可读取完整源码摘要；JUnit与日志原样保存。comparison_bundle_01 中 audit.json/timing.json 额外压缩，steps.jsonl.gz 保留原格式。该包未独立重算，不能单独签收比较链。所有失败/预期拒绝分开记录；清单自身仅是本地保全，不是外部独立托管认证。
