## 1. 不可缩减范围与权限原则

本方法保留 OPCEU、ORRER/CHEH、PCHMP、CF-BOCPD、RGRC、CCRR、CIAV 七个算子，
以及选择性观察、隐藏事件、多人责任、开放世界未知、非平稳阶段、可逆归因、主动验证和
具身反馈全部能力。选择这一推断主干不把五条同级跨领域技术路线中的任何一条降为附属项。

三层权限固定为：

1. neural amortized proposer（神经摊销提议器）只能 `propose and score`；
2. typed particle revision（类型化粒子修订器）只能 `normalize, constrain and revise`；
3. reversible RGRC ledger（可逆 RGRC 账本）是长期记忆唯一 `commit` 权威。

任何调用方不得用神经 top-1 输出直接修改个体习惯，不得让结构化修订器绕过 RGRC 写入，
也不得让 CCRR 的阶段目的地提案自授权提交统计量。

## 2. TypedParticleState：类型化粒子状态

时刻 $t$ 的信念由带显式未决质量的粒子集合表示：

\[
\mathcal B_t=
\left\{
(\chi_t^{(i)},w_t^{(i)},S_t^{(i)},\ell_t^{(i)})
\right\}_{i=1}^{N_t}
\cup \{w_t^{unresolved}\}.
\]

每个离散粒子为：

\[
\chi_t^{(i)}=
\left(
H_t^{(i)},
R_t^{(i)},
I_t^{(i)},
C_t^{(i)},
Z_t^{(i)},
r_t^{(i)},
V_t^{(i)}
\right),
\]

其中：

- $H_t$：完整事件链，不是单个事件标签；
- $R_t$：`pickup_actor → carrier → handoff_giver → handoff_receiver → placer`
  等有序人物角色；
- $I_t$：实例关联或 `unknown_instance`；
- $C_t\in\{observation,actor,identity,habit,noise,unresolved\}$：变化原因；
- $Z_t$：`stay/create/reactivate/unresolved` 的阶段目的地；
- $r_t$：阶段 run length（游程长度）；
- $V_t$：事件、粒子和账本修订谱系。

粒子还必须绑定：

- `source_snapshot_id`；
- `event_hypothesis_id`；
- `revision_id / parent_revision_id`；
- `statistic_state_ref`；
- `ledger_lineage_ref`。

禁止跨快照拼接粒子，也禁止非 `habit` 原因直接创建或恢复主人习惯阶段。

### 2.1 Rao–Blackwellized analytic state

以下状态不逐个采样，而在每个离散粒子条件下解析维护：

\[
S_t^{(i)}=
(\alpha_t^{(i)},A_t^{(i)},b_t^{(i)},
\Lambda_t^{(i)},\xi_t^{(i)}).
\]

分别对应：

\[
\alpha=\alpha_0+\sum_c\Delta\alpha_c,
\]

\[
A=\lambda I+\sum_c w_cx_cx_c^\top,
\qquad
b=\sum_cw_cx_cy_c,
\qquad
\theta=A^{-1}b,
\]

\[
\Lambda=\Lambda_0+\sum_c\Delta\Lambda_c,
\qquad
\xi=\xi_0+\sum_c\Delta\xi_c.
\]

阶段内遗忘因子固定为 1。分布变化由显式阶段竞争处理，不能用无来源指数遗忘替代。

## 3. Neural amortized proposal kernel

神经提议器从冻结的更新前快照和当前证据簇生成候选：

\[
\chi_t^{(i)}\sim
q_\phi
\left(
\chi_t\mid
\chi_{t-1}^{a(i)},c_t,\mathcal B_{t-1}
\right).
\]

其中 $a(i)$ 是父粒子索引。提议动作必须覆盖：

```text
branch / revise / retract / reactivate / rejuvenate / preserve_unresolved
```

提议器的目标首先是 truth-compatible Top-K recall（真值兼容 Top-K 召回），不是只优化
top-1 accuracy。候选集必须始终包含开放人物、开放实例和未决后备项；规则生成候选可与
神经候选并存，防止 proposal bottleneck（提议瓶颈）使结构化层无法恢复真值。

神经分数只定义 proposal log probability（提议对数概率）或结构化势函数，不天然视为校准
后验，也不拥有证据晋升和长期写入字段。

## 4. Structured particle revision kernel

### 4.1 重要性权重

每个候选粒子的未归一化权重为：

\[
\widetilde w_t^{(i)}=
w_{t-1}^{a(i)}
\frac{
p_\theta(\chi_t^{(i)}\mid\chi_{t-1}^{a(i)})
p_\theta(c_t\mid\chi_t^{(i)},\pi_t^{obs})
}{
q_\phi(\chi_t^{(i)}\mid\chi_{t-1}^{a(i)},c_t)
}
\prod_j\psi_j(\chi_t^{(i)},c_t).
\]

实现使用 log domain（对数域）。

\(\psi_j\) 必须至少覆盖：

- physical event constraint（物理事件约束）；
- ordered role constraint（有序人物角色约束）；
- identity constraint（实例关联约束）；
- provenance constraint（来源约束）。

OPCEU 提供 observation likelihood（观测似然），CF-BOCPD/CCRR 提供原因、游程和阶段
转移先验。硬约束失败的粒子质量为零，并必须保存 rejection reason（拒绝原因）。

### 4.2 显式未决质量

归一化必须包含：

\[
\sum_{i=1}^{N_t}w_t^{(i)}+w_t^{unresolved}=1.
\]

`unresolved` 不是异常退出路径，而是正式后验状态。当现有观察无法区分 actor change 与
habit change，或真实事件链没有充分支持时，概率质量必须留在未决项，等待 CIAV 或迟到
证据。

### 4.3 重采样与 rejuvenation

重采样策略尚未选择，但必须满足：

1. 不得因为重采样删除全部 unknown/unresolved 支持；
2. 必须记录父粒子和随机种子；
3. 迟到证据可对受影响时间后缀执行局部 rejuvenation；
4. rejuvenation 不能被记作 append-only 新事实；
5. 若局部修订与完整重跑不等价，必须触发 replay fallback（重放回退）。

## 6. Reversible Commit Protocol

一个证据簇产生不可分割的统计增量束：

\[
\Delta S_c=
(\Delta\alpha_c,\Delta A_c,\Delta b_c,
\Delta\Lambda_c,\Delta\xi_c).
\]

RGRC 根据粒子边缘后验产生准入建议，但实际提交只能通过现有 HybridStatisticLedger。
原子单位固定为 `evidence_cluster_statistic_bundle`，合法操作固定为：

```text
quarantine → promote → retract
quarantine → corrected_revision
retracted lineage → corrected_revision/reactivated contribution
```

提交协议强制：

- evidence-cluster/semantic-dedup 单次生效；
- 人物责任、原因、阶段、授权和来源绑定；
- 多键统计增量整簇原子提交；
- downdate 数值不稳定时从日志重放；
- 每次实验提交 full-rerun equivalence receipt；
- 神经提议器和粒子修订器均无直接账本写权限。

## 7. 训练协议

### 阶段一：proposal coverage

\[
\mathcal L_{proposal}
=-
\log\sum_{h\in\mathcal H_{truth-compatible}}
q_\phi(h\mid D).
\]

优先验证事件链、未知人物、交接角色、实例关联和原因候选的 Top-K 覆盖。

### 阶段二：structured posterior

\[
\mathcal L_{structured}=
\lambda_H\mathcal L_H+
\lambda_A\mathcal L_A+
\lambda_I\mathcal L_I+
\lambda_C\mathcal L_C+
\lambda_Z\mathcal L_Z+
\lambda_{cal}\mathcal L_{cal}.
\]

训练数据必须使用相同可见输入，封存 evaluator truth 不得进入提议器或势函数。

### 阶段三：decision-aware optimization

主要优化目标仍为：

\[
\min_\theta
\mathbb E\left[\sum_tL_{action}(a_t,X_t)\right],
\]

并受以下不可抵消约束：

\[
\begin{aligned}
OwnerContamination&\le\epsilon_c,\\
RecoveryLatency&\le\epsilon_r,\\
FullRerunError&\le\epsilon_f,\\
PrivacyViolation&=0,\\
ProvenanceViolation&=0.
\end{aligned}
\]

是否采用 differentiable SMC（可微 SMC）、交替优化或分阶段冻结仍为用户待选绑定，不在
本回执中伪装成已经确定。

## 9. 当前未决绑定与声明边界

**2026-09-02 证据降级。** 2026-08-28 的 finite exact-enumeration conformance falsifier
（有限精确枚举符合性证伪器）及其 v0.2 结构化联合复苏门经代码级核验后降级为
**contract conformance + normalization check + finite-state truncation behavior**，
不再作为本方法的收益证据。

被撤回的表述包括：typed particle revision 比精确枚举更高效、rejuvenation 的计算优势
已获支持、Rao–Blackwellization 的收益已获支持、neural amortized proposer 已获支持。

降级理由（完整清单见两份实验报告顶部的「证据降级与仪器局限」一节）：该仪器的状态空间
是静态的 360 个 `LatentState`，两帧证据条件独立，`transition_log_probability` 恒为 `0.0`，
`statistic_state_ref` 仅为占位字符串因而 $S_t=(\alpha,A,b,\Lambda,\xi)$ 完全不存在，
提议分布为均匀且全部 $\psi_j$ 被接受（重要性权重退化为截断支持上的精确贝叶斯），
并且 `_beam_result` 与 `_typed_particle_result` 都通过 `_top_states` 先对全部 360 个状态
计算精确 log target。因此该仪器无法对本方法的三个卖点（RB 化、类型化约束、摊销提议）
施加任何压力，也不存在成立的效率比较：两个"近似"方法的候选评分数按构造都不低于
精确枚举本身。

`526.625` 矛盾**——2026-09-02 的三轮审核查明二者相差恰好一个粒子预算 `K=24`
