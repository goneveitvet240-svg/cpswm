# 方向结构二推进记录：M30 多种子匹配死亡测试与 CHEH 重构

日期：2026-08-21
范围决定：OPCEU、CHEH、PCHMP、CF-BOCPD、RGRC、CCRR、CIAV 全部保留并组成一篇统一论文。本轮失败用于重构 CHEH，不用于删除隐藏事件、同屋多人或未知人物能力。
当前结论：multi-seed matched death test（多随机种子匹配死亡测试）已经实现并运行；当前 CHEH 没有超过独立调参的 Damen–Hogg 2012 AMG 领域适配，而且不能表示 unknown handoff（交给未知人物）。论文创新主张仍不成立。

## 1. 已有覆盖提醒

必须继续正面保留两个强近邻：

1. Bernert & Ramparany 2021 已经探索连续观察之间所有 compatible event sequences（兼容事件序列），所以“保留所有端点兼容解释”不是 CHEH 创新；
2. Damen & Hogg 2012 已经用 AMG、Bayesian network（贝叶斯网络）、事件似然、角色/共享约束和多种搜索求 global MAP（全局最大后验），所以“给 direct/handoff 加事件似然或角色约束”也不是创新。

本轮 2012 对照仍是 object-relocation domain adaptation（物体移动领域适配），不是其视频检测器、半高斯特征训练、RJMCMC-SA 或 IP solver 的完整复现。它足以直接威胁当前 CHEH 的完整链选择主张，但论文实验还需要更忠实的实现和外部数据。

## 2. 死亡测试协议

运行入口：

```bash
PYTHONPATH=src .venv/bin/python apps/evaluation_runner/run_m30_hidden_event_death_test.py
```

### 2.1 场景与拆分

默认生成 80 个确定性可复现实例：

- 2 个 validation seeds（验证随机种子）× 10 个场景族 = 20 个实例；其中 16 个已知人物实例用于调参，4 个未知人物实例不进入调参；
- 6 个 held-out test seeds（留出测试随机种子）× 10 个场景族 = 60 个实例；
- 每个 seed 改变家庭、人物、物体、会话、日期和受控人物证据强度，不只是复制 UUID；
- 每个机制都有 direct/handoff 成对版本：clean、delayed evidence、identity noise、duplicate cluster、unknown actor。

10 个场景族是：

| 机制 | direct | handoff |
|---|---|---|
| 干净人物证据 | `clean_direct` | `clean_handoff` |
| 迟到人物证据 | `delayed_direct` | `delayed_handoff` |
| 先错后纠身份噪声 | `identity_noise_direct` | `identity_noise_handoff` |
| 相关重复证据簇 | `duplicate_cluster_direct` | `duplicate_cluster_handoff` |
| 未知最终人物 | `unknown_direct` | `unknown_handoff` |

### 2.2 公平比较约束

| 约束 | 实现 |
|---|---|
| 相同输入 | 所有方法共享完全相同的 before/after endpoints（前后观测端点）和累计人物证据 |
| 独立调参 | CHEH 搜索 3 个 handoff fraction × 2 个 retraction threshold；AMG 搜索 3 个 handoff event likelihood |
| 防测试集泄漏 | 只用 validation known-actor cases 选超参数，随后冻结并评估 60 个 test cases |
| 公平迟到证据 | 无状态方法在迟到证据到达后允许从相同累计证据完整重跑；结果记为 `full_rerun`，不冒充 `append_only_revision` |
| 假设边界 | 2021/2012 当前适配的 closed-known-actor assumption（封闭已知人物假设）外案例单独报告为 unsupported，不混入主成绩 |
| 真值隔离 | 模型输入契约不含完整链、责任人物或场景真值；真值只在 benchmark capability（基准能力）侧评分 |

人物证据属于 controlled-noise track（受控噪声轨），用于测试推断与修订机制，不代表真实人物感知已经解决。人物责任高分不能被写成真实世界成绩。

CHEH 的 family-level diagnosis（场景族诊断）更重要：

- 所有已知人物 direct 案例完整链 Top-1 = 1.0；
- 所有已知人物 handoff 案例完整链 Top-1 = 0.0，但真值始终留在候选集合；
- unknown direct 真链覆盖 = 1.0；
- unknown handoff 真链覆盖 = 0.0；
- 所有案例的最终放置责任人物都能被受控人物证据识别。

因此问题不是“看不出最后是谁”，而是当前 evidence update（证据更新）只按 `responsible_actor_key` 重加权，同一最终人物对应的 direct 与 handoff 假设得到相同似然比，链机制只能由固定 handoff prior 决定。多调一个 prior 不能解决实例级机制识别。

## 4. 死亡测试结论

### 已经成立的工程能力

- 完整 direct/handoff 真值和候选生成可复现；
- CHEH 概率质量互斥归一；
- 迟到人物证据产生 append-only revision（追加式修订）；
- 重复 evidence cluster（证据簇）被拒绝；
- 已知人物真链不会被当前阈值误删。

### 没有成立的研究主张

- CHEH 没有超过 2012 AMG 领域适配的完整链 Top-1；
- CHEH 与完整重跑的无状态基线人物恢复率相同，revision history（修订历史）尚未转化成最终任务收益；
- candidate recall（候选召回）已被 2021 方法覆盖，不能作为创新；
- `unknown_actor` 只作为 direct responsible actor 存在，不能承担 handoff recipient/initiator role（交接接收者/发起者角色）；
- 尚未测试错误假设进入长期习惯后的 owner contamination（主人记忆污染）、可逆修复和具身行动效用。

结论是 `CHEH direct baseline failed`，不是项目二失败。完整项目范围保持不变，但当前 CHEH 修订算子必须重构。

## 5. 候选创新：ORRER

下一版拟实现 **Open-world Role-conditioned Reversible Event Revision（ORRER，开放世界角色条件可逆事件修订）**。它不是简单再加一个 handoff classifier（交接分类器），而是四个相互依赖的算子：

### 5.1 Open-world role birth（开放世界角色出生）

- 将 `unknown_actor` 从只能承担 direct 最终责任的特殊标签，改成可进入 initiator、carrier、recipient、placer 四类角色的匿名实体节点 (u_k)；
- 迟到身份关联可以执行 `resolve(u_k → person_j)`、`merge(u_i,u_j)` 或 `split(u_k)`；
- 角色解析改变人物绑定，但不能改写已经观察到的端点或无审计痕迹地替换旧假设。

这直接修复本轮 unknown handoff 真值不在候选集的问题。开放人物枚举本身仍不是充分创新，必须与下面的可逆更新共同验证。

### 5.2 Role-conditioned mechanism evidence（角色条件机制证据）

新增来源受约束的证据因子，而不是只看最终责任人物：

\[
p_{k+1}(h) \propto p_k(h)
\left[\frac{q(A_{place}(h)\mid e_A)}{p_0(A_{place}(h))}\right]^{w_A}
\left[\frac{q(M(h)\mid e_M)}{p_0(M(h))}\right]^{w_M}
\left[\frac{q(R(h)\mid e_R)}{p_0(R(h))}\right]^{w_R},
\]

其中 (M(h)) 区分 direct/handoff，(R(h)) 表示 initiator–recipient ordered role pair（发起者—接收者有序角色对）。每个因子都必须声明 reference prior、endpoint role、evidence cluster、时间和 provenance（来源），防止 posterior 乘 posterior 和相关帧重复计数。

提醒：2012 AMG 已有事件 likelihood 和角色约束。因此论文候选创新不是上述单个乘法项，而是它与开放世界角色出生、跨时间重激活和下游可逆修复组成的在线算子。

### 5.3 Retracted-hypothesis reactivation（已撤销假设重激活）

当前 CHEH 把低于阈值的假设永久置零，后来的纠正证据无法恢复它。ORRER 要保存 immutable pre-pruning score（不可变剪枝前分数）和生成语法；新独立证据到达时可以创建有明确 parent/reason 的 `REACTIVATE` revision，而不是只能从头重跑或永远丢失真链。

直接死亡测试：先用错误身份/机制证据把真链压到阈值下，再给独立纠正证据；比较 CHEH v0.3、ORRER、AMG full rerun 和 fixed-lag smoother（固定滞后平滑器）的恢复、计算量和校准。

### 5.4 RGRC downstream repair（RGRC 下游可逆修复）

每次 CHEH/ORRER 假设对长期习惯的影响必须记录 dependency ledger（依赖账本）。事件后验改变时，RGRC 应撤销旧责任人物的 sufficient statistics（充分统计量）并把质量转移到新人物/新阶段。真正要证明的收益是：

- false owner update（错误主人更新）减少；
- contamination area-under-time（污染随时间面积）减少；
- correction latency（纠正延迟）下降；
- search/return/delivery regret（搜索、放回、递送后悔值）下降。

只有这一段把“有历史”转化成无状态完整重跑无法自动获得的持续学习与具身效用差异。

## 6. 下一轮实现门

下一轮保持完整项目范围，按依赖实现：

1. 扩展 CHEH 物理语法，使匿名未知人物可以担任 handoff 两侧角色；
2. 新增 `EventMechanismEvidence` 和 `RoleBindingEvidence` 的参考先验、簇去重、endpoint/provenance 契约；
3. 实现 `REACTIVATE` revision 和 adversarial identity correction（对抗式身份纠正）测试；
4. 给 2012 AMG 适配同样的 mechanism/role evidence，并重新独立调参，不能只增强 CHEH；
5. 把事件修订接入 RGRC 隔离写入与撤销账本，第一次测长期污染；
6. 之后把 OPCEU 观察代价和 CIAV 主动验证接入同一事件不确定性，测行动效用。

论文表述仍限定为：`matched death test implemented; CHEH failed exact-chain superiority; ORRER redesign specified`。不得写“创新已证明”或“首次”。

## 7. 后续实现结果

ORRER v0.1 已按第 6 节的前四项实现：开放未知交接角色、`EventMechanismEvidence`、`RoleBindingEvidence`、正证据门控 `REACTIVATE` revision，以及获得相同三类证据的 matched open-world AMG。M30 death test 已升级到 v0.2。

留出结果为：ORRER 已知人物完整链和 unknown truth coverage 均为 1.0，但 matched open-world AMG 同样为 1.0。说明表示缺口已经修复，强基线优势仍未成立。下一门已经转移到 ORRER×RGRC 的长期污染、恢复成本和行动效用，不删除任何项目模块。详见 `方向结构二_推进记录_2026-08-21_ORRER开放角色可逆修订与匹配增强基线.md`。
