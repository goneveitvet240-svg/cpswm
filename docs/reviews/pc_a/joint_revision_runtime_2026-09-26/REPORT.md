# 完整提议的三解析块计算与原子推理恢复

本轮把自动生成的完整提议接到实际 Dirichlet（位置统计）、ridge/RLS（岭回归/递归最小二乘自然参数）和六维信息形式位姿状态。原模型评分目标与计算后的统计引用分别保存、精确绑定；条件模型失败时同时回滚神经采样与会话记录。**这是条件统计计算/恢复的局部工程交付，不是六操作活跃粒子集合更新、联合后验发布或自然闭环完成。**

## 实现与实际含义

- ingestion-owned evidence groups（入站方证据分组）必须对全部已到达记录做完整且不重复的划分，并绑定记录正文/到达来源摘要；缺组、重组身份、错源或非正定噪声拒绝。
- 每个候选从同一明确给定的空历史先验开始。所有非撤回提议都按其完整 H/R/I/C/Z/r/V 条件重新计算全历史，保留三个解析块及六维位置＋朝向。观测模型自行产生实际数值，运行库不从 UUID 猜位置、噪声或习惯先验。
- `rejuvenate` 的 replaced revision 是潜在假设替换，不等于撤销原始观测；此阶段采用完整重放回退，不声称局部重算或效率收益。`retract` 保存原父状态作为待执行移除提议，不给它追加新观测。其余操作的实际活跃集合修改留给原生修订内核。
- 原提议目标保持模型实际评分时的 `pending-conditional`/父状态引用；推导出的 `resolved_hypothesis` 只替换统计引用，保留其 scored target hash（已评分目标摘要）。没有改动目标后继续冒用旧 q，也没有把完整枚举候选冒充从 q 抽样的 SMC 粒子。
- 同一会话组合真实神经提议及完整候选条件计算；失败回滚 q 的随机数和记录，模型自身状态逐候选恢复。恢复逐请求重新生成候选、重新运行神经模型、重算三解析块；返回重算结果，不发布调用者提交的缓存统计。
- 先验、条件模型、检查点与快照摘要仍需要外部保管。模型声明的绑定不等于独立校准或来源认证；父状态/分组在本阶段是显式调用依赖，没有取得 core/账本权限。

## 第一轮：修前失败与修复

原有及新增开发测试先得到 466 passed，mypy 363、Ruff 通过；实际三检查点联调却暴露带父历史恢复失败。冻结源码后另设计并复现四个 P2，`round1-attacks-expanded.log` 为 **4 failed**：

| 问题 | 合法或完整攻击路径 | 修复 |
|---|---|---|
| 观察模型标识漂移 | 保留相同 artifact 摘要，在两请求之间改变 observation model id；新请求被接受 | 构造时固定标识，调用、快照和恢复均核验 |
| 回调重入破坏原子性 | 内层真实推理先成功，外层再中断；q 回滚后内层日志仍留存 | 会话处理/快照加入串行重入保护 |
| 合法父历史恢复误拒绝 | 全部模型数值重算相同，但 StateCodec 的不可变对象共享关系改变导致字节差异 | 输入和输出完整重算后才保留原编码；实际返回值仍来自重算 |
| 回滚依赖损坏后继续出快照 | 神经 q 已执行，条件计算失败，同时磁盘检查点损坏使回滚失败 | 会话标为不可继续，要求从保管快照恢复，不输出半完成历史 |

修复后四项与 22 个本轮组件检查共 **26 passed**。最初开发中集合/字典比较错误及变量名复用类型错误的失败日志也保留，不冒充正式审核发现。
