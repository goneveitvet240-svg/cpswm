## 0. 方向效力、位置与不可缩减边界

本文件把下列问题正式确立为 CPSWM 的**方向结构二**：

> 机器人怎样从选择性、稀疏且不完整的长期观察中，持续学习非平稳、同屋多人干扰下的个体物体摆放习惯，推断没有被直接看见的人—物事件，并证明这些信念真正改善机器人决策？

本方向必须持续推进。已有项目覆盖其中某些组成部分，不构成放弃理由；它们应被转化为可复现的强基线，在相同信息、感知、训练和行动预算下验证新方法能否超过。

进一步固定以下执行原则：项目框架内的选择性观察、隐藏事件、同屋多人、非平稳个体习惯、抗污染巩固、历史阶段恢复、主动验证和全部具身下游共同进入一个统一系统，并以一篇方法论文组织。已有系统实现某项功能时，必须提醒该重合并说明其方法和证据等级；随后保留该功能，继续针对其假设、隐变量、更新算子、目标函数或闭环决策共同设计新方法。不得为图省力绕开已有路线，也不得把普通已有实现直接包装成创新。

2026-08-23 进一步冻结跨领域扩展原则：本方向同时保留 **Reversible Belief Data Systems（可逆信念数据系统）**、**Epistemic Information-Flow Control（认知信息流控制）**、**Regime-Localized Reversible Learning（阶段局部可逆学习）**、**Object-Centric Latent Process Inference（对象中心潜在流程推理）**、**Task-Aware Self-Adjusting Decision（任务感知自调整决策）** 五条同级一级技术路线。不得预设其中某一条为中心贡献、把其余路线降为附属模块，也不得用工程实现的先后顺序代替研究地位的主次判断。五条路线共同进入既定统一系统和单篇论文，但分别保留独立方法假设、独立强基线、独立指标和独立失败判据；它们之间的组合效应另行验证。

同时，本方向遵守以下范围边界：

1. 它是总项目中的核心方法研究簇，不是总项目的替代物。
2. 它不取代物体属性、常识与场景理解、移动性画像、多位置记忆、偏好与规范、语言查询、搜索、导航、操作和具身协助等其他主线。
3. 它不是只研究 object search（物体搜索）、re-observation（重新观察）或 verification cost（验证代价）。这些只是信念的下游用途和行动成本之一。
4. 它不是只做一个 next-location predictor（下一位置预测器）。位置、实例身份、行为者、隐藏事件、习惯阶段和观察过程必须共同进入问题定义。

7. 局部算法可以依据实验重构或替换，但不得静默删除上述完整能力、把统一方法拆成多篇独立论文或退回只做其中的容易部分。

## 1. 中心研究对象

### 1.1 四个困难不是四个独立小题

| 困难 | 真实含义 | 单独处理为什么不够 |
|---|---|---|
| selective observation（选择性观察） | 机器人只在路径、任务、视角和资源允许时看到家庭的一部分，缺失不是随机的 | 把“没看到”直接当作“不存在”会制造错误负证据 |
| hidden events（隐藏事件） | 拿起、携带、交接、放置等关键转移常发生在机器人离开后 | 只拟合相邻快照会混淆人物、事件和状态变化 |
| multiple residents（同屋多人） | 主人、家人、访客和机器人会对同一物体产生不同规律 | 家庭级频率会把别人的行为写进主人模型 |
| non-stationary habits（非平稳个体习惯） | 习惯会形成、渐变、突变、周期切换、暂时中断并再次返回 | 静态统计会适应过慢，简单遗忘又会删除可复用的旧规律 |

四者相互作用。例如，机器人夜间很少进入书房，会造成观察偏差；杯子在两次观测之间被不同人物交接；最近搬来的家人改变了杯子的出现频率；如果模型没有同时估计观察机会、行为者和习惯阶段，就可能把“看得少”错判为“主人习惯改变”。

### 1.2 本方向的完整输入与输出

输入不仅是检测到的物体位置，还包括：

- RGB/RGB-D、位姿、视野、遮挡、容器状态和检测质量；
- 机器人任务、路径、观察动作和未观察原因；
- 物体实例候选、属性、功能、归属和相似实例；
- 人物身份候选、在场情况、轨迹和人—物交互；
- 时间、活动、工作日/周末、家庭事件和语言纠正；
- 通用常识、家庭惯例、明确偏好和整理规范。

输出必须同时包含：

- 当前物体位置与状态的后验；
- 实例身份与行为者后验；
- 未观测事件链的多个候选及其证据；
- 人物—物体—情境条件化习惯；
- 当前习惯阶段及历史版本；
- 未来位置、使用者和事件预测；
- 是否观察、询问、搜索、抓取、递送、整理或暂不行动的决策依据。

## 2. 形式化问题

对物体实例 (o) 和时间 (t)，定义潜在家庭状态：

\[
X_t = (L_t,I_t,S_t,A_t,E_t,Z_t,\Theta_t)
\]

其中：

- (L_t)：位置或容器；
- (I_t)：实例身份；
- (S_t)：静置、被使用、携带、收纳等状态；
- (A_t)：造成转移的行为者；
- (E_t)：拿起、携带、交接、放置等事件；
- (Z_t)：当前习惯 regime（阶段）；
- \(\Theta_t\)：人物条件化长期习惯参数。

机器人不直接获得 (X_t)，只获得受观察策略和可见性影响的证据：

\[
O_t \sim p(O_t\mid X_t,V_t,Q_t),
\qquad
M_t \sim p(M_t\mid \pi_{obs},T_t,V_t,C_t)
\]

其中 (V_t) 是可见性，(Q_t) 是观测质量，(M_t) 是是否缺失，
\(\pi_{obs}\) 是观察策略，(T_t) 是当前任务，(C_t) 是家庭情境。由于路径和任务会决定看见什么，缺失通常是 MNAR（Missing Not At Random，非随机缺失）。

目标不是只计算位置频率，而是维护：

\[
p(X_{0:t},\Theta_{0:t}\mid O_{obs},M_{0:t},U_{0:t},C_{0:t},K)
\]

其中 (U_{0:t}) 包括机器人行动和用户纠正，(K) 包括物体属性、常识与场景约束。

当需要行动时，信念必须进入决策：

\[
a_t^*=\arg\max_a
\mathbb{E}_{X\sim B_t}
\left[U(a,X)-C_{task}(a)-C_{privacy}(a)-C_{error}(a)\right]
\]

因此，概率更准但不改善查询、搜索、递送、整理或错误风险的模型，不能单凭 NLL、Brier 或 ECE 宣称方向成功。

## 3. 必须分离的七类记忆与信念

| 层次 | 回答的问题 | 写入原则 |
|---|---|---|
| observation evidence（观测证据） | 相机在什么条件下真正看到了什么 | 追加式保存，不直接等于世界事实 |
| current belief（当前信念） | 物体现在可能在哪里、处于什么状态 | 可快速改变，可保留多个假设 |
| episodic event（情景事件） | 某时某地谁对什么做了什么 | 必须带来源、时间和置信度 |
| inferred event（推断事件） | 观测间隙可能发生了什么 | 保存候选集，不把最高分候选冒充事实 |
| personalized habit（个体习惯） | 某人物在某情境下通常怎样 | 经过身份、行为者和稳定性门控后更新 |
| habit regime（习惯阶段） | 当前规律属于稳定、异常、渐变还是新阶段 | 版本化，允许旧阶段再次激活 |
| preference/norm（偏好/规范） | 主人希望怎样、家庭规定怎样 | 与观察到的行为严格分开 |

预测输出不能反向作为无来源训练证据；语言模型生成的常识只能作为先验、候选或解释，不得直接覆盖观测证据。

## 4. 拟推进的新方法研究簇

这里提出的是一组可组合、可竞争的 method hypotheses（方法假设），不是预先冻结的一条实现路线。

### 4.1 方法簇 A：观察过程感知的联合多假设世界模型

核心思想：显式建模“机器人为什么没有看见”，联合估计实例—位置—行为者—事件，而不是先把观测补成完整轨迹再学习习惯。

候选实现：

- 动态因子图或动态贝叶斯网络，保留结构化不确定性；
- Rao–Blackwellized particle filter（Rao–Blackwell 化粒子滤波）处理离散事件链和连续空间状态；
- 神经 amortized proposal（摊销提议网络）产生高概率事件候选，结构化概率模型负责校准和约束；
- 多假设数据关联，避免相似杯子或书本的错误身份传播；
- observation likelihood（观测似然）显式使用视野、遮挡、距离、容器和检测率。

可能的新贡献不在“使用概率”本身，而在于把非随机缺失、身份竞争、行为者和隐藏事件纳入同一可追溯后验，并证明这种联合建模优于分段流水线。

### 4.2 方法簇 B：人物门控、抗污染的分层习惯记忆

核心思想：每次位置证据先进入当前状态和事件层，再依据人物后验与证据质量对个体习惯进行软更新。

候选习惯结构：

\[
p(L_{t+1},E_{t+1}\mid p,o,c,h,Z_t)
\]

其中 (p) 是人物、(o) 是实例、(c) 是时间/活动/场景情境、(h) 是历史。

证据权重可写为：

\[
w_t=q_{identity}q_{actor}q_{placement}q_{observation}
q_{independence}
\]

authorization（授权）在该分数之外执行不可补偿的 hard constraint（硬约束）：未授权证据不得进入习惯更新；已授权动作或巩固的 privacy cost（隐私成本）进入决策损失，不能被其他高置信度相乘抵消。

关键机制包括：

- `unknown_actor` 保留概率质量，不强行归给主人；
- shared household（家庭共享）分布与 individual（个体）分布分层共享统计强度；
- 访客和短期异常进入隔离缓冲区，达到条件后才巩固；
- 同一事件的重复帧或重复检索不能被当作独立证据累计；
- 用户纠正可以撤销派生习惯并通过日志重建。

### 4.3 方法簇 C：事件层次与反事实行为者归因

核心思想：把观察到的人—物原子交互、未观察到的转移和高层活动组织成事件图，并比较替代解释。

事件候选至少覆盖：

```text
pick_up → carry → hand_over → place → return
主人移动 / 家人移动 / 访客移动 / 机器人移动 / 未知行为者
同一实例转移 / 相似实例误关联 / 物体仍被携带
```

候选方法包括：

- hierarchical event graph（分层事件图）；
- abductive inference（溯因推理）生成能够解释前后快照的最小事件链；
- counterfactual attribution（反事实归因）：移除某人物假设后，当前证据的似然下降多少；
- 基于人物轨迹、在场关系、接触、携带连续性和活动语义的联合打分；
- 事件上下文反过来修正实例关联，但不得在同一 tick 内形成不可控同步递归。

### 4.4 方法簇 D：可回归、可复用的非平稳习惯生命周期

核心思想：不在“永远记住旧模型”和“快速覆盖旧模型”之间二选一，而是维护阶段后验和历史版本。

系统需要区分：

- isolated anomaly（孤立异常）；
- temporary placement（临时放置）；
- contextual mode（情境模式）；
- gradual drift（渐变）；
- abrupt change（突变）；
- old habit recurrence（旧习惯回归）；
- permanent replacement（永久替代）。

候选实现：

- BOCPD（Bayesian Online Change-Point Detection，贝叶斯在线变化点检测）；
- sticky HDP-HMM（粘滞层次狄利克雷过程隐马尔可夫模型）；
- switching state-space model（切换状态空间模型）；
- 参数高效 continual learning（持续学习）配合人物/阶段记忆库；
- 神经预测器与显式阶段控制器的混合模型。

旧阶段不得被无条件删除；新证据应能够重新激活历史阶段，并分别评价变化检测延迟、误报、旧习惯恢复和灾难性遗忘。

### 4.5 方法簇 E：主动但非侵扰的观察—记忆—行动闭环

核心思想：观察策略影响学习数据，学习后的信念又影响观察策略，因此必须处理闭环偏差。

可选动作包括：

```text
沿原路径顺带观察
轻微转头或调整视角
延迟到未来任务验证
主动进入房间或打开容器
询问具体家庭成员
暂不行动并保留不确定性
```

候选方法包括 POMDP（部分可观测马尔可夫决策过程）、belief-space planning（信念空间规划）、value of information（信息价值）和 contextual bandit（情境赌博机）。但策略必须同时计入主任务延迟、隐私、打扰、错误操作与长期学习收益。

### 4.6 方法簇 F：信念到具身效用的可归因接口

同一个信念模型必须向多个下游能力暴露统一接口：

- 历史、人物、事件、习惯和证据查询；
- 个性化物体搜索与多位置排序；
- 下一次使用、归还位置和活动所需物体预测；
- 递送、提醒、整理和放回；
- 不确定时的澄清与保守行动。

每个下游实验必须能追踪收益来自哪个信念变化，防止把更强感知、更多算力或更长路径误写成习惯模型贡献。

### 4.7 已有技术路线不是禁区：六类直接方法改进

已有论文使用过 event graph（事件图）、BOCPD、Dirichlet、GNN 或 continual learning（持续学习），只说明不能把这些通用名词本身当成创新点，并不意味着本项目只能绕开它们寻找交叉空白。本项目可以直接修改它们的状态定义、更新规则和优化目标，形成新算法：

1. **CHEH，Counterfactual Hypothesis Event Hypergraph（反事实假设事件超图）**：把方法簇 C 的普通事件图升级为互斥事件链超边；同时保存人物责任、实例关联、观察支持和来源，使旧事件能够随新证据修订或撤销。
2. **CF-BOCPD，Cause-Factored BOCPD（原因因子化在线变化点检测）**：把方法簇 D 的普通“是否变化”升级为 \(p(r_t,C_t,Z_t\mid D_{1:t})\)；观察、人物、身份、习惯和噪声原因分别触发不同参数块的重置。
3. **OPCEU，Observation-Process-Corrected Evidential Update（观察过程校正的证据更新）**：把方法簇 B 的软人物计数升级为对未观察事件和证据相关性的期望充分统计量更新，避免高频重复帧和自选择路径造成虚假确信。
4. **PCHMP，Provenance-Constrained Hypothesis Message Passing（来源约束的假设消息传递）**：把通用 GNN/Transformer 升级为带类型防火墙、互斥假设归一化、人物置换等变性和证据子图输出的结构化消息传递。
5. **RGRC，Responsibility-Gated Reversible Consolidation（责任门控的可逆巩固）**：把通用 replay/EWC 升级为隔离、晋升、撤销和历史阶段重激活四种长期记忆操作，门控变量包括人物责任、变化原因、证据独立性和行动错误成本。
6. **CIAV，Cause-Information Active Verification（变化原因信息主动验证）**：把方法簇 E 的普通状态熵探索升级为对变化原因互信息与任务效用的联合优化，在运动、隐私和打扰预算下选择微观察、容器检查或询问。

上述六项以及历史阶段重激活机制全部进入同一个统一框架和同一篇论文。它们仍需分别与“未改进版本”做直接替换消融，但消融的作用是验证每个新算子的贡献，不是决定是否从项目中删除该能力。

### 4.8 五条同级跨领域一级技术路线（2026-08-23 增补）

本节不是用外部领域重新命名已有模块，也不是把方向结构二改写成数据库、控制或流程挖掘中的单一问题。它把五类跨领域技术正式纳入方向结构二，作为与 4.1–4.7 方法簇交叉的同级研究轴。每条路线既可提出独立新方法，又必须通过公共实体、事件、来源、时间、版本和任务契约接入完整闭环。

| 一级技术路线 | 主要借鉴领域 | 在结构二中的独立研究问题 | 当前直接接口 | 独立成立证据 |
|---|---|---|---|---|
| Reversible Belief Data Systems（可逆信念数据系统） | incremental view maintenance（增量视图维护）、data provenance（数据溯源）、bitemporal database（双时态数据库）、MVCC | 怎样把带来源、有效时间、记录时间和修订谱系的概率信念维护为可加入、可撤销、可分支、可合并、可重放的在线视图 | HybridStatisticLedger、VersionedBeliefMap、RGRC、BeliefSnapshot | 撤销—重放等价、事务一致性、快照原子性、迟到证据正确性、吞吐与延迟 |

五条路线之间不是单向流水线或从属层次。CHEH/PCHMP 的事件修订可以改变阶段后验和地图；CCRR 的阶段变化也可以反向修改隐藏事件先验；任务失败可以重新打开旧事件假设；认知信息流控制可以阻止非法反馈进入任意长期统计量；地图快照和任务依赖又会约束哪些主动观察值得执行。文档中的数据流图只表示一次可执行路径，不冻结唯一的信息流方向。

#### 4.8.1 RLS 接入语义地图的既有决定继续有效

2026-08-22 已在 N4 方案 B 中选择的 **B-F1 Dirichlet + RLS residual（Dirichlet 基础分布 + RLS 情境残差）**、**B-PM3 graph proxy + online RLS residual（图代理 + 在线 RLS 残差）** 及其来源簇排除、风险门、回放降级和地图—任务并发语义，均未因本次跨领域扩展而作废。本次增补不以数据库、真值维护、流程推理或信息流控制替换 RLS；RLS 同时属于“可逆信念数据系统”和“阶段局部可逆学习”两条一级路线中的核心数值更新机制。

RLS 在方向结构二中的职责继续固定为：

1. 在语义地图维护期间在线吸收新的情境化观察，而不是等待任务结束后批量更新；
2. 对每个 `(actor, object, regime, parameter block)` 维护自然充分统计量 $A,b,\theta$，并与 Dirichlet 位置基础分布分工，而不是替代全部离散地图信念；
3. 每个 RLS 增量绑定来源记录、证据簇、事件修订、人物责任、阶段、授权范围和输入 watermark；
4. ORRER/RGRC 推翻来源时执行定向 downdate；数值条件不满足时明确降级为受影响阶段的日志重放；
5. 阶段内默认不使用无条件遗忘覆盖旧统计量；非平稳性由 CF-BOCPD/CCRR 的阶段竞争、创建、重激活和隔离处理；
6. 地图新版本与任务执行并发推进，但任务读取不可变快照，RLS 更新不得让执行器看到半完成统计量；
7. RLS 的研究价值必须同时通过地图恢复、长期污染、阶段适应和行动效用验证，不得缩小为“比完整重跑更便宜”这一项成本主张。

是否以后修改 RLS 覆盖的地图层、残差形式、遗忘策略、数值表示或与 Dirichlet/信息滤波的分工，仍由后续实验、对抗审核和用户决定；在此之前不得将 RLS 从结构二中静默删除或宣告作废。

#### 4.8.2 五条路线的独立与联合验证

完整系统不仅做一次总分比较，还必须形成三级证据：

1. **单路线死亡测试**：每条路线分别对最强邻近方法和合理增强基线，检验自己的独立主张；
2. **交互消融**：验证可逆数据 × 信息流控制、信息流控制 × 阶段学习、阶段学习 × 潜在流程、可逆数据 × 任务决策、潜在流程 × 主动观察等交互是否产生非加性收益；
3. **完整闭环死亡测试**：在相同证据、感知、训练、计算和行动预算下验证全部路线联合后是否改善长期记忆与行动，而不是利用弱代理、评测泄漏或额外观察。

单条路线的局部失败只能推翻该路线当时的具体算法主张，并触发同一路线的新方法设计与复测；不得自动删除其他路线，也不得据此缩减方向结构二的完整科学问题。

## 6. 研究问题与可证伪假设

### RQ2-1：怎样从选择性观察中学习而不混淆“未看到”和“不存在”？

**H2-1：** 在相同真实轨迹下改变机器人路径和视野后，观察过程感知模型的习惯后验变化显著小于忽略缺失机制的模型，同时保持或提高当前位置估计准确率。

### RQ2-2：怎样从前后快照恢复未被看见的人—物事件？

**H2-2：** 联合事件—身份推断在事件链 Top-k recall、最终实例位置和错误关联传播上优于逐帧关联加启发式差分。

### RQ2-3：怎样避免同屋其他人污染主人的个体习惯？

**H2-3：** 在家人、访客和未知行为者比例上升时，人物软归因和隔离巩固能显著降低 owner contamination rate（主人习惯污染率），而不会把全部证据保守地丢弃。

### RQ2-4：怎样同时适应新习惯并保留可复用旧习惯？

**H2-4：** 阶段化模型在突变检测延迟、渐变适应、旧阶段恢复和长期平均效用上优于固定遗忘、滑动窗口和普通 rehearsal（回放）模型。

### RQ2-5：联合建模是否真的值得？

**H2-5：** 在同感知、同训练数据、同计算和同动作预算下，完整模型优于每个独立增强组件及其合理组合；如果只改善校准而不改善行动效用，则该方法主张不成立。

### RQ2-6：信念怎样改善不止一种机器人能力？

**H2-6：** 共享信念能够在至少两类不同任务上产生可重复收益，例如“物体搜索 + 个性化放回”或“语言查询 + 主动递送”，而不是只针对单一 benchmark（基准）过拟合。

## 7. 最强基线不是单篇论文，而是组合系统

### 7.1 必须忠实比较的系统

- O-STaR：机会式多目标感知、动态场景图、Dirichlet–Categorical 位置信念和家庭迁移模式；
- Scene Graph Memory / NEP：部分可观测动态图上的物体位置后验；
- DynaMem / POCD / Where Did I Leave My Glasses?：动态语义地图、概率变化检测和主动维护；
- HOMER / SLaTe-PRO：长期物体迁移、活动条件和主动询问；
- STREAK：家庭上下文漂移下的持续物体迁移学习；
- GESTO / EGG：持久场景实体与人—物事件层次；
- HUMEMBR：跨日人物身份、日常规律和预测式导航；
- WorldLines / ObsMem：观察可见性、历史证据、状态、信念和具身计划；
- MEMENTO / POLAR：长期交互中的个性化记忆获取、组织与利用；
- UcON / PerSim / TidyBot：用户习惯、个体差异和偏好驱动的搜索或整理。
- HERMES：时序场景图、事件边、语言注册的用户习惯/偏好节点和长期检索。

### 7.2 必须构造的增强组合基线

```text
O-STaR + person labels
O-STaR + STREAK-style continual learner
O-STaR + GESTO/EGG-style event representation
O-STaR + observation-likelihood negative evidence
O-STaR + change-point detector
O-STaR + all independently engineered additions

WorldLines/ObsMem + learned habit predictor
GESTO + person identity memory + regime detector
HOMER/SLaTe-PRO + selective observation masking + actor labels
HERMES + observation-derived probabilistic habit updater
```

完整方法必须面对“忠实复现 + 独立调优 + 合理增强”的最强版本。若一个简单组合已经达到相同效用，新方法必须说明额外结构带来的必要收益，否则不应夸大贡献。

## 8. 数据与基准设计

### 8.1 场景因素

基准必须能够独立控制：

- 观察覆盖率、视角偏差、遮挡、漏检和容器不可见；
- 主人、家人、访客、机器人和未知行为者比例；
- 直接看见事件、只看见事件前后、只看见局部动作；
- 相似实例、物体交接、共同移动和身份断裂；
- 固定、多位置、情境化、游走和阶段变化型物体；
- 稳定、周期、渐变、突变、暂时扰动和旧习惯回归；
- 行动、询问、隐私和主任务干扰成本。

### 8.2 四条评价轨道

1. **Oracle state track（真值状态轨）：** 隔离习惯和事件算法，不受感知误差干扰。
2. **Controlled observation track（受控观测轨）：** 系统性注入选择偏差、漏观测、误检、遮挡和身份噪声。
3. **Real-perception replay track（真实感知回放轨）：** 使用固定日志比较方法，保证输入一致。
4. **Closed-loop embodied track（具身闭环轨）：** 方法自主决定观察和行动，评价学习—决策反馈。

最终还需要小规模真实家庭或家庭式环境部署，验证仿真结论是否在真实人物、遮挡、隐私和行为变化下成立。

### 8.3 数据切分

- 按家庭、人物、物体实例和时间切分，防止泄漏；
- 变化发生前、变化适应期、变化后和旧习惯回归期分别评价；
- 报告 seen home（已见家庭）、new resident（新住户）、new object（新物体）和 new regime（新阶段）泛化；
- 固定观察日志与闭环日志分开，防止观察策略优势伪装成模型优势。

## 9. 分层评价体系

### 9.1 观察和感知层

- observation opportunity calibration（观察机会校准）；
- visible-but-missed / not-visible 区分准确率；
- 实例关联准确率、ID switch 和相似实例混淆；
- 人物身份和人—物交互识别。

### 9.2 事件与信念层

- 当前状态 accuracy / NLL / Brier / ECE；
- hidden-event Top-k recall、事件边界和事件链编辑距离；
- actor attribution accuracy、unknown-actor calibration；
- 多假设覆盖率和错误假设清除时间；
- 证据可追溯、撤回和重放一致性。

### 9.3 个体习惯与持续学习层

- next-location / next-event / next-user prediction；
- owner contamination rate（主人习惯污染率）；
- guest contamination recovery（访客污染恢复）；
- change-point detection delay / false alarm；
- forward transfer、backward transfer、forgetting；
- old-regime recurrence recovery（旧阶段恢复）；
- 按人物、物体移动性和观察覆盖率分层报告。

### 9.4 查询和具身决策层

- 时间化/人物化语言查询正确率与证据支持率；
- object-search success、SPL、搜索时间和容器检查数；
- 错误拿取、错误递送、错误整理和违背明确偏好的次数；
- 主动询问次数、打扰时间、额外路程和隐私成本；
- proactive assistance（主动协助）的成功、提前量和无效协助；
- 总体任务效用及 worst-group（最差群体）表现。

校准指标是诊断工具，不是单独的 go/no-go（继续/停止）证据。

| WP2-D | 信念到查询、搜索、整理和协助 | CIAV 与具身闭环效用验证 |

4.8 的五条一级技术路线横跨这些工作包，不与工作包形成上下级或一对一替代关系：可逆信念数据系统主要贯穿 WP2-B/C/E；认知信息流控制贯穿 WP2-A/B/C/E；阶段局部可逆学习贯穿 WP2-C/D/E；对象中心潜在流程推理贯穿 WP2-B/C/D；任务感知自调整决策贯穿 WP2-A/D/E。工作包是工程和实验组织，一级技术路线是科学问题与方法主张，二者不得混同。

所有工作包共享：

- 同一实体、事件、证据和时间语义；
- 同一长期家庭情境生成器；
- 同一最强基线适配层；
- 同一 Benchmark Manifest（基准清单）；
- 可从原始日志重建的信念和习惯版本。

## 13. 按现有执行步骤推进

方向确立后，工程推进遵守现有 v1.2 顺序：

1. 在 M31/M30/M29/M32 中加入多人、隐藏事件、选择性观察和习惯阶段的可控场景与指标；
2. 先在 oracle/符号轨建立强基线和组合基线，避免感知误差掩盖方法问题；
3. 用 M13–M16 建立可回放的当前状态、证据和多假设投影；
4. 在 M17–M19 依次接入人物习惯、隐藏事件和阶段生命周期；
5. 通过 M20–M27 连接查询、搜索、询问、整理和协助闭环；
6. 以相同协议逐步替换 M09–M12、M25 和 M26 的 oracle；
7. 最后进入真实感知回放、半真实环境和真实机器人长期部署。

这个顺序是成熟度安排，不是把方向降格成“小验证项目”。每一步都必须保留最终完整能力的接口和数据语义。

## 14. 创新成立与失败的判据

### 14.1 创新成立

至少需要同时满足：

1. 在检索范围和日期内，方法组合与现有系统存在清晰、可核验的结构差异；
2. 在同预算下优于忠实复现及合理增强组合基线；
3. 多人污染、隐藏事件、选择性缺失和习惯变化中至少两个困难存在交互收益，而非独立模块简单相加；
4. 改进能够转化为查询、搜索、整理、递送或协助中的行动/效用收益；
5. 在真实感知回放或真实环境中仍保留主要结论；
6. 失败案例、未知行为者和不确定性得到诚实报告。
7. 4.8 的五条一级技术路线分别给出独立强基线、独立指标和失败判据，并通过交互消融说明完整收益不是某一条路线单独承担或其他路线仅作装饰。

### 14.2 局部方法主张失败

以下情况应停止或重构该局部方法，而不是停止总方向：

- 合理增强的 O-STaR/STREAK/GESTO/WorldLines 组合已达到同等效果；
- 只改善 ECE、NLL 或离线准确率，不改善行动效用；
- 收益主要来自更多标注、更多观察、更多算力或更强感知；
- 只有合成 oracle 数据有效，真实感知回放失效；
- 对家人或访客的污染风险高于家庭级简单模型；
- 复杂联合模型不如可解释的分层基线稳定。

局部失败应触发方法替换、简化或重新组合，不反向删除本方向的完整科学问题。

这里的“简化”只允许优化具体算法实现，不允许删去统一系统中的选择性观察、隐藏事件、同屋多人、非平稳习惯、抗污染巩固、历史阶段恢复、主动验证或既定具身下游能力。某个局部方法被强基线击败时，应重新提出该技术路线上的新方法并复测。

## 15. 当前结论

方向结构二不是被缩小后的“验证代价项目”，而是 CPSWM 中最有潜力的核心方法研究簇之一。它的研究对象是一个完整闭环：

> 机器人在任务和生活共同决定的选择性观测下，维护具体物体、人物、位置、事件和习惯阶段的联合不确定性；从不完整轨迹中提出并比较隐藏人—物事件；防止家庭成员、访客和识别错误污染主人的个体模型；持续适应并保留可复用的旧习惯；再把这些信念用于语言理解、预测、搜索、整理、递送和主动协助。

现有工作已经分别证明机会式观察、动态物体记忆、人物日常规律、事件图、持续学习和个性化记忆的价值。方向二的推进方式不是回避它们，而是吸收其最强实现、构造公平组合基线、提出新的联合方法，然后用长期、多人、非平稳和具身决策实验检验是否真正超越。
