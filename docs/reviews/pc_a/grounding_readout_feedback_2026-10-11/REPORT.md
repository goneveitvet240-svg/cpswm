## 2. 真实 Unity 反证：深度通道是否看到了碗

实际运行固定 AI2-THOR 5.0.0 / Unity `f0825767cd50d69f666c7f282e54abfe58f1e917` 的本机二进制。初始相机设为与历史采集一致的 225°，实际 RotateRight 30° 后为 255°。固定顺序移除 Bowl、WineBottle、SoapBottle，每次实际 Pass 采集 RGB-D 和动作回执。

`DisableObject` 是**实验者对仿真世界的干预**，不是机器人抓取。方法侧仅收到 RGB-D/相机自定位与执行回执；物体 ID、材质、instance masks、raycast 仅用于干预/事后评价。所有公开推理完成后才读取实例真值。

| 原实例像素区域 | RGB 变化像素 | 深度变化超过 0.5 mm 的像素 | 中位深度变化 |
|---|---:|---:|---:|
| Bowl_22（Glass） | 1160 / 1164 | **0 / 1164** | **0 m** |
| Wine_Bottle_1（Glass 标签） | 1229 / 1229 | 1133 / 1229 | 0.2970 m |
| Soap_Bottle_3（Metal/Glass 标签） | 1475 / 1475 | 1384 / 1475 | 0.1602 m |

碗消失后，深度仍原样保留，确认该区域深度不代表碗表面。两个瓶子是“会写深度的渲染控制”，不能仅凭 SDK Glass 材质标签一律拒绝所有玻璃类别。公开背景连续性检查没有使用这些标签。

历史固定像素 `[163,159]` 的深度投影仍为 `[0.1706410663, 0.9360319378, 2.4728515048]`，与碰撞射线命中点距离 **179.46 mm**；它原先距离碗 AABB 下界 1.56 mm 并不意味着只差 1.56 mm 的物理表面校正。两处墙面/常规控制射线误差约 0.0014 mm / 0.0509 mm，不能据此改全局相机公式。

方法侧行为：初始两个瓶子有报告，碗返回未知但仍有 **9 个二维光流点**；移除碗后两个瓶子继续报告；移除 WineBottle 后仅 SoapBottle 仍报告；移除 SoapBottle 后三者都返回未知。没有把“没看到”写成世界中的全局不存在，也没有输入人物归因。

**保留的新失败：**本次初始 WineBottle 选点实例正确，但在原 AABB 的 x 上界外 **0.1102 mm**，严格联合评分失败。之后碗移除帧的两个瓶子及 WineBottle 移除后的 SoapBottle 报告通过原 AABB。没有添加容差把该失败改判成功；该保护器不等于完整几何有效性证明。

**配置失败记录：**第一轮使用源房屋默认 270° 再旋转到 300°，没有看到原目标碗，评价 KeyError。该轮原始数据与失败日志保留为 `live-wrong-pose-raw.tar.gz`；有效比较使用回到历史协议的第二轮，没有按成绩挑选角度。

## 4. 32 天长期比较：缺陷修复有效，但快基线打平

固定 seeds 7/8/9，每例 32 天，覆盖访客干扰、17 日习惯切换、26 日旧习惯回归；开启原有开放世界事件。三个种子实际可观测决策数分别 31/31/32，总 **94**，不是人为补齐 96。

2 种人物似然配置 × 3 种真实运行时读出 × 3 seeds = **18 次完整生产运行**，共 **564 个实际构造的 PUT_BACK 命令**。每条配置从头运行 P5，再读取和准备命令，不只是最后一步替换输出。观测仍是明确标注的语义 Oracle，命令没有在 Unity 中执行放置。真值只在整例推理结束后用于评分。

| 配置/对照 | 习惯位置选择正确 |
|---|---:|
| 旧慢读出 + 旧偏主人似然 | **9/94** |
| 只接入 v0.6 读出，仍保留旧偏主人似然 | **69/94** |
| 只中和人物似然，仍用旧慢读出 | **9/94** |
| **v0.6 读出 + 中性人物似然** | **94/94** |
| 最近一次可信主人事件 + 中性人物似然 | **94/94** |
| 普通全历史软计数，相同当前人物权重 | **70/94** |
| 普通指数近期计数，半衰期 1 / 3 / 7 天 | **77 / 80 / 79，共 94 次** |

普通计数与近期计数使用完全相同的当前 CIAV 修订人物权重；所有预设半衰期完整报告，没有按测试表现只选最好一条。latest-owner 是共享生产状态上的简单读出消融，并非完整外部作者系统或独立调优的最强邻近方法。

修复后的 94/94 包括：初期 21/21、访客阶段 22/22、访客后 6/6、新习惯 27/27、回归 18/18。人物中性组逐步验证新 CIAV 后验与主 PCHMP 后验一致；旧偏置只在显式标为“不具实际人物证据的负控制夹具”时重现。18/18 SQLite 恢复后的语义状态与读出一致。

**不能据此说长期记忆机制已成功。**18 例最终长期提交数全部为 **0**；行政写入门仍阻止慢记忆写入。这些提升发生在现有快记忆动作读出。快基线打平，因此本轮没有证明可逆长期机制、阶段记忆或完整框架具有额外效用。新增 seeds31..40 确认组本轮未执行；这仍是开发比较。
