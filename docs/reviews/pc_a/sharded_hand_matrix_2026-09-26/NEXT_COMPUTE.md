# 剩余计算瓶颈的后续工作（尚未实现）

本轮原数据、完整支持和校验未缩减。第三轮只读profile在243候选的一次完整评分中记录约35万次候选反序列化、36万次内容摘要及1,461个条件节点；第四轮只做严格标量快路径，真实完整评分约减少22%/31%/23%，大支持代价仍高。插桩耗时和共享主机计时不应解释为隔离基准。

下一步可在独立轮中研究“同一次完整解码的可验证只读批处理”：避免为每个条件节点重新解析同一上下文及全候选，并避免重复生成可证明相同的序列化形式。需要真实的所有权/不可变性约束、原始外部输入绑定和明确的提交前校验，不能只加一个可信标志或删掉摘要检查。

必须与旧路径比较全部目标、九因子概率、归一化、采样、恢复和状态字节；覆盖合法正路径、完整伪造缓存及重新自封摘要、方法替换、原地tensor.data修改、重复/失效请求和账本动作后果。仍按冻结后两轮不同自审执行；旧公开入口的安全范围不能无说明收窄。此处仅记录下一轮工程候选，不声明已经实现、测得提速或完成审核。

科学主线仍是补齐可信事件/身份/位姿误差监督，完成真实联合训练与自然记忆—行动反馈。计算提速不能代替这些证据，也不决定三种候选架构的科学取舍。
