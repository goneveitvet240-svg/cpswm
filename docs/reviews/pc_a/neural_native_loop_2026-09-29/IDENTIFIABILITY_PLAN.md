# 对当前二视角任务的可区分性复核计划

在完整分辨率对照完成后、剩余预算允许时进行，不中途改任务追求方法获胜。第三轮实际结果显示后验更新与关闭更新动作完全相同；需要判断是参数/前端效果问题，还是当前动作集合与停止规则使反馈收益在这个任务里无法区分。

固定原先验、0.9/0.05开发似然、0.5 aggregate unresolved似然、同一类别停止与已看视角规则；枚举225/315两个静态视角的全部四种确定性类别测量组合。六个原有方法都接相同的测量函数和共同初始后验。各神经方法仍实际加载原检查点，其余组使用相同首架构检查点；相机对象为明确受控的测量回放，不称新的真实Unity试验或自然视觉。该穷举只能判断当前局部机制与配置，不能外推完整方法不存在价值。

对每个组合记录第一/下一动作、总观测与是否停止、原生后验是否相同、启用反馈是否确实改变概率。合法阳性、先阴后阳、全阴都必须覆盖。如果动作始终相同，应将当前实验明确降格为接线与感知诊断：它有反驳本局部收益主张的作用，但不足以验证完整后验控制优势。下一任务须有至少三个可能有信息的动作、可信条件测量、以及能暴露记忆/事件推断贡献的后果；三者缺一不能继续把同一二视角成功率当研究收益。

工具冻结后依次两审，第一审验证四种测量都确实执行且所有方法得到相同信息；第二审针对漏掉不利组合、基线忘记已看结果、改初始后验、把受控回放混称实测。结果与真实场景结论分栏，完整统一范围保持，不据此替用户放弃某条科学路线。
