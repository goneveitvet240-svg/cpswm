# 比较之后的候选推进项：用独立的相机位置诊断前端测量

本计划先固定；必须等第三轮两审、实际24次比较与重建完成后才开始实现。如时间不足，保留为下一主项，不跳过审查。

现有真实帧已表明“可见但未检出”，而默认开发似然假设在假设视角有0.9阳性率。下一轮优先采集可复算的仿真测量证据，辨明是少数视角问题还是系统性漏检；不擅自改正式神经架构、0.5过滤设置、unknown先验或论文指标，也不在当前两个样本上直接拟合并宣布校准成功。

固定同一已有房屋、同一Apple资产、北/南两种位置和相机高度/30度俯角，使用相机x=1.05、1.25、1.45三个预先声明位置；每处依次观察公开yaw=195,210,225,240,255,270,285,300,315,330,345，共2×3×11=66个请求。位置仅是外生初始化，不算机器人导航；每次初始化第一帧Pass，之后实际右转15度10次，不根据检测/掩膜挑图或早停。x=1.25包含本轮已看场景；x=1.45可作另一相机位置的开发诊断，但同房屋同目标且计划受前轮失败启发，不宣称正式holdout或跨场景泛化。

方法侧仅保存原始RGB与动作状态、并分别使用两个固定官方前端推理；所有身份、实例掩膜、SDK可见性、真实相机/目标位置只由评估端读取。数据与读数都逐帧保留，不把新仿真真值说成新增独立人类接触/人物/释放复核。两模型在同一原始RGB上比较，完整记录可见/不可见分母、置信度、目标框IoU、图像来源与实际视角；同一目标的重复视角不当成独立场景样本。漏检率是本固定网格描述性读数，不能当通用检测概率。

冻结后第一审验证固定完整矩阵、像素通道、实际动作、模型来源和合法数据重建；第二审攻击漏帧/重帧、错RGB与掩膜、重封检测、真值进入模型以及误把重复视角算独立样本。实际采集后重新从原图推理并核对全包。保留新失败与源绑定，不拿图片展示代替量化，也不把扩大数据量等同于完整自然闭环。

可用的仿真真值仅限这一渲染任务：实际相机视角、指定资产实例的像素掩膜和几何包围框、动作成功状态。它们可回答“图像中是否确有目标”和“类别候选框是否落在目标上”，不能回答接触/释放时刻、人物身份、长期个人习惯或运行前端位姿误差的真实世界分布。若将这些数据用于后续拟合，必须另行定义各联合假设与测量分布的关系，尤其aggregate unresolved不能从仅两个目标位置估成可信概率。

本轮不会随结果调相机分辨率、置信阈值、图像亮度或资产颜色。若需要观察这些干预，其配置与全量分母应在下一轮另行固定，不能混入此66帧网格后择优报告。原始采集与离线推理均使用固定源码/模型摘要，结果只作下一步设计依据。
