# 第二批完整采集的描述性结果

受测源码 a981541fc15bd1e441051f9479dc96b17cdc2f44；第二批 24 格、384 张公共原图全部采集完成。每格另有初始、准备和时钟事件，记录总数为 34 个 SDK 事件（含一个初始状态）；未将其都当作公共观测。原图复推与交付状态以 REPORT.md 为准。全部统计来自第二批，没有用首批成功格替换第二批数据。

## 物理、图像和初始化分别看

| 条件 | 格数 | 后八帧 RGB 逐字一致 | 公共首末 RGB 差均值范围 | 两次启动同序号 RGB 逐字一致 |
|---|---:|---:|---:|---:|
| 默认 auto | 8 | 8/8 格 | 0–0.044023 | 54/64 对 |
| 暂停 frozen | 8 | 8/8 格 | 0 | 16/64 对 |
| 显式 stepped | 8 | 0/8 格 | 0.067920–0.071924 | 48/64 对 |

RGB 差是 0–255 字节尺度的全图绝对差均值，不是百分比。不同启动的 64 对是四个位置/尺寸组合各 16 个同序号帧，属于相关重复，不是 64 个独立场景。

全部 24 格在准备后相机元数据与目标掩膜逐字不变。冻结八格在准备后的所有 SDK 事件中，对象位置/旋转也完全不变；但准备帧到最后帧的 RGB 差均值仍为 14.695607–14.936403。主要变化发生在准备后的早期调用，随后 16 张公共图像在每条冻结序列内完全相同。故已记录对象/相机位姿变化不是这个早期 RGB 变化的必要条件；具体渲染原因尚未通过干预确认。

显式步进八格各执行 16 次 0.01 秒请求，成功返回的请求时间合计 0.16 秒。最后八帧内对象坐标分量仍变化约 2.494–3.258 毫米，RGB 也继续变化；固定相机不等于物理世界静止。默认条件后八帧虽然 RGB 全同，对象坐标仍可有最大约 5.96e-8 米的浮点变化，不能把“逐字图像相同”定义为全引擎状态相同。

**冻结不保证不同启动得到同一个初始物理状态。** 两次冻结启动之间，最大对象坐标分量差为 0.004771 米，最大全图 RGB 差均值为 0.068569；相机与目标掩膜保持一致。默认条件和显式步进的跨启动最大对象坐标分量差分别为 0.002009 米和 0.001463 米。控制器从创建场景之后才暂停，创建阶段的差异会留在各自初始态中。所有位移数字均是最大坐标分量差，不冒称欧氏距离。

因此，会话内稳定、不同启动的可重复性，以及不同方法共享同一起点是三项不同要求。本批没有证实冻结模式可直接提供严格配对的完整闭环初始状态，也没有把固定后八帧窗口升级成正式暖机标准。

## 检测结果没有因时序控制变好

每一行覆盖三种物理条件各两次启动，共 96 帧。

| 条件 | 每帧目标像素 | Faster R-CNN 类别阳性 | 候选框与目标框有交集 | SSDLite 类别阳性 |
|---|---:|---:|---:|---:|
| 北 / 320 | 0 | 0/96 | 0/96 | 0/96 |
| 北 / 640 | 0 | 96/96 | 0/96 | 0/96 |
| 南 / 320 | 558 | 0/96 | 0/96 | 0/96 |
| 南 / 640 | 2235 | 96/96 | 96/96 | 0/96 |

全部 24 条类别序列在各自 16 帧中保持相同的 0 或 1；三种物理条件未改变这些二元读数。南侧 320 持续漏检、北侧 640 持续报告无目标像素画面中的目标类别。南侧 640 的几何交集仅要求 IoU>0，不能作为指定实例的正确识别率，更不是动作任务成功率。SSDLite 在第二批 384 帧中均无 apple 候选。

先前报告的首帧检出与本批所有公共图像漏检不矛盾：本批公共第一帧在准备调用与时钟调用之后，原始准备图仍完整保留；两个前端及过滤值没有调整。这说明启动阶段可以影响读数，不能挑选首帧作为能力证明。当前结果也说明持续漏检/误报不能仅靠物理暂停或固定采集次序解决。

## 后续工作的依赖

同一批已保存原图上的前端比较，可以继续推进可信目标实例对应与漏检/误报诊断：先核对候选究竟落在哪个实例，再决定能否形成校准样本。若比较不同方法各自运行的真实闭环，则还需明确可重放的初始状态、物理时间及环境扰动；不能从本批推定启动状态完全相同。两条工作不要求把所有图像差异强行降为零，但都要明确分母、重复关系和数据用途。

本轮不拟合 0.9 等观测似然，不选新模型/正式阈值，不替换正式 pipeline 默认采集策略，也不把局部相机数据提升为自然身份、接触/释放、长期记忆或方法收益证据。
