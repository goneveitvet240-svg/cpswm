# 结构一官方运行入口与未决技术选择（2026-08-26）

## 本次直接闭合的非方法性缺口

1. 新增 `StructureOneCertifiedIngress`，作为 M13--M19 注册后端的唯一受支持写入口。
2. 每次写入必须声明来源记录、内容类型、证据权威、事实资格、人物证据来源、训练资格和运行范围。
3. 隐藏事件只能以 `hypothesis_only`（仅假设）进入 M18；未来预测只能保持 `prediction_only`（仅预测）；偏好和家庭规定只能保持 `directive_only`（仅指令）。
4. M17 只接收显式 `habit_evidence`（习惯证据），并拒绝推断、预测、偏好或家庭规定成为训练证据。
5. 正式运行范围拒绝 evaluator-grade hard actor truth（评估器级人物真值）。历史复现实验和 oracle evaluation（神谕评估）必须显式声明运行范围。
6. 新增 `StructureOneRuntime`，把隐藏事件、M21 查询、搜索/放置/询问规划和执行反馈放在同一条可审计运行链上；尚未选择的方法通过注入端口进入，不另建平行世界模型。
7. 新增 deterministic M21 query compiler（确定性 M21 查询编译器）作为保守基线。词典无法绑定的对象会显式 abstain（弃权），不会凭空创造实体。
8. 执行反馈只有在目标后端成功应用后才提交 feedback projector（反馈投影器）的下游统计；仅通过规则检查但没有后端时保持 `certified_only`，不能伪装成完整闭环。
9. `CoreHabitChainMethod` 和 `build_first_batch` 的人物证据默认值改为 `ABSENT`；冻结 v0.3 的 hard actor truth（人物真值）只能通过显式 `allow_legacy_hard_actor=True` 复现。
10. actor support（人物候选集合）不再从完整事件流推导。未提供 TRAIN_ONLY/MANIFEST support 时只保留 owner 与 `unknown_actor`，避免未来家庭成员和人数泄漏。

## 仍需用户选择的技术设计

以下项目保持 `UNRESOLVED`，本次没有用现有样品偷偷替换正式模块：

| 决策 | 候选路线 | 当前处理 |
|---|---|---|
| 跨天具体物体身份 | structured Bayesian association（结构化贝叶斯关联）/ learned metric or GNN（学习式度量或图网络）/ hybrid（混合） | 仅保留 `ObjectIdentityBackend` 端口 |
| 场景常识与物体属性 | curated KG（整理知识图谱）/ VLM-LLM retrieval（视觉语言模型-大语言模型检索）/ visual estimation（视觉估计）/ provenance-weighted hybrid（按来源加权混合） | 仅保留 `CommonsenseProvider` 端口 |
| 隐藏事件正式方法 | factor graph（因子图）/ DBN（动态贝叶斯网络）/ particle method（粒子方法）/ CHEH-ORRER adaptation（CHEH-ORRER 适配） | M18 正式入口已接好，算法未选择 |
| M17 正式习惯后端 | hierarchical posterior（分层后验）/ CF-BOCPD chain（原因分解 BOCPD 链）/ hybrid ledger（混合账本） | 强制写规则已接好，正式替换未选择 |
| M21 正式语义编译 | deterministic baseline（确定性基线）/ constrained LLM（约束式大模型）/ hybrid parser（混合解析器） | 只有保守基线可用，正式方法未选择 |
| 搜索/放置/询问策略 | utility planner（效用规划）/ policy learning（策略学习）/ hybrid（混合） | 运行时端口和反馈回路已接好，策略未选择 |

## 严格完成口径

- `certified_only` 表示语义和来源通过强制入口，但目标后端尚未绑定。
- `applied` 表示注册后端已通过强制入口收到认证写入。
- 只有 identity、commonsense、hidden event、formal M17、query engine 和 action planner 都绑定，并在真实观察流上完成回归与行动效用验证后，才能称结构一完整生产线闭合。
- 本次未运行测试，因此不能把新增链路标记为已验证。

## 用户确认的正式路线（2026-08-26）

1. 身份：learned metric（学习式度量）产生视觉似然，Bayesian association（贝叶斯关联）拥有最终身份后验；`unknown_object` 保持显式状态。
2. 常识：provenance-weighted hybrid（来源加权混合）；家庭确认事实优先于通用 KG/VLM/LLM 先验，所有融合结果保留来源记录。
3. 隐藏事件：DBN/factor graph 定义概率结构，particle filtering（粒子滤波）执行近似推断，CHEH-ORRER 管理分支、修订和撤回；粒子状态严格按 `(household, subject, object)` 分区。
4. 习惯：正式 M17 使用 RLS-only CF-BOCPD；Dirichlet surprise 继续计算并进入诊断日志，但不影响变点确认。
5. 查询：constrained LLM（约束式大语言模型）只输出目录约束下的结构化 M21 查询，不能创造实体、关系或世界事实。
6. 行动：offline pretraining + controlled online adaptation（离线预训练加受控在线适配）；真实更新受安全动作掩码、每分区预算、反馈置信度、单次策略漂移和人工批准约束。

代码中的冻结选择及哈希位于 `structure_one_selected_routes.py`；正式组合根位于 `structure_one_selected_runtime.py`。模型权重、数据集和训练结果尚未产生，不能把“适配器已接入”解释为方法已完成训练或真实闭环已验证。
