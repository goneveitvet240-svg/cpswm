# 持续对象出生与保守重识别计划（2026-10-08）

## 目标

在 PR98 对照结论之后，补齐 S1 自然表面支路的两个工程能力：记录首帧之后首次出现的对象候选；当首帧锚点的光流丢失时，允许现有外观—几何开发模型提出可拒绝的重识别。未知、歧义和失败必须保留，不能按类别或真值强制匹配。

## 冻结边界

- base：`6e9c953a81e2fc072f4d079d7a19194b1324ea64`（PR98 head）。
- 继续使用已经存在的 `appearance-rgb-histogram-surface-geometry-development@1` 配置；本任务不新增身份概率、阈值、先验或评分指标。
- 晚出生对象只成为可追溯的 provisional track（临时轨迹）；不自动取得首帧 ordinal（序号）任务引用，因此不能把后出现的同类物体冒充原目标。
- 重识别只有在既有开发能量优于其 UNKNOWN 分支、且锚点—候选为唯一一对一可接受关系时才恢复；冲突、相等、缺深度、缺外观支持均保持 UNKNOWN。
- 严格三维 AABB 判据、动作预算、完整 H/R/I/C/Z/r/V、三个 RB blocks 和七算子范围不变。几何毫米误差另做独立校验，不在本任务调偏置或容差。

## 验证

1. 受控合法路径：丢失后唯一外观—几何一致候选恢复，并以新 mask 重新初始化像素支持。
2. 完整伪造/歧义路径：多候选、多锚点冲突、类别不符、外观或几何不支持时不得恢复。
3. 晚出生路径：首帧没有该类别、后帧出现时建立 provisional track；现有 `report_from_surface_state` 仍返回 `initial_query_unresolved`。
4. 事务路径：任一后段失败不部分推进轨迹、出生记录或重识别历史，合法重试成功。
5. 旧行为回归：连续 mask 支持、共享 mask、重复输入、来源/时间/绑定检查和 owner 撤回重放保持。

先运行定向单元与事务回归；受控验证通过后，再对冻结 S1 RGB-D 做只读重放诊断。重放结果与新协议实验分开记录，不用同一批失败目标反调阈值。
