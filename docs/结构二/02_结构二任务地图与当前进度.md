## 8. 已知仓库维护问题

历史 `structure_two_corrected_instrument_v0_3.json` 绑定的是旧版 action evaluator（行动评测器）。
当前评测器已经增加“搜索位置必须登记”的失败关闭规则，因此旧工件校验会报 provenance mismatch
（来源绑定不匹配），直接按当前源码重跑又会正确拒绝旧工件中的未登记位置。对应两个旧测试目前
保持失败，不能通过只改哈希来掩盖。

这不改变 Task 7/8 或 v0.6 的数值结论，但说明 corrected-instrument v0.3 只能作为历史失败证据。后续
若需要恢复该测试的合法正路径，应新建版本化迁移协议，明确旧位置如何映射到当前 registry，再生成
新工件；不得覆盖原始 v0.3 历史文件。
