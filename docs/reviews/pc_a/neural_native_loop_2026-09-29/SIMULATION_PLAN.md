# 第二轮预先固定：动作反馈驱动下一次观察

当前缺口是：真实 RGB 回来了，但只有语义 producer 能新增原生来源；未识别出完整语义过渡时，相机测量没有进入下一次联合行动信念。不能为接线伪造人物/接触语义，也不能把一次未检出当成长时习惯撤回。

本轮增加可选、显式配置的相机 outcome decoder（结果解码器）。它只读取实际成功动作返回的 RGB，输出与该动作发布时的条件观测模型一致的离散测量或 abstain（弃权）。消费者按原动作保存的全联合 atom likelihood（原子假设似然）做 Bayes 条件化，保留 unknown atom 和完整相关结构。结果仅作为同一原生批次上的短时行动视图，不改原生证据、解析统计或 RGRC 账本。

解码器的模型/源码/加载方法固定；调用方不传入“已验证标签”或后验。当前视图从拥有的命令、实际回包、保存的问题、同一个配置解码器重建，不缓存调用方提供的概率。每个结果绑定动作和原始观测，失败执行/弃权不伪造未检出。新原生批次或纠错代不自动继承旧似然，避免语义入口已经吸收图像后的重复计数。SQLite 恢复重新提供同配置解码器，不能重发已执行动作。

仿真用已有真实 AI2-THOR 程序和 ProcTHOR 训练房屋。先做固定几何可见性检查：从给定相机位置转动朝向，场景内已有苹果在两个预设位置之一；位置由 evaluator（评估端）固定，不由方法动作决定。仅评估端保存对象位姿、像素 mask/可见性。方法只收到 RGB 和执行状态。摆放/初始化为外生场景干预，不算机器人抓取、导航或放回成功。

保留现有三网络候选；仿真先用一种明确标注的接线开发配置，随后三臂接口均复验。使用现有官方 SSDLite 像素类别检测作为测量，默认0.5过滤值沿用已有开发前端。detected/not_detected 是检测器输出，不是独立身份真值或可靠不存在证据。观测似然与相机效用必须公开标为 ASSUMED_NOT_CALIBRATED；不据运行结果选正式阈值或架构。

两轮审查：第一轮检查实际回包→条件后验→下一动作、解析数值、失败/弃权、no-double-count 和长期账本不变；第二轮检查完整伪造结果、换 decoder/导入依赖、状态恢复、重复/乱序/旧模型与旧 generation。先冻结代码依次完成两审，修复则重新冻结重审。之后真实仿真报告每次动作、RGB摘要、测量、前后联合概率、决策与停止原因，保留失败和零收益。

开发条件仍不支持自然手物交互、人物身份、完整任务成功或学习优势。第三轮再增加公平、同起点/同预算、有实际动作后果的比较；不会复用历史17步冷启动差异作收益证明，也不修改B正式比较协议。
