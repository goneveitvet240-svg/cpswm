# CPSWM · 持续个性化语义世界模型

研究机器人如何理解共享空间中的人物行为、持续学习个体习惯，并在新证据出现时修正旧记忆。

[English](README.md) · [文档](docs/README.md) · [开发进展](docs/DEVELOPMENT.md) · [复现说明](docs/REPRODUCTION.md)

## 研究问题

机器人上次看到杯子在厨房台面上，后来却在书桌上发现它。是谁移动的？这是一次临时使用、两个人之间的交接，还是某个人的习惯变了？一次漏看，不应直接变成对人物习惯的确定判断。

CPSWM 研究选择性观察、隐藏事件、多人共享、未知人物或物体，以及习惯变化同时存在时的推断与记忆。目标是让机器人保留合理的多种解释，在证据不足时主动核实，并把后续纠正落实到记忆和行动。

## 方法思路

系统区分原始观察、候选事件、当前信念和长期个体记忆。记忆更新保留证据来源和修订历史；新证据推翻旧解释时，可以撤回相应统计贡献。

设计中的数据流为：**观察与反馈 → 事件及人物角色候选 → 联合信念 → 可修订记忆与行动 → 新观察**。这条完整闭环仍在实现中。

推断框架使用类型化粒子维护隐藏事件链、人物角色、实例身份、变化原因、习惯阶段、持续长度和修订谱系，并维护三个条件解析块。七个算子协同处理观察证据、隐藏事件推断、变化归因、阶段修订、可逆记忆与主动验证。详细定义见[技术框架](https://github.com/goneveitvet240-svg/cpswm/blob/codex/dual-pc-handoff-20260912/docs/结构二/01_结构二完整框架与技术路线.md)。

## 当前进展

开发分支包含证据记录与回放、可逆记忆组件、条件推断接口、RGB-D 感知和模拟器适配。近期工作包括真实手物交互录像中的物体候选评价，以及持久运行状态与相机动作接口的连接。

目前尚未用经校准的自然观察完成感知—记忆—行动闭环，也没有确认完整方法优于对照。具体实现、局部实验和失败结果见[开发进展](docs/DEVELOPMENT.md)。

`main` 保留较早的基础代码；新实现位于审查分支。运行前请按[复现说明](docs/REPRODUCTION.md)选择版本。
