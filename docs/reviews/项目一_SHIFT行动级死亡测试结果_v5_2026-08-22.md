# 项目一 SHIFT 行动级死亡测试结果 v5（2026-08-22）

## 严格判决

- **v5 causal prefix-online contract：接受为当前 synthetic benchmark 的确认性契约。** 三种 detector 的每次 prediction 只读取对应 prefix；change-time estimate、decision time 和 posterior-at-decision 已分离；verification 与 consolidation 使用真实可见证据和后续 prefix。
- **研究总判决：`INCONCLUSIVE`。** shared-policy 给出 `REBUILD_JOINT`，independently-retuned-policy 给出 `USE_ORDINARY`；两轨路线不一致。
- **action baseline guardrail：触发。** legacy retuned 与 `never-act` 完全相同，其他 detector 也未在两轨都以 MDE 0.05 击败 `never-act`，因此不得确认 legacy 或 ordinary 优势。
- **joint CF-BOCPD：继续停止直接扩展。** 当前没有支持 joint 进入正式 11 臂实验的行动收益证据。
- **v4 `REBUILD_JOINT` 与 legacy 优势：不接受为论文确认性结论。** v4 只保留离线代理方向证据。
- **正式结构一 B1 与 11 臂联合实验：继续 BLOCK。** v5 没有产生可以解封扩展的稳定方法选择。

本结果仍是 synthetic causal prefix-online benchmark，不构成 external validity、真实具身任务效用、general superiority 或 state-of-the-art 证据。

## Prefix-online 与时序复核

- validation ledger 共 1620 条 candidate trajectories，每条恰含 day 3–day 10 的 8 个 prefix snapshots。
- 每个 snapshot 保存 prefix input hash、可见 evidence IDs、当前 posterior 和首次 change-time estimate；validator 从 params 与 split input 确定性重放。
- 两轨三臂 TEST 共 1800 个 outcomes：902 次 reset、339 次 semantic verification、181 次 consolidation。
- 902/902 reset 满足 `change_time_estimate < decision_time = reset_time`。
- 339/339 verification 使用 `owner-associated-repeat-object-location@1`。
- 181/181 consolidation 均发生在 verification 之后的真实 prefix cutoff；不存在机械 `+1 microsecond`。
- action truth 逐案例绑定 `model_input_sha256`、`evaluator_truth_sha256` 和 `generated_case_sha256`。
