# 结构二一页读懂

## 它到底想解决什么

想象一个机器人生活在多人家庭里。杯子昨天在厨房，今天不见了。机器人只看到了前后两个快照，
没有看到中间过程。可能是主人拿走了，可能是家人挪了，可能发生了交接，也可能机器人只是因为
遮挡没有看到。与此同时，主人的习惯会变化，访客还会带来以前没有出现过的行为。

普通做法容易犯四种错误：把“没看到”当成“不存在”；把最可能的隐藏事件当成事实；把家人的
行为写进主人的长期习惯；习惯变化后要么适应太慢，要么把以后还会回来的旧习惯删掉。

结构二要建立的是一个 continual personalized semantic world model（持续个性化语义世界模型）：

> 它不只记“物体在哪里”，还要记机器人为什么这样相信、谁可能做了什么、哪些内容仍不确定、
> 哪些长期习惯可以提交，以及以后出现反证时怎样撤销和修正。

## 七个算子用大白话解释

| 算子 | 大白话 | 解决的核心错误 |
|---|---|---|
| OPCEU | 先判断机器人有没有机会看到，再决定“没看到”算不算证据 | 不把遮挡和没路过误当成物体不存在 |
| ORRER/CHEH | 为看不见的时间间隙保留多条事件链，例如拿起、携带、交接、放置 | 不把一个 top-1 猜测永久写成事实 |
| PCHMP | 在物体、人物、事件、位置和来源之间传递受约束的信息 | 不让推断结果循环冒充新证据 |
| CF-BOCPD | 判断变化来自观察方式、人物、身份、习惯还是噪声 | 不把访客出现误判成主人换习惯 |
| CCRR | 在保持旧阶段、新建阶段、恢复历史阶段和继续未决之间竞争 | 既适应新习惯，又保留可能回归的旧习惯 |
| RGRC | 决定证据先隔离、再晋升、撤销还是纠正版提交 | 不让错误人物归因污染长期记忆 |
| CIAV | 选择是否换视角、查容器、调整路线、询问或暂不行动 | 用最小打扰获得真正能改变决策的证据 |

## 完整闭环

```text
任务、路线、相机和检测结果
        ↓
OPCEU：这次没看到是否真的有信息？
        ↓
ORRER/CHEH：中间可能发生过哪些事件链？
        ↓
PCHMP + 类型化粒子：联合维护人物、实例、事件、原因和阶段假设
        ↓
CF-BOCPD + CCRR：这是噪声、换人，还是习惯真的变了？
        ↓
RGRC：隔离、提交、撤销或修正长期记忆
        ↓
CIAV：是否值得再看一眼、检查、询问或保持未决？
        ↓
搜索、放回、递送、提醒和协助
        ↓
执行反馈重新进入证据链，必要时撤销过去的派生结论
```

## 统一主干怎么工作

当前选定主干是：

> Neural Amortized Proposal + Rao-Blackwellized Typed Particle Revision + Reversible Consolidation
> 神经摊销提议 + Rao-Blackwell 化类型粒子修订 + 可逆巩固

它分三层权限：

1. 神经模型只能提出和打分候选；
2. 类型化粒子层负责归一化、物理/人物/来源约束和修订；
3. 可逆 RGRC 账本是唯一可以写入长期人物记忆的组件。

神经模型认为“这是主人”不等于系统就能把它写成主人习惯。它必须经过结构约束、来源检查、
责任后验和长期写入门。

## 最终要证明什么

结构二不是只追求预测准确率。最终主效用是 PCT（惩罚后任务完成时间），同时把污染、恢复、
安全和隐私作为不能被速度抵消的硬护栏。论文必须回答：

- 搜索、放回和交接是否真的更快或损失更低；
- 在线计算是否比强匹配方法更划算；
- 少量错误是否能够快速、完整地恢复；
- 是否会把错误人物行为写入长期记忆；
- 局部修订在信念、行动和效用上是否接近完整重跑；
- 七个算子各自和联合起来是否有可归因的贡献。
