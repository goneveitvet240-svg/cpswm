# 项目一 SHIFT 行动级死亡测试结果 v4（2026-08-22）

> **确认性结论已撤回：** v4 解决了候选账本伪造、预测重放和功效门问题，但三个 detector 仍在完整 observation stream 上生成一次性 prediction，并把历史峰值混同于在线 decision。v4 不构成真正 causal prefix-online action death test；其 `REBUILD_JOINT` 和 legacy 优势仅保留为方向性证据，论文确认性判断必须使用全新 TEST seeds 的 v5。

## 严格判决

- **action death-test contract：不再接受为论文确认性契约。** validation candidate ledger、argmin 重算、input+params+prediction deterministic replay 与 power gate 仍然有效，但缺少真正 prefix-online decision semantics。
- **joint CF-BOCPD：方向性 `REBUILD_JOINT`。** shared-policy 与 independently-retuned-policy 两轨的离线代理结果显示 joint 相对 legacy independent CF-BOCPD 的 regret 劣势，但不得作为论文确认性优势声明。
- **v3/v4：均仅保留方向性否决证据。** 论文确认性判断必须等待 v5。
- **正式结构一 B1：尚未完成且继续 BLOCK。** v4 不再解除 action death-test 前置阻断，更不构成正式 B1 完成证据。
- **11 臂联合实验：继续 BLOCK。** 当前不得把被否决的 joint 直接扩展到全局 11 臂；应先重构 joint，或由项目所有者选择 ordinary/legacy 路线后重新预注册。

本实验仍是 synthetic action proxy，不支持 general superiority、state of the art、external validity 或正式具身效用主张。
