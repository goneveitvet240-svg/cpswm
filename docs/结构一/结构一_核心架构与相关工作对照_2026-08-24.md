## 0. 一句话定位

> 结构一是 CPSWM 三条方向里**范围最宽**的一条，也是**实现最少**的一条。
> 它是「家庭世界模型」本身；结构二只是它的一个困难切面，结构三只是它的一个下游闭环。

三条结构的关系，用一句话区分：

| | 回答的问题 | 时间尺度 |
|---|---|---|
| **结构一** | 这个家里有什么人、什么物、什么规律？机器人到底理解了这个家多少？ | 跨天 / 跨周 / 跨月 |
| 结构二 | 在观察是选择性的、有人干扰、习惯会变的条件下，怎么把上面那些**学对** | 一个观察间隙 ~ 一个阶段 |
| 结构三 | 模糊语言进来时，怎么把上面那些**用对**，不确定时怎么主动确认 | 一次任务 |

**结构一明确拒绝被以下任何一句话定义**：只研究是否重新观察、只研究物体搜索、
只优化 ECE/Brier/NLL、只优化搜索时间、只把项目表述为部分可观测问题、
只训练一个 next-location predictor。

## 1. 核心架构

### 1.1 家庭语义场景图（表示的骨架）

```text
G_t = (V_t, E_t)

节点：person / object instance / room / furniture / container / activity / household role
关系：located_at · inside · on · near
      belongs_to · used_by · shared_by
      held_by · carried_by · transferred_to
      supports_activity · normally_stored_at
      observed_by · inferred_from · predicted_by
```

注意最后一组：`observed_by / inferred_from / predicted_by` 是**关系词表的一等公民**。
「这条边是怎么来的」和「这条边是什么」被放在同一层——这是整个结构一最重要的一条表示决定。

### 1.2 六类彼此分离的长期内容（真正的核心设计）

| 内容 | 回答的问题 | 能否直接当事实 |
|---|---|---|
| direct observation | 当时真正看见了什么 | 带质量的证据，不等于永远有效 |
| episodic event | 谁何时对什么做了什么 | 需保留来源和有效时间 |
| inferred event | 观测间隙可能发生了什么 | **否**，保留多个候选 |
| habit distribution | 长期通常怎样 | **否**，只能作为统计先验 |
| future prediction | 下一次可能怎样 | **否**，**不能反向训练自己** |
| preference / norm | 主人希望或家庭规定怎样 | 需与实际行为分开 |

这六类的**分离**才是结构一的架构，不是那张场景图。
分离一旦塌掉，系统就会出现四种经典失败：把没看见当不存在、把两次快照差当成某人的移动事件、
把当前状态频率当成长期习惯、把模型预测喂回自己当训练数据。

> `future prediction` 那一行「不能反向训练自己」是本仓库反复出现的一条硬约束，
> 项目一评测协议里的 `预测 → 决策 → 学习` 模板方法就是它的代码化身。

### 1.3 联合概率状态

```text
B_t = P(L_t, I_t, S_t, R_t, E_t, A_t, Z_t, Θ | O_1:t, C_1:t, K, G_1:t)
```

L 位置 · I 实例身份 · S 状态（拿取/使用/携带/收纳）· R 关系 · E 隐藏事件 ·
A 行为者 · Z 习惯阶段 · Θ 长期习惯参数；
条件里 `K` 是物体属性与通用常识，`G_1:t` 是场景图历史。

**关键一句**：「选择性观察信息只是 `O_1:t` 的质量与缺失机制之一，不是整个模型的中心变量。」
这句话是结构一对结构二的边界声明——结构二不能反过来定义结构一。

### 1.4 三层位置知识分解

三个归一化 posterior（后验）不得直接相乘后充当唯一正式模型。保留三条公平比较路线：

- hierarchical Bayesian shrinkage（分层贝叶斯收缩；当前 additive pseudo-count baseline）；
- mixture of experts（专家混合；显式非负门控）；
- tempered product of likelihood-ratio experts（温度化似然比专家乘积；每个 expert 必须声明
  reference prior、温度和概率地板）。

三条路线只用 validation（验证集）选择，本文不预先替用户选定。

约束：个性化证据可以**逐渐**覆盖常识，但**一次异常不能彻底覆盖**长期规律。

### 1.5 多轴移动性画像与七个非互斥派生标签

正式状态是 stationarity、entropy/modality、return propensity、activity coupling 与
regime-change status 五轴；七类只作为可重叠的展示标签。活动或阶段轴没有证据时必须标为
`unassessed`，不得从位置频率硬推断。

| 类型 | 含义 | 例子 |
|---|---|---|
| anchored 锚定 | 几乎不动 | 冰箱 |
| stable 稳定 | 有清晰固定位置，偶尔短暂移动 | 路由器、台灯 |
| home-based mobile 主位置可移动 | 常被拿走，但大多回到主位置 | 钥匙、遥控器 |
| multimodal 多常用位置 | 长期存在多个情境化高频位置 | 水杯、眼镜 |
| activity-carried 活动携带型 | 位置由活动链决定 | 清洁工具 |
| wandering 游走型 | 高熵，难成模式 | 儿童玩具 |
| regime-changing 阶段变化型 | 主位置随生活安排持续改变 | 搬家后的收纳物 |

每个实例保存：主位置及置信度、Top-K 常用位置与条件、位置熵/移动率/返回率/停留时间、
人物条件化转移矩阵、活动触发位置、当前与历史阶段、异常位置及解释、下一位置预测及不确定性。

### 1.6 四类规范分层

| 类型 | 例子 | 机器人用途 |
|---|---|---|
| observed habit | 主人经常把外套放沙发 | 预测和寻找 |
| stated preference | 主人说希望挂进衣柜 | 整理和操作 |
| household norm | 家里规定药品放高处 | 安全约束 |
| commonsense norm | 生鲜通常要冷藏 | 通用安全先验 |

由此得出结构一最实用的一句话：

> **「最可能在哪里找到」与「机器人应该放回哪里」是两个不同的决策问题。**

## 2. 项目纲领

### 2.1 十二个研究问题

| | 研究问题 |
|---|---|
| RQ1 | 长期、连续、**非任务限定**地观察家庭，而不是收到命令才感知 |
| RQ2 | 跨时间、遮挡、视角变化和相似实例维持**具体物体身份** |
| RQ3 | 学习家庭常景、物体属性、功能、空间约束和常识归属 |
| RQ4 | 判断物体是稳定 / 主位置可移动 / 多模态 / 游走 / 阶段变化型 |
| RQ5 | 学习人物—物体—时间—活动—情境条件下的个性化摆放与使用习惯 |
| RQ6 | 保存多个常用位置、返回规律、位置转移和下一位置预测 |
| RQ7 | 未观察到拿取/携带/放置/交接时，维护多个隐藏事件解释 |
| RQ8 | 区分主人 / 家人 / 访客 / 机器人自身造成的变化，避免习惯污染 |
| RQ9 | 区分周期情境 / 偶然异常 / 渐进变化 / 突然变化 / 旧习惯回归 |
| RQ10 | 区分**观察到的行为**、**主人明确偏好**和**家庭整理规范** |
| RQ11 | 通过自然语言查询历史、习惯、预测、证据和不确定性 |
| RQ12 | 让长期家庭模型改善协助、搜索、导航、递送、整理和放回 |

> 结构二等价于 **RQ7 + RQ8 + RQ9** 在「选择性观察」这一约束下的联合形式。
> 也就是说：**结构二是结构一 12 个 RQ 里的 3 个。**

### 2.2 十条工作流与八个阶段

WS1 长期观察与常景 · WS2 实例属性功能常识 · WS3 情景记忆与证据图 ·
WS4 移动性画像与多位置记忆 · WS5 人物条件化习惯 · WS6 多人物与隐藏事件 ·
WS7 非平稳持续学习 · WS8 预测查询解释 · WS9 协助闭环 · WS10 隐私与长期基准

阶段 P0 底座 → P1 长期真值与选择性观测 → **P2 属性/常识/移动性/多位置（自评为「下一核心推进」）**
→ P3 事件与多人物 → P4 非平稳 → P5 查询与预测 → P6 主动协助 → P7 真实部署

### 2.3 五层评价（分层不可互相替代）

1. 感知与场景层 · 2. 世界模型与记忆层 · 3. 习惯与持续学习层 ·
4. 查询与具身任务层 · 5. **成本与校准层**

纲领明写：第五层（NLL / Brier / ECE / 路径 / 时间 / 询问次数）
「用于检查概率是否可靠、决策是否值得，**但不能覆盖或替代前四层**」。

### 2.4 八条**刻意未决**的技术选择

结构一 §17 明确列出**不替用户决定**的八项：习惯模型族（贝叶斯 / GNN / 混合）、
隐藏事件方法（因子图 / DBN / 粒子滤波）、变化模型（BOCPD / 遗忘因子 / sticky HMM）、
常识来源（KG / VLM / 视觉属性）、数据来源（符号生成 / 物理仿真 / 真实回放 / 真实采集）、
单篇论文先聚焦哪个 RQ、仿真平台（Habitat / iGibson / Isaac Sim）、真实机器人平台。

**这是一个优点也是一个风险**：它保住了范围，但也意味着结构一至今没有一条被冻结的技术主线。

### 4.2 一句话读这张表

**12 个 RQ 里，9 个已经被单独覆盖，2 个已经被实测打平或击败，只有 2 个还是空白：**

- **RQ8 的核心**：从被动观察推断「谁移动了哪个具体物体」，并据此隔离主人模型；
- **RQ10 的整体**：observed habit / stated preference / household norm / commonsense norm
  四层同时维护，并把「区分准确率」本身作为指标。

再加上一个次级空白：

- **RQ4 的七类在线移动性画像**（现有工作都是二值稳定性或三分箱刚性）。

### 4.3 结构一的处境比结构二更难

结构二至少有一条「六列全 ●」的组合空白可以站；
结构一的每一个 RQ 单独看都有人做过，**它的宽度本身就是它的弱点**：
审稿人会逐条问「这一条 X 做过了，这一条 Y 做过了，那你的贡献是哪一条？」

## 5. 我们采取的改进措施

### 5.1 表示层（结构一自己的设计决定）

| 措施 | 针对的失败 | 与已有工作的差别 |
|---|---|---|
| **六类长期内容强制分离** | 把推断当观测、把预测喂回自己、把当前频率当长期习惯 | WorldLines/ObsMem 有 typed memory views（事件/状态/信念/承诺/证据），最接近；但它的习惯层是规则/检索，不是从多人不完整观察在线估计的概率规律 |
| **来源关系进词表**（`observed_by / inferred_from / predicted_by` 作为一等边） | 事后无法回溯「这条边怎么来的」 | 多数场景图工作把来源放在属性里或不保存 |
| **三层位置分解** `P_common × P_household × P_person` | 常识被一次异常覆盖 / 个性化永远压不过常识 | AEG 做 common+功能，PerSim 做 population+人格，**没有把 household 惯例作为独立一层** |
| **七类移动性画像** | 「固定 vs 移动」二分丢掉主位置回归、多模态、阶段变化 | POCD/Glasses 二值，PerSim 三分箱 |
| **四层规范分层 + 「找得到」≠「该放哪」** | 把主人的实际行为当成主人希望的规范 | 各家只做一层 |

### 5.2 方法论与治理层（目前最扎实、最难被质疑的部分）

这一层是本仓库真正的差异化资产，而且**不依赖任何一条曲线赢**：

1. **「已有覆盖提醒 — 创新状态」双卡片强制协议**：每发现一个近邻必须先写它已实现的功能、
   具体方法、证据等级、重合范围，然后才写自己的创新状态。杜绝「绕开」和「包装」两种失败。
2. **九级创新台账状态机 + 可执行门禁**（本轮新增 `innovation_ledger.py`）：
   未到 `direct baseline passed` 不得进贡献列表，「首次 / state of the art」直接抛异常，
   且**对冲词不豁免**（"作为一个候选创新，我们首次提出…" 照样拒）。
3. **预注册死亡测试 v1→v5**：预注册 → 冻结 → 结果三段分离；
   ATG-3 解封需七项 receipt 同时校验，解封后禁止重调参与二次解封。
4. **独立调参强制**：每臂独立 18-trial 搜索空间 + trial 前向哈希链，
   禁止「新方法调优 vs 旧方法默认」。
5. **实测预算而非声明预算**：时间 / 预测次数 / p95 延迟 / 峰值内存 / 持久字节 / 参数量全部实测入 receipt。
6. **重采样单元是轨迹不是事件**：避免把同一轨迹内相关样本伪装成独立样本。
7. **action baseline guardrail（`never-act` / `always-reset-verify`）**：
   这条护栏直接把 v4 已得出的「legacy 优势」判为不成立。**很少有人会给自己设这个。**
8. **机器可读进度账本 + 验证器**：逐模块 `allowed_claims` / `forbidden_claims`，
   证据内容哈希逐字节核验，矛盾声明自动检测，required gate BLOCK 即非零退出。
9. **对抗式自攻测试**：逐臂绑定篡改、外层重签、pydantic `model_copy` 绕过嵌套校验器、
   symlink 覆盖受保护文件——四轮全部 fail-closed。
10. **来源防火墙贯穿全栈**：oracle 通道与普通通道互斥；`gt.*` 授权禁止授予
    感知/世界模型/语言/行动前缀的 subject；合成适配器**源码级断言**不 import `cpswm_gt`。

> 对海外 RA / PhD 申请来说，第 5.2 节比任何一条曲线都值钱：
> 你展示的不是「做了一个系统」，而是「建立了一套让自己无法自欺的实验治理体系」。
> 第 7 条尤其罕见——主动设置一条能推翻自己已有结论的护栏，并且真的推翻了。

### 5.3 五条跨领域一级技术路线（2026-08-23 冻结）

把 incremental view maintenance / 双时态数据库 / MVCC、information-flow control 与
taint tracking、machine unlearning 与多模型估计、object-centric process mining 与
truth maintenance、self-adjusting computation 与因果一致性，正式引入具身世界模型。

**§4 那些「已被覆盖」的机器人文献，没有一篇是从这五个领域切进来的。**
这是结构一目前最有辨识度的差异化角度，也是唯一一条不与现有机器人工作正面撞车的路。

风险：七个算子 + 五条路线 = 十二条同级主张，而没有一条通过 `direct baseline passed`。
文档治理上并列是对的，**投稿上必须收敛到一条中心因果链**。

## 7. 结构一特有的三个风险

1. **宽度即弱点。** 12 个 RQ 里 9 个已被单独覆盖。必须选一个 RQ 做深，
   而不是把「12 个都做」当成贡献。按覆盖矩阵，**RQ10 是最干净的空白**，
   RQ8 次之（但结构二已经在那里撞上 AMG 了）。
2. **八条未决技术选择还没冻结。** 保住范围是对的，但至今没有一条被冻结的技术主线，
   意味着任何一次实验都可以被「那不是我们最终的方法」解释掉——
   这会让所有负面结果失去约束力。
3. **感知层是空的。** RQ1–RQ3 依赖的 M07/M08/M10/M11/M12 全部 `absent`。
   在这五个模块存在之前，结构一在真实数据上不可评测。
   进度盘点的建议是**走路线 A（数据集适配），把 M05 dataset adapter 的优先级提到 M07–M12 之前**——
   这是绕开 SLAM 直接拿到真实数据的唯一捷径。

## 8. 建议的下一步（针对结构一）

1. **RQ10 做成一篇。** 四层规范分层 + 「区分准确率」作为一级指标，
   直接对照 TidyBot（stated preference）、Housekeep（population norm）、
   Interpretable Constructs（四构念）、TAACo（稀疏反馈）。
   这是结构一唯一一个既有空白、又不需要感知层的 RQ——**可以现在就做**。
2. **冻结两条技术选择**：习惯模型族、数据来源。其余六条可以继续未决。
3. **M05 dataset adapter 优先于 M07–M12**，先拿到真实数据的部分标注轨。
4. 别让结构一继续以「12 个 RQ 全做」的形式存在于投稿计划里——
   它可以以那种形式存在于**项目**里，但不能存在于**论文**里。
