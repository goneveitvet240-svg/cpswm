# 项目一 ATG-1 消融拓扑门闭环

日期：2026-08-22

协议：`project-one-ablation-protocol-pilot@0.2`

门名称：`ATG-1`（Ablation Topology Gate 1，消融拓扑门一）

## 1. 命名边界

旧评审记录中的狭义“消融 B1”统一更名为 `ATG-1`。它只表示把 joint
CF-BOCPD 作为第 11 个消融臂接入协议拓扑，不表示结构一正式 B1。

结构一正式 B1 始终指 M05–M12：机器人与传感器适配、标定与同步、
VIO/SLAM、三维场景、可观测性、开放词汇感知、实例重识别、人物与交互事件感知。
这些能力尚未完整推进，因此：

> “正式结构一 B1 已完成”不成立，状态保持 `BLOCK`。

## 2. ATG-1 契约闭环

`ProjectOneProtocolPilotManifestV2` 现在除检查 11 臂各出现一次外，还检查：

- 全部 11 臂的 `independent_tuning_run_id` 全局唯一；
- 每臂绑定同一 validation split、封存 TEST split 和 observation trace；
- 嵌套 comparison/arm 从普通数据重新验证，拒绝 `model_copy` 绕过。

`ProjectOneProtocolPilotReportV2` 对每个臂重新绑定并核验：

- 所属 comparison 及 comparison manifest ID/hash；
- manifest 中具体 arm 的内容 hash；
- independent tuning run ID；
- declared model version 与方法注册表；
- method semantics 与 manifest components；
- topology result 与 topology binding hash。

对应 tamper-negative tests 覆盖跨 comparison 重复 tuning ID，以及 comparison、manifest
arm、tuning run、model version、method semantics、topology status/hash 的篡改。

## 3. v0.1 兼容与输出安全

v0.1 不是仅保留 JSON hash。本快照同时保留冻结的 v0.1 schema、Runner、CLI、在线
suite 与 ordinary/legacy CF-BOCPD 依赖，并以 round-trip regression test 和真实 CLI
subprocess test 验证：

- v0.1 config/report 均可反序列化和往返回归；
- v0.1 Runner 与 CLI 可以逐字节重新生成权威 report fixture；
- v0.2 拒绝 `output == config`，且 `benchmarks/` 下所有路径均不可作为输出；
- 已有输出默认拒绝覆盖，仅显式 `--force` 可覆盖非 benchmark 输出；
- 写入采用临时文件、`fsync` 和原子发布，不暴露半写报告。

报告不再接受自由文本成功声明。`caveat_ids`、`allowed_claims`、
`forbidden_claims` 和逐臂 `note` 都是固定的版本化规范 ID；篡改为“executed”、
“superior”或“state of the art”等声明会被 schema 拒绝。

`SealedSplitMetadata` 已改为受约束的 `ContractModel`：实验 ID 非空，全部 hash 为
64 位小写十六进制，case count 非负；三类 split 计数之和必须等于 artifact manifest
计数，并且 split identity 与计数必须重算得到声明的 artifact manifest hash。计数同时
写入 manifest 和 report 并做双向绑定。

## 4. 后续门继续封锁

- `ATG-2`（旧消融 B2）：每臂独立调参和实测预算账本，`BLOCK`；
- `ATG-3`（旧消融 B3）：凭合规 receipt 解封 TEST，并运行 ordinary / legacy
  independent / joint 三臂公平比较，`BLOCK`。

ATG-1 不运行模型、不读取或生成 TEST case、不调参、不产生性能指标，也不解除
ATG-2/ATG-3。

## 5. 当前判断

1. “正式结构一 B1 已完成”：不成立，`BLOCK`；
2. “第 11 臂纯拓扑正常接入”：成立于 ATG-1 契约与测试范围；
3. “第 11 臂拓扑契约已经闭环”：两个已复现漏洞修复并由负向测试封口后，成立于本
   Git 快照的协议范围；不等于实验闭环；
4. “joint CF-BOCPD 做得比已有方法更好”：没有实验，禁止宣称。
