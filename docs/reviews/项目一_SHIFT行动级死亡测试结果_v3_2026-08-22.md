# 项目一 SHIFT 行动级死亡测试结果 v3（2026-08-22）

## 判决

最终双轨判决：**`REBUILD_JOINT`**。

v3 使用完整 `RESET → CONSOLIDATE` 恢复语义、missed consolidation 长期未恢复代价，以及第三组全新 151 TEST seeds（11101–11401 奇数）。shared-policy 与 independently-retuned-policy 两轨均显示 legacy independent CF-BOCPD 相对 joint CF-BOCPD 的 action regret 优势超过 MDE 0.05。

## 契约修复状态

- power analyses 每轨精确四项、两轨八项；空、重复、遗漏、乱序均拒绝。
- empirical paired stddev、required n、status 从 pilot artifacts 和 config pilot seeds 重算。
- 两轨 required n 最大值为 151，全部 PASS 后才生成 TEST。
- 独立轨道每臂相同 18 × 117 = 2106 validation-only candidates。
- consolidation 强制以 `RESET_OLD_REGIME → CONSOLIDATE_NEW_REGIME` 顺序出现。
- 未 consolidation 的真实 habit case 标记 `missed_consolidation`、保持未恢复并令 task-success proxy 失败。
- 逐案例 prediction/truth/outcome、aggregate metrics、power 和 paired intervals 均可重算。
