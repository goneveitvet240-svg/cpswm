## 2026-08-26 已选择路线

项目负责人已选择以下技术路线；这些选择扩大并具体化完整结构三，不授权删除原有能力：

| Gate | 选择 | 方法含义 | 当前落地状态 |
|---|---|---|---|
| S3-DG-09D | Multi-parse posterior compiler（多解析后验编译器） | 不把模糊原话提前压成单一查询；维护解析后验并对实例后验边缘化，未解析和拒答质量进入显式 `unknown` | 核心契约、边缘化融合与测试已落地；真实 LLM provider、校准集和 prompt 实验待接入 |
| S3-DG-10D | Probabilistic dynamic instance graph（概率动态实例图） | 联合维护已有实例、新实例和未知关联；只有通过阈值与 margin 门的关联才能投影到动态地图 | 关联图、证据簇去重、frame/anchor 校验与门控地图写入已落地；真实 RGB-D/点云/re-ID 模型待接入 |
| S3-DG-14D | Revision-aware neuro-symbolic evidence graph（可修订神经符号证据图） | VLM/感知输出只是 proposal（提案）；人物和事件经独立验证后才激活，习惯是可随事件撤回的软证据 | 人物—事件—习惯修订链、授权绑定和撤回投影已落地；真实跟踪、事件提议与长期估计器待接入 |
| S3-DG-11E | Habitat + Isaac/ROS dual platform（双平台） | FindingDory/Habitat 与 Isaac/ROS 使用隔离运行时，但共享任务、动作、结果和成本语义 | 双平台描述符、能力覆盖和语义一致性门已落地；sidecar（侧车）适配器和真实运行待接入 |
| S3-DG-12C | Complete neighbor audit（完整邻近系统审计） | 强邻近系统不得被静默排除；必须冻结版本复现，或基于证据排除，未完成时禁止 sealed comparison（封闭比较） | 六系统完整登记和 fail-closed（失败关闭）比较门已落地；各系统复现状态仍诚实标为 pending |
| S3-DG-13D | Layered hybrid ingress（分层混合入口） | `datasets` 只负责固定 revision 获取，规范评测读取内容哈希 JSONL；原始 Parquet 由 `pyarrow` 旁路保留 | 固定 commit、流式获取、不可变 JSONL、哈希验证和可选依赖组已落地；真实官方快照尚未下载 |
