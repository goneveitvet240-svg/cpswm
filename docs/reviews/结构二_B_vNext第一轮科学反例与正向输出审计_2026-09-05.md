## 科学反例攻击

### Gate B v0.8

1. **任意 runtime engine 替换**：原链允许 runtime receipt 自报一个未在 preregistration 中冻结的 engine digest。修复后 `expected_runtime_engine_sha256` 在 task plan、canonical binding、raw output 和 runtime receipt 间逐层相等，否则拒绝。
2. **伪造 readout trace digest**：原 `belief_trace_sha256` 与 `action_policy_trace_sha256` 可由调用者填写任意 SHA-256。修复后 digest 从 runtime state、decision/info hashes、公共本体以及实际 belief/action/policy/projection 字段确定性推导；改 payload 而保留旧 digest 会失败。
3. **fresh registry clone**：攻击者在另一 canonical path 创建同 UUID/metadata 的新 SQLite registry。修复后 policy/root manifest 同时冻结 canonical path 与 storage identity；另一位置 clone 被拒绝。
4. **同路径 replace/rollback**：攻击者以 clone 替换已登记路径。修复后 registry 使用 `O_NOFOLLOW` 打开、要求 regular file 且 `nlink=1`，冻结 canonical path + `st_dev` + `st_ino`，并在连接前后用 guard file descriptor 与 path identity 双检；同路径替换在 replay commit 前被拒绝。
5. **比较语义反例**：action-regret 必须同时满足决策前 belief equivalence、action difference 和 utility difference；full-rerun 必须同时满足 belief/action equivalence；causal comparisons 必须在冻结 window 内出现 material belief/action difference。任一关系或阈值不符均不能转化为 typed positive。
6. **覆盖作弊**：公共 episode ontology 必须精确覆盖 10 个 arms 的 arm×episode cells，location UUID 数为 8–12、独立 guest 为 1–3，并覆盖 `put_back/search/deliver/ask`；lossless projection 与每步 broker 链缺失时拒绝。

局限：本地 SQLite identity guard 可以阻断已测试的 clone 与同路径 inode 替换，但不是远端 WORM/transparency log（一次写入多次读取/透明日志）的替代品。当前配置保持 `NOT_ENROLLED`，正式 replay/custody 保证必须由 verifier-owned（验证方持有）后端与独立信任锚完成登记后才可声称。

### Task 7 v0.4

1. 对 20 条随机链、耦合强度 0/1.5、窗口长度 1–4 的 9,121 个 boundary-preserving（边界保持）非自身候选，独立比较局部 conditional-target delta 与完整 `chain_log_target` delta，全部在数值容差内一致。
2. 明确覆盖 one-cell change 与 later-window regime/cell change；无法保持左右边界、非有限目标、无非自身候选或条件目标不一致时走 explicit full-replay fallback（显式全量重放回退）。
3. `W=3`、两 sweep，suffix 为 8/64/256 时窗口目标工作量均为 54、最大 live window items 为 37、reachable overlay 为 314 bytes，untouched suffix read/copy/rehash 均为 0。
4. 2×2×2×2 因素矩阵完整，且 terminal responsible actor 被缓存；belief 轴阈值和 action TV 阈值均保持 0.1，未删除 selected-action equality 或 contamination gate。
5. 科学反例确实击中：local rejuvenation 的 mean/worst max-axis TV 为 `0.2446254387/0.7501398038`，mean/worst action TV 为 `0.1124641575/0.3986280822`，selected-action match 为 `0.9375`，local-minus-full contamination 为 `+0.0029183569`。因此总体保持 `FAIL`，没有用仪器层正向结果覆盖科学失败。

### Task 8 v0.4

1. joint、factorized、matched two-stage 三臂共享相同信息 hash、状态预算和候选 temperature grid；每臂只由 validation units 独立选择参数，冻结后才读取 confirmatory units。
2. consequential endpoint 直接消费 `(H+Z,C)` 的交叉单元；equal-marginal（相同边缘概率）反例会给出不同后果动作，证明端点没有退化为只看边缘概率。
3. 在全部 64 个登记 validation+confirmatory units、temperature=1 时，matched two-stage 对 joint posterior 的最大 L1 差为 `9.0456503969e-16`，验证匹配臂能重构联合分布而非人为弱化比较器。
4. 40 个 confirmatory cells 先按 5 个独立 seed clusters 聚合，再做 10,000 次预注册配对 percentile bootstrap（百分位自助法）。`two_stage_cost - joint_cost` 的 paired mean 为 `-0.0008583299`，95% 下界为 `-0.0020587012`，低于预注册严格阈值 `0.001`；总体保持 `FAIL`，未事后调阈值。
