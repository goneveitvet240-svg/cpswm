# 为什么联合机制仍未产生独有动作收益（2026-10-13）

当前证据支持的判断：**联合项确实改变了后验，但这种差异多数没有形成可用的动作优势。人物采样覆盖已修复，权重退化仍严重；放回读出主要沿用共享基础预测；搜索则没有让原生联合机制控制行动。因此，现有结果既没有证明联合机制独有收益，也不足以否定完整研究路线。**

本报告绑定PR113 `27ef572986feff7af78c04c65f73d850a4017f31`。实际运行来源清单记录 `7cd811103b03961881be3aa4c1c46b066e3e3ba4`，清单内505文件与本次工作树逐一相符。新增工具只做已有修复后留出轨迹的回溯分析，不是新留出实验、参数选择或修复。完整框架范围保持。

## 1. 后验确实不同，动作差异却被完整压在排序间隔内

修复后sparse32/long64、67001–67004，同信息同预算的联合与因子化共384个配对时刻：

| 检查项 | 结果 |
|---|---:|
| 人物边缘分布不同（TV > 1e-10） | 194/384 |
| 最终放回概率分布不同（TV > 1e-10） | 162/384 |
| 人物分布TV均值 / 最大 | 0.031226 / 0.670564 |
| 动作分布TV均值 / 最大 | 0.001778 / 0.061898 |
| 最终放回位置相同 | 384/384 |
| 两臂共同放回错误 | 33 |
| 相同搜索日志（逐字段） | 384/384 |

这里TV是总变差距离 `sum(abs(p-q))/2`，不是准确率或效用。

对每个时刻，取因子化最终分布第一名与第二名的间隔 `m`，联合与因子化各位置概率最大差 `d`。**384/384步均满足 `2d < m`**，因此这些实际分布的差异在数学上不足以翻转argmax。不是只有汇总指标巧合打平，而是逐步排序全部有明确裕量。因子化最终间隔中位数0.963450。

例：sparse32、episode0、第14步，联合主人概率0.2140，因子化0.8846，人物TV达0.6706；但动作TV只有0.0619，基础预测间隔0.8，两者仍选相同正确位置。这反驳“联合项完全没生效”，同时说明“后验动了”距离“行动获益”仍很远。

## 2. 读出主要由共享基础预测决定

重建每个粒子的三个RB解析块、主人目标门控、cause/mechanism/run-length权重及RGRC账本之后，最终读出与原记录逐浮点值一致。

原生读出先要求**当前放置者为owner且实例为target_instance**，再读取该粒子的owner/active-regime RB单元。每个单元内部还将解析分布按信息置信度混回base；剩余概率全部回到base。若有已提升账本，再混入25%的账本分布。

可写成：

`preledger = (1-A) * base + Σ a_i * analytic_i`，其中 `A=Σ a_i`；有活动账本时，`final=0.75*preledger+0.25*ledger`。

| 联合臂，384步 | 诊断 |
|---|---:|
| owner＋target粒子概率质量均值 | 0.32218 |
| cause/mechanism/run门控后质量均值 | 0.13473 |
| 再乘RB信息置信度后的解析质量A均值 | 0.08200 |
| 最终分布中直接base系数均值 | 0.89596 |
| 最终动作与base argmax相同 | 381/384 |
| base单独放回错误 / 完整读出错误 | 36 / 33 |
| 活动账本时刻 / 当步账本改变动作 | 43 / 0 |

“直接base系数”未计账本中继承的历史base成分，不能解释成完整因果贡献。base来自同一冻结v06基础读出，四臂逐步分布完全相同，其第一/第二名间隔中位数0.999352；33个共同错误处的间隔中位数也达0.999255。也就是说，基础预测错误时经常仍非常坚决，而原生联合信号不够强或方向不够可靠。

还存在一个值得专门检验的语义问题：**当前放置者不是主人时，即使粒子保存了主人习惯历史，这段历史也不直接进入此处的owner读出。**这可能抑制“通过访客事件反推主人习惯”的价值。但门控原本也承担防污染功能；是否需要改，必须用合法正路径、访客干扰和错误归因的配对任务检验，不能仅凭本次负结果删掉。

## 3. 采样覆盖修好了，粒子有效支持还没有恢复

169次新位置更新均抽到了多个人物，但联合臂有81次在阈值`单粒子质量 > 1e-8`下只剩一个人物拥有有效样本。全384步中：

| 指标 | 联合 | 因子化 |
|---|---:|---:|
| ESS < 2的时刻 | 349 | 339 |
| ESS中位数 | 1.000000126 | 1.000000081 |
| 非首步每个父粒子恰好一个后代 | 376/376 | 376/376 |
| 分配给归一化父权重 < 1e-8 的后代 | 7554/9024 | 7625/9024 |

ESS（有效样本量）按24粒子的归一化权重计算，不把固定的未解析质量算作第25个粒子。低ESS不自动证明后验错误：有些观察确实可能使后验集中。**但当前分配方式明确没有随权重集中而增加高权重历史的后代数。**

源码将每个父粒子的提议总质量设为`1/24`，修复后的24个分层抽样区间分别落入24个父块，因此每条历史只有一个新分支；后验更新又继承父权重并乘投影、观测及反馈因子。原本低权重的历史继续占据抽样预算，高权重历史仍只得到一个子假设。这解释了为何“名义上24粒子、多个人物”仍可能相当于“实际上一个有分量的路径”。

这是已确认的预算分配现象和明确的风险，尚不是严格的后验误差证明。要判定其中多少是正确集中、多少是近似退化，需要固定开发场景中可枚举/高精度参考后验，再检验同预算父粒子分配与恢复操作。不能仅凭ESS低就宣布修改一定带来收益。

## 4. 当前3次收益全部是冷启动，没有证明后续长期收益

四臂基础分布逐步一致；不消费新位置证据的两臂，384步全部等于base argmax，均36错。消费新证据后，两臂均33错，只改变以下3个动作：

- sparse32 / episode0 / 第1步；
- sparse32 / episode3 / 第1步；
- long64 / episode3 / 第1步。

这3步base均为四位置等概率0.25，新位置证据打破了平局并选对。**第2步及以后，两臂相对于各自no_new对照均没有动作改变。**因此，本轮正结果可支持“新位置证据有冷启动作用”，不能用于声称联合依赖或长期因果记忆已经产生动作收益。此前采样修复相对于旧采样的34→33属于另一个对照轴，不能和本节36→33混为一谈。

## 5. 因子化为什么也能享受这些收益

匹配因子化臂保留完整状态、历史、候选、条件转移、RB更新、反馈、共享位置似然和动作读出；仅把六个显式跨变量interaction potentials（交互势）的最终系数置零。因此这轮检验的是**这六个交互项在其余机制相同条件下的增量价值**，不是“整个联合框架”对“完全独立变量模型”的总效果。

新增位置似然在观察固定后，是按放置者索引的局部因子，两臂均能消费。169次更新中只有9次owner与guest似然相同，其余160次能区分二者；所以不能把结果概括成“人物似然根本没有辨别力”。此前记录中166次在抽样人物支持上有差异，也不保证差异对应的样本有足够后验权重。

六个交互特征均有非零加权出现，联合项没有整体死掉。但它们是当前手设的相容性偏好，不保证对具体任务提供新增信息。例如“handoff且role接收者等于placement_actor”在合法handoff候选上由构造保证，实际更接近handoff偏置，不能仅凭其名字认定存在不可由简单模型复现的依赖价值。其余特征是否提供准确且行动相关的关系仍待严格对照。

## 6. 搜索收益在当前实验里没有开放给原生联合机制

`CurrentEventActionState.predict()`先用独立维护的共享位置头执行搜索，然后把付费发现的位置送回原生模型；最终搜索顺序又显式采用共享头的顺序。共享头不读取原生联合/因子化的后验。这是为同信息对照而保留的设计，但也意味着此设置只能检验后续放回效用，**不能检验联合机制是否更会选下一次观察、查谁、查哪个位置**。

384步共享搜索日志完全一致符合源码设计。不能把它作为联合主动感知无用的反证，也不能把共享搜索变好计作联合独有收益。

## 7. 为什么不能简单调大原生权重

做了一个明确标为离线诊断的极端读出：仅在解析质量A > 1e-10时，归一化该时刻已有RB解析混合，忽略base及账本。联合臂共220个这样的时刻；实际读出在这部分有18错，纯解析读出32错——修正11个原有错误，同时制造25个新错误。因子化在其217个可定义时刻同样18→32。

这不是新策略的闭环运行，也没有重新反馈或调参，更不代表所有中间混合权重都无效。它只说明：**当前解析状态中并非已经藏着一个普遍更好的答案，等着把权重拧大。**必须先定位其错误来源，再检验读出，而不能靠放大差异制造创新证据。

## 8. 下一步的判别顺序

1. **先查有效推断。**在开发集固定事件上对照参考后验，分别查父权重集中、投影零概率和反馈后的恢复。然后以相同总候选评分/粒子预算比较可恢复的分配方式；联合与因子化一起跑。若后验误差不降，先不归咎于动作层。
2. **再查决策语义。**在同一历史、同一信息下，比较当前owner门控和明确面向owner习惯的条件读出；必须同时保留访客污染、错误归因及完整伪造反例。记录从哪个依赖到哪个动作的变化，同时统计新引入的错误。这是待预注册的建议，不是本次已实施改动。
3. **最后检验真正的联合增量。**若要主张主动感知收益，应给双方相同候选动作、成本、观察与执行接口，由各自后验决定行动；若主张长期归因收益，主结果必须在首步之外、不同世界动力学上出现，并胜过保留共同机制的强对照。任务/指标/科学路线的选择仍由用户决定。

现有D0理想检测、外生人物/世界、已知位置菜单及每条件仅1种去ID位置轨迹的限制保持。四个种子不是四种独立世界动力学，本报告不做显著性或自然机器人泛化声明。当前能够明确定位实现与实验瓶颈；完整机制的科学价值仍待检验，不能以工程通路通过代替。
