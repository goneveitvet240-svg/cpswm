# 项目一 SHIFT 行动级死亡测试结果 v2（2026-08-22）

## 最终判决

双轨预注册判决为 **`REBUILD_JOINT`**：shared-policy track 与 independently-retuned-policy track 均显示 legacy independent CF-BOCPD 相对 joint CF-BOCPD 的 action regret 优势超过预注册 MDE `0.05`，且区间不跨阈值。

v2 使用全新 151 个 TEST seeds（9101–9401 奇数），未复用已撤回 v1 的 TEST seeds。每个 seed 六个 shift families，共 906 TEST cases。

## 公平搜索与功效

- shared-policy：每臂 18 个 detector candidates。
- independently-retuned-policy：每臂完全相同的 `18 × 117 = 2106` detector-policy/calibration candidates。
- 每条轨道精确包含 regret/corruption × ordinary/legacy 四个 power analyses；两轨共八项。
- shared required n：11、151、16、141；retuned required n：3、66、11、101；最终 n=151，全部 PASS。
- empirical stddev、required n 和 status 均由报告内 pilot artifacts 按 config pilot seeds 重算。

## 状态边界

- “joint CF-BOCPD 在有意义的下游行动上优于 ordinary BOCPD”：不成立；独立公平重调轨道区间跨 0。
- “joint 优于 legacy independent CF-BOCPD”：明确不成立，两轨均被 legacy 以超过 MDE 的幅度击败。
- “继续把现有 joint 扩展到全局 11 臂”：BLOCK。
- “正式结构一 B1 已完成”：BLOCK。
- “legacy 应自动成为最终正式方法”：仍不能仅凭 synthetic action proxy 决定，需要真实 habit-state update 和外部有效性验证。
