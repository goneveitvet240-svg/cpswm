# 结构三技术决策门 v0.1

日期：2026-08-25
原则：需要项目负责人选择的路线不擅自拍板；先推进与选择无关的契约、数据、评价和并列基线。

| Gate | 待决定问题 | 并列候选 | 当前绕行工作 | 触发决定的条件 |
|---|---|---|---|---|
| S3-DG-01 | 最终六通道融合模型 | log-opinion pool、factor graph/DBN、particle/RB filter、energy-based、neuro-symbolic、learned fusion | 保持统一 likelihood contract，先做全部基线与敏感性分析 | 真实/半真实数据与公平调参结果齐备 |
| S3-DG-02 | `unknown` 质量模型 | 固定先验、coverage-derived、Good-Turing/open-set、学习式估计 | 显式 unknown 契约、召回漏失压力测试和 AUROC/AUPRC | FindingDory/真实覆盖率与漏检标定可用 |
| S3-DG-03 | 观察选择偏差校正 | IPS、doubly robust、显式生成模型、仅分层报告 | 保留 split、来源、选择上下文和后续 propensity 字段 | 确定 estimand 与 logging policy |
| S3-DG-04 | 主动规划深度 | 一步 VoI、rollout、POMCP/其他非近视规划 | 保留动作模型与统一成本；先跑一步基线 | 多步容器/恢复情境与预算固定 |
| S3-DG-05 | 记忆持久模型 | latest、fixed/exponential decay、recency、HCS、其他 survival model | 统一 M19 likelihood-ratio 接口并保留全部对照 | 长期事件与人物活动数据可用 |
| S3-DG-06 | conformal 路线 | 阈值基线、CO-CIP、split conformal、anytime-valid e-process | 先冻结数据、风险、成本和评价，不覆盖现有后验基线 | 开放集/非平稳基线完成且理论构造可审查 |
| S3-DG-07 | 非搜索失败恢复策略 | retry、重新观察、重新定位、询问、停止、安全撤退 | 当前只规范写入；每种恢复作为独立 oracle policy arm | 任务/安全效用和允许动作集明确 |
| S3-DG-08 | FindingDory 深层 episode 数据采用边界 | 仅 SFT 八列帧检索轨、读取 Habitat episode 原始文件、寻找其他实例轨迹数据 | 八列 metadata adapter、缺失字段审计与 prediction cache 已完成；不伪造完整 episode | Habitat schema、scene/time grouping 与衍生数据许可完成核验 |

任何 gate 的暂缓都不授权删除 person/event/habit、显式 unknown、多视角/触觉、
静态/动态地图、主动验证或不确定执行写回。暂缓只意味着对应方法保持并列，完整范围继续推进。
