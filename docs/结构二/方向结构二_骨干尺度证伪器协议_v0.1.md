## 0. 本协议要回答的三个决定性问题

1. Rao–Blackwellization 是否真的降低方差或计算成本？
2. 类型化粒子修订是否比普通粒子滤波更有效？
3. 联合模型是否真正优于匹配预算的两阶段流水线？（该问题由配套的联合性死亡测试承担）

在这三个问题有答案之前，不得冻结粒子预算、重采样策略、回春核和可微策略。

## 1. 任务 3：链式阶梯任务

### 1.1 完整粒子，不得缩减

每个粒子必须真实携带

$$\chi_t=(H_t,R_t,I_t,C_t,Z_t,r_t,V_t)$$

**明确禁止**继续使用 `structure_two_fresh_triarm.py:109` 的 `_ActionParticle`：

```python
class _ActionParticle:
    actor_key: str
    identity_target: bool
    cause: ChangeCause
    regime_change: bool
```

它只有 4 个字段，缺 $H_t$（完整事件链）、$R_t$（有序角色）、$r_t$（游程）和 $V_t$（谱系），
且把 $I_t$ 压成布尔、把 $Z_t$ 压成布尔。任何以它为状态的实验只能登记为
`Development evidence`，不能进入骨干收益证据链。

### 1.2 状态空间随观察间隙增长

环境由 $G$ 个观察间隙组成。每个间隙 $g$ 的事件链片段包含：

- 机制 $m_g\in\{\text{direct},\text{handoff}\}$；
- 有序角色 $R_g$：`direct` 为 $|A|$ 种（取放同一人），`handoff` 为 $|A|^2$ 种（giver × receiver）；
- 实例关联 $i_g\in I\cup\{\text{unknown\_instance}\}$；
- 变化原因 $c_g\in\{observation,actor,identity,habit,noise\}$；
- 阶段目的地 $z_g\in\{stay,create,unresolved\}\cup\{\text{reactivate}(k)\}$。

因此单间隙分支数

$$B_g=\big(|A|+|A|^2\big)\cdot\big(|I|+1\big)\cdot
\big[(|C|-1)\cdot 2 + (3+r)\big],\qquad r=\#\{\text{已退役阶段}\},$$

**注意 `CREATE` 与 `REACTIVATE` 只在 `cause = habit` 时合法**（镜像
`TypedParticleState._validate_typed_state`），所以阶段因子不能当成与原因无关的乘子——
本协议 v0.1 初稿写成 $|C|\cdot|Z_g|$ 是错的，会把单间隙分支高估 36%。分支随历史增长
（每多一个退役阶段 $+90$），所以总状态数**不是干净的幂**，这正是要保留的真实困难。
实测值（$|A|=5$、$|I|=2$）：

| $G$ | 单间隙分支（$r=0,1,2,\dots$） | 离散状态数 | 设计用途 |
|---:|---:|---:|---|
| 1 | 990 | 990 | 精确枚举金标准 |
| 2 | 990 / 1080 | 988,200 | 精确枚举金标准 |
| 3 | +90/退役阶段 | 995,085,000 | **实测**枚举的时间与内存边界 |
| 4 | 同上 | 1.011×10^12 | 实测边界，已不可枚举 |
| ≥5 | 同上 | ≥1.04×10^15 | 粒子近似与可扩展性测试 |

$G=1,2$ 两格为代码实测值，$G\ge3$ 由递推
$f(d,r)=90(10+r)f(d-1,r)+90f(d-1,r+1)$ 独立复算（$G=1,2$ 与实测精确相符）。

**不预先规定任何一个 $G$ 一定不可枚举。** 精确枚举的可行边界必须由实测状态数、
墙钟时间和峰值内存确定，并写入结果报告；$G=3,4$ 的作用就是把这条边界测出来。

### 1.3 验收标准

随 $G$ 增长，事件链、有序角色、实例关联、变化原因、阶段目的地、游程和谱系
**都必须真实增长**。禁止用一个静态状态在多帧上重复打分冒充链式任务。
验收方式：断言 $G+1$ 的状态枚举数严格大于 $G$，且抽样的链在 gaps、$H_t$、$R_t$、
$V_t$、$r_t$、阶段时间线六项长度上随 $G$ 增长（$I_t$ 与 $C_t$ 经 gaps 长度间接覆盖）。

## 2. 任务 4：给粒子挂载真实解析块

### 2.1 最低实现要求

$$S_t=(\alpha_t,A_t,b_t,\Lambda_t,\xi_t)$$

- 每个 (actor, object, context) 三元组维护 Dirichlet 参数 $\alpha$，
  $\alpha=\alpha_0+\sum_c\Delta\alpha_c$；
- 线性高斯动态参数 $A=\lambda I+\sum_c w_cx_cx_c^\top$、$b=\sum_c w_cx_cy_c$、
  $\theta=A^{-1}b$；
- 精度或协方差统计量 $\Lambda=\Lambda_0+\sum_c\Delta\Lambda_c$；
- 充分统计量 $\xi=\xi_0+\sum_c\Delta\xi_c$；
- 更新由**真实观测**触发，不得由场景标志硬编码（对照：旧仪器的
  `run_length = 1 if short_regime else 4`）；
- `statistic_state_ref` 必须指向真实状态对象或不可变快照，不得是
  `f"analytic-state:{state.key}"` 这类占位字符串。
- 阶段内遗忘因子固定为 1（沿用方法冻结 v1.0 §2.1）。

### 2.2 验收标准

1. 移除解析更新后，实验结果发生**可解释的**变化（而不是无变化，也不是崩溃）；
2. RBPF 与 sampled-$\theta$ PF 成为真正不同的算法——即存在一个可打印的差异：
   前者对 $S_t$ 积分，后者对 $S_t$ 采样，二者的有效样本量与方差可分别测量。

## 3. 任务 5：统一计算成本口径

### 3.1 每个算法必须记录的七个计数器

| 计数器 | 定义 |
|---|---|
| `unique_state_target_evaluations` | 被计算过目标的**不同**离散状态数。**口径差异必须声明**：精确臂计的是完整链，粒子臂计的是链前缀，两者不可直接相除 |
| `elementary_likelihood_evaluations` | 基础似然项调用次数（含重复） |
| `proposal_generation_evaluations` | 提议器前向/候选**打分**次数。**已知缺陷**：bootstrap 分支每次采样只记 1，而其内部构造的候选与 typed 分支 `_legal_gaps` 构造的约 990 个候选都不计数，因此该列低估 typed 的真实生成量约 50 倍，且两臂口径不同。真实工作量以 `elementary_likelihood_evaluations` 为准 |
| `wall_clock_seconds` | 墙钟时间 |
| `peak_tracked_objects` | 峰值同时存活的假设对象数（**当前实现**；真正的 `peak_memory_bytes` 尚未实现，边界测量另行用 `resource.getrusage` 记录） |
| `particle_count` / `resampling_events` | 粒子数与重采样次数 |
| `ancestry_window_length` | 局部修订实际访问的历史窗口长度 |

### 3.1.1 先验口径声明

`_AXIS_PRIOR` 中的数值是**未归一化势函数**，不是目标分布的边缘先验：可用的阶段
move 集合依赖历史与 admissibility，而势函数从未按可用集重新归一化。$G=1$ 下目标
隐含的实际先验为 `habit 0.232`（声明 0.20）、`stay 0.788 / unresolved 0.172 /
create 0.039`（声明 0.55 / 0.12 / 0.18），admissible gap 上的先验总质量为 0.698。
各臂共用同一目标，**比较仍然公平**，但论文中不得引用声明值当作先验。

### 3.2 明确禁止

1. 近似方法内部调用全状态枚举（旧仪器的 `_top_states` 对全部 360 个状态排序）；
2. 先计算精确后验，再从中挑 Top-K；
3. 不同算法使用不同的成本定义；
4. **用 oracle 目标重新打分某臂的输出来构造它的精度指标。** 这是常设禁止项，不是
   一次性 bug：任何这样构造的度量测的都是该臂的 support，而不是它的估计量。旧仪器的
   截断来自排序、本仪器 v0.1 的截断来自采样，形式不同、后果相同——TV 都恒等于
   $1-P_{exact}(\text{support})$。每个臂的精度必须由它自己的估计量（自归一化粒子权重）
   给出；覆盖率作为独立指标单独报告，绝不冒充 total variation。
5. **用只读众数的规则给行动打分。** 常设禁止项：`argmax` 类打分在所有臂共享众数时
   分辨率恒为零，与动作数量、查询特征、真值参数都无关（已用 9-bin 非退化边缘证伪
   "加 bin 就能修好"）。任何决策指标必须附带一个连续量——行动后验的 TV，或该决策
   真正骑在上面的那个后验量的校准误差。单一硬阈值代价尤其不得单独报告：它可以
   奖励一个更差的信念（实测 sampled-$\theta$ 的巩固代价低于精确 oracle）。
6. **把量纲不同的计数器放在同一列比较**——旧表里 bootstrap PF 的 `48 = K × frames`
   是真实采样代价，而束搜索的 `744 = 360×2+K` 和类型化修订的 `502.6 = 360+|pool|`
   按构造都 ≥ 全枚举代价；三者同列本身就是错误。

### 3.3 强制执行方式

成本计数由**单一 instrumentation 层**记录，各算法不得自报。精确枚举器接受一个
`caller_role` 参数，当调用方角色为近似臂时直接抛异常；对应的负向单元测试必须存在
（"近似臂调用全枚举 → 测试失败"）。

### 3.4 验收标准

可以绘制 **accuracy–compute curve（准确率—计算量曲线）**，横轴至少同时提供
`unique_state_target_evaluations` 与 `wall_clock_seconds` 两个版本，
而不是只比较一个模糊的候选评分数字。

## 4. 任务 6：四个主要推断对照臂

| 臂 | 离散骨架 | 连续参数 $S_t$ | 说明 |
|---|---|---|---|
| **A. Exact oracle** | 全枚举 | 解析 | 仅用于小 $G$；提供金标准后验 |
| **B. Sampled-$\theta$ PF** | 采样 | **采样** | 检验 RB 化的收益归属 |
| **C. RBPF** | 采样 | **解析边缘化** | B→C 的差 = Rao–Blackwellization 的收益 |
| **D. Full typed RBPF** | 采样＋类型化约束＋局部修订＋候选提议 | 解析边缘化 | C→D 的差 = 类型化修订的收益 |

保留 `incremental beam` 与 `full-rerun beam` 作为**诊断性参考**（它们是旧仪器的参照物），
但它们不是主要对照臂，且同样受 §3.2 约束。

匹配条件（全部强制）：同一份观测；相同粒子预算**或**相同计算预算（两种口径都要报）；
各臂独立调参；完整方法不得使用任何额外真值信息；同时报告均值、方差和失败种子清单。

**验收标准**：能够分别回答"RB 是否有效"（B vs C）和"typed revision 是否有效"（C vs D），
避免所有组件一次性加入后无法归因。

## 5. 任务 7：迟到纠正测试

在 $t-k$ 注入纠正证据，比较四种处理：

1. `local_rejuvenation`（局部回春）；
2. `full_rerun`（完整重跑）；
3. `reweight_only`（仅重加权旧粒子）；
4. `append_only`（不允许修改已提交账本）。

测量：posterior equivalence（对 full rerun）、revision recovery、owner contamination、
被错误提升状态的可撤回性、局部修订成本、对未受影响历史的破坏程度。

**验收标准**：小 $G$ 下 `local_rejuvenation` 与 `full_rerun` 近似等价（差值落在预注册容差内）；
大 $G$ 下成本显著更低，同时污染不扩大。`append_only` 臂预期在污染发生后无法恢复——
这正是"可逆巩固"这一科学主张的可证伪形式。

**2026-09-02 补充**：首轮实现把 `local_rejuvenation` 做成"从纠正点开始的完整后缀重跑"，
在纠正点为 $k$ 时它与 `full_rerun` **逐位相同**，等价性成为实现恒等式而非证据。
本验收标准要真正成立，`local_rejuvenation` 必须是窗口式的——只重提议受影响的间隙，
其余间隙重加权。该核尚未实现。

## 7. 本协议冻结了什么、没冻结什么

**已冻结**：状态定义（完整 $\chi_t$）、$S_t$ 的最低实现要求、七个成本计数器、
四个主要对照臂及其匹配条件、迟到纠正的四种处理、指标集、禁止事项与强制执行方式。

**未冻结，必须由实验决定**（沿用方法冻结 v1.0 §9）：
particle budget、resampling policy、rejuvenation kernel、differentiability strategy、
神经提议器架构、训练计划、巩固阈值、CIAV 动作预算、各门的样本量与阈值。

**本协议不授权的表述**：协议冻结 ≠ 实现完成 ≠ 结果成立。在阶梯任务真实运行之前，
结构二骨干的近似质量、RB 收益、类型化约束收益和提议器收益一律登记为 `Unresolved`。
