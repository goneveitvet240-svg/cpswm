脚本没有导入 CPSWM 或调用生产 `fit`、`predict`、`summarize`。它从两个已锁定前端的公开候选重建 8×8 网格及全部无序不同像素对；从同事件原始 RGB/depth NPY 和公开相机参数独立计算 8 维特征、深度有效性；逐点把保存的 `point_members` 与原始 masks 和最终 runtime audit 比较，再重新生成 same/different/VOID 标签。保存的去重索引、完整实例目录、不可见实例和各候选来源均核对。模型标准化、类别频率及训练数组摘要仅使用 house 1–8 的 64 帧；保存参数自行计算所有分数，并复核初始及最终训练目标、逐帧/屋/分区报告。

字节摘要要求精确相等。独立浮点算式使用预先写定的容差：报告指标/分数 `atol=rtol=2e-12`、公开特征 `2e-10`、train-only 标准化 `1e-10`；所有检查通过。特征最后一维用相机坐标下欧氏距离独立复算，旋转和平移保持距离，因此没有复用生产 world-point 实现。

176 个候选产生 353,452 次候选来源配对，去除 733 次跨方法/框的重复后得到 352,719 个公开像素对。所有对深度均有效；277,991 个 VOID 的互斥原因全部为 `ineligible_instance`，本批 `invalid_depth`、`ambiguous_membership`、`unmapped_pixel` 均为 0。此处不合格包含资产隔离的合法上下文实例等，不能统称为背景，更不能把它们自动改成 different-instance 负例。全部 **277,991 个公开 VOID 分数仍为有限数并保存在 scores.npy**；私有标签只决定是否纳入训练/指标，没有删除其公开推断输出。

训练和验证的 VOID 比例分别为 80.25% 与 76.99%。训练常数是仅由训练正负对求得的 `0.8835432000615495`，验证正对比例是 `0.8410242059605428`。这也说明任务存在明显类别不平衡；像素对总数不代表统计独立样本数。

## 对象覆盖：并集与对象帧次分别统计

对象身份按 `(house_index, SDK object_id)` 合并。下面“可见”指原始 mask 在至少一帧非空；“端点命中”指公开像素对的端点落入合格 mask；“参与监督”要求对象至少出现在一个非 VOID 对中。

对应的可见合格对象帧次是 182/71/253；端点命中对象帧次是 67/37/104；参与监督对象帧次是 67/34/101。因此不能把 503 个合格实例写成全部可见或全部获得监督，也不能把 80 个对象并集和 101 个对象帧次混为一谈。验证中两个被端点命中的对象没有形成非 VOID 配对，记录仍被保留。

## 固定对上的模型与常数比较

下表均在同一批非 VOID 对上比较；常数始终来自训练频率。数值越低越好。

| Validation，按对汇总 | 35,735 对 | 0.298310 | 0.445967 | 0.087341 | 0.135510 |
| Train，逐屋等权平均 | 8 屋 | 0.245543 | 0.315898 | 0.069320 | 0.086274 |

这支持一个窄结论：在固定公开配对和最终资格门控下，当前离线亲和度模型在本批已曝光开发数据上优于训练频率常数。它不证明实例检测、完整前景 mask、跨视角身份或完整 pipeline 已完成。

本轮 8×8 全配对比旧三表面采样方案覆盖更多像素，这是采样协议变化，不能归为学习收益。前端模型仍是既有固定输出，本轮没有依据验证结果选模型、阈值或超参数。mask 监督描述渲染实例成员关系，不证明 depth 对应的物理表面归属；分数也未校准为观测似然。12 屋、同机/同引擎、仅原地改变 yaw 的相关数据不能提供独立统计样本或平移视差证据。正式位置参照、完整 mask、跨视角身份、记忆写入与动作收益仍未由此实验验证。
